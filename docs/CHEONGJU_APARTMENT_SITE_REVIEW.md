# 청주 아파트 17개 혼합 키 — 단지별 원본 관계 검토

2026-10-05. [청주 전체 이름 키 감사](CHEONGJU_NAMED_OBJECT_MIX_RESULT.md)의 법정동 교차·복수 K-apt 코드 아파트 17개를 검토했다. **17개 모두 최소 한 주소 쌍에서 별개 단지 혼합을 뒷받침하는 원본 근거가 확인됐다.** 개별 거래의 단지 소속과 새 객체 경계를 인증한 결과는 아니다.

## 확보한 근거

기존 17개 키의 관측 주소 39개와 기간 거래 6,894건을 유지했다. 2026-07 원본 표제부 전국 8,060,932행을 순차 검사해 관련 주소의 546행을 확보했다. 원본 파일 해시는 이전 고정 입력과 일치하며 관련 관리 PK 중복은 없다. K-apt 대표주소·기본정보 파일도 이전 감사와 같은 해시임을 확인했다.

K-apt 근거가 있는 주소 37개 모두에서 사용승인일이 동일 주소의 원본 공동주택 표제부에서 재현됐다. K-apt 기본정보 중복 행은 원문 그대로 보존했다. 표제부의 주용도 ‘공동주택’, 세부용도 및 승인일을 별도로 저장했다. 공동주택 행에는 관리실·상가·주차장 등도 포함되므로 행수를 아파트 동수나 단지 수로 해석하지 않는다.

주소 쌍 28개 중 **23개**에서 다음 근거가 함께 확인됐다.

- 관측 주소의 비어 있지 않은 K-apt 코드 집합이 서로 겹치지 않음.
- K-apt 단지명·도로명주소·사용승인일이 서로 다름.
- 양쪽 주소에 공동주택 표제부가 있고, 각 K-apt 승인일이 표제부에서 재현됨.
- 현행 유효·양수 단가·통계 기간 조건의 거래가 실제 같은 달에 관측됨.

예를 들어 ‘대원’ 이름으로 묶인 한 키에는 가경대원아파트(가경동 1511, 1997-07-29)와 복대대원아파트(복대동 221-7, 1999-10-07)가 포함된다. 서로 다른 두 K-apt 코드와 도로명주소, 원본 승인일 및 같은 달의 거래 관측을 확보했다.

현행 키 생성 규칙이 구까지만 포함하고 법정동을 생략하는 동명 아파트에서 객체 범위를 넓게 묶는다는 설명과 일치한다. 다만 정적 K-apt 파일에는 코드 유효기간·변경 이력이 없으므로 행정코드 변경 또는 다필지 관계가 없다고 확정하지 않는다. 같은 달 거래도 개별 거래 소속의 직접 증명은 아니다.

## 남은 두 주소

K-apt 대표주소 근거가 없는 주소 두 개 때문에 **5개 주소 쌍**은 근거 부족으로 남겼다.

- `apt-site-06` 우암동 50-4: 공동주택 표제부에서 연립주택 등 세부용도가 관측됐다. 아파트 거래 분류와 대장·객체 관계를 추가 확인해야 한다.
- `apt-site-07` 서운동 21-7: 아파트·관리실·단독주택 표제부가 함께 관측됐다. 동주소 혼재만으로 거래의 소속 건물을 선택하지 않는다.

이 두 주소도 거래를 버리거나 자동 오류로 확정하지 않았다. 해당 두 키에는 다른 주소 사이에서 별개 단지를 뒷받침하는 근거가 있으므로, 전체 17개 중 미검토 키로 되돌리는 대신 주소별 미확인 범위를 남겼다.

## 병행 선택기의 보류 규칙

17개 키에 `object_scope_review_hold`를 적용하는 실험용 게이트를 만들었다. 주소 파티션 39개·거래 6,894건을 보존하고, 새 객체 키·대표 PNU는 할당하지 않았다. 혼합 키 전체의 기존 가격 마트·건물 속성을 개별 주소에 승계하지 않는다. 기존 보강은 원형을 근거 파일에 보존했다.

이는 운영 차단이나 제품 변경이 아니다. 별개 단지를 뒷받침하는 근거와 실제 거래 소속을 구분하고, 전체 묶음의 가격·속성이 새 단위에 무조건 복사되는 일을 실험 단계에서 막는 규칙이다. 비주거의 도로명 군집에는 주거 단지 분할 규칙을 적용하지 않았다.
