# 회귀 개선 작업 현황 — 수행 내용과 남은 작업

> 기준일: 2026-10-27 · 이 대화에서 수행한 1~5차 작업 기준  
> 대상: 복합, 토지, 집합 주거 단지, 집합 비주거 도로명, 주거 지역회귀  
> 상태: 주요 정합성 수정·공통 표시·일부 상세 UI를 로컬 반영. **전체 계획 완료 아님.**  
> 원격 반영: 2026-10-29 사용자 요청으로 통합 커밋·운영 반영 대상으로 정리. 과거 차수의 미배포 표현은 당시 기록이다.

## 1. 이 문서의 역할과 상태 구분

수행한 작업과 앞으로 수행할 작업을 현재 시점에서 모아 읽는 현황 문서다. 차수별 상세 변경·검증 이력은 [통합 구현계획 §9~13](REGRESSION_UNIFIED_IMPLEMENTATION_PLAN.md#9-구현-진행-기록--2026-10-26)을 함께 확인한다. 원문의 미체크 항목을 모두 미구현으로 보거나, 일부 기능 반영을 원문 항목 전체 완료로 보지 않는다.

- **로컬 반영:** 관련 코드·화면·응답 계약을 수정했다는 뜻이다. 운영 반영이나 모든 조건 검증을 뜻하지 않는다.
- **부분 반영:** 같은 원문 항목 안에서 해결한 부분과 남은 부분이 함께 있다.
- **구현 잔여:** 기능이나 UI 처리가 아직 없다. 테스트만 추가하면 끝나는 일이 아니다.
- **검증·감사 잔여:** 구현된 기능의 남은 실제 조건 검증, 설명 대조 또는 원문별 완료 판정이 필요하다.

차수별 과거 잔여 목록은 당시 기록이다. 특히 통합 계획 §12.5의 QA 목록만으로 현재 미구현 기능 전체를 설명할 수 없다. 이 문서 §4와 통합 계획 §13.3을 최신 잔여 목록으로 사용한다. 현재 원문별 세부 판정이 모두 끝난 상태는 아니므로 완료율은 산출하지 않는다.

## 2. 공통으로 수행한 개선

### 2.1 분석 기준과 실제 모형 정보 — 로컬 반영

- 다섯 회귀에 공통 ‘분석 기준 보기’를 연결했다.
- 종속변수·단위·척도, 실제 적합 수, 계수 수·설계행렬 순위, 실제 사용 변수·기준 범주, 표본 단계와 모형/자료 서명을 제공한다.
- 거래 단위 모형과 단지 중앙단가 모형을 구분한다. 금액은 만원, 단가는 만원/㎡로 표시한다.
- 주거 고급 특성의 상수·자료 없음·결측 제외 후 차이 없음·단일 단지 식별 불가를 실제 계산 상태로 기록한다. 모든 엔진의 생략 사유가 같은 세밀함을 가진다고 단정하지 않는다.

### 2.2 계수 해석과 숫자 표기 — 로컬 반영

- 복합 로그로그 면적·로그 공시지가의 1% 효과를 수정하고, 절편이나 단위가 다른 원계수 절댓값을 중요도 순위로 해석하던 설명을 제거했다.
- 계수 상세를 `변수 / β / 효과 해석 / SE / t / p` 순서로 맞췄다. 범주 효과는 실제 기준 대비로 설명한다.
- 작은 계수·통계량을 반올림해 0으로 지우지 않고, 작은 p값은 `<0.001` 등으로 표시한다.
- 기존 통계 기준을 유지하면서 화면에 임계치를 명시했다. 복합 요약의 유의 계수 집계 p<0.05와 회귀식 기본 표시 p<0.1을 같은 기준으로 오인하지 않게 했다.

### 2.3 학습·검증·후보 비교 — 로컬 반영, 토지 새 비교 실험은 잔여

- 집합 주거/비주거 후보는 공통 유효 거래와 같은 분할에서 비교한다. 지역회귀 후보도 공통 유효 단지와 분할을 사용한다.
- 복합 후보의 평가 관측·연도 분할·계산 방식 서명을 대조해, 같은 n만으로 ‘성능 유사’를 표시하지 않게 했다.
- 지역회귀 확장 비교는 같은 기준지역 평가 단지를 양쪽 학습에서 제외한 별도 실험으로 제공한다. 평가 표본 부족은 비교 불가로 표시한다.
- 선정용 검증과 독립 확인을 구분한다. 척도나 표본이 다른 AIC로 우열을 대신 정하던 복합 fallback을 제거했다.
- 검증 방식·관측 단위·예정/시도/완료 분할·정상 예측 수·실패 코드를 구조화했다. 표본 부족, 학습 거래 부족, 적합/예측 실패, 비유한 예측과 미실행을 구분한다.
- 집합 거래 5겹은 모든 분할이 완료돼야 CV 오차를 제공한다. 복합 연도별 검증은 기존 정책상 일부 연도 오차를 유지하되 ‘일부 제공’과 완료 범위를 표시한다.
- **토지의 동일 연결 비지분 표본에서 공시지가 사용/미사용을 비교하는 기능은 아직 구현하지 않았다.**

### 2.4 추정 결과와 요청 상태 — 로컬 반영

- 다섯 회귀의 추정 API가 화면의 기대 모형 서명과 서버 재적합 모형을 대조한다. 불일치하면 409와 재실행 안내를 반환한다.
- 입력·조건·모형이 바뀌면 이전 추정값을 최신 결과로 표시하지 않는다. 호환 수치 입력은 보존하고 새 모형에 없는 범주는 조정하거나 거절한다.
- 필수 수치 누락을 0으로 바꾸거나, 없는 범주를 기준 범주로 조용히 계산하는 경로를 차단했다.
- 토지의 늦은 성공·오류가 새 결과나 로딩 상태를 덮지 않게 했다. 복합·주거·비주거·지역회귀도 입력/모형 변경 시 이전 추정의 오류·진행 상태를 해제한다.
- 응답 무효화와 서버 계산 중단은 별개다. 모든 회귀에 서버 계산 취소 기능을 새로 구현한 것은 아니다.

### 2.5 문체·도움말·접근성 — 부분 반영

- ‘조건별 통계적 추정’, ‘추정값 계산’, ‘95% 평균 추정범위’ 등의 표현을 맞췄다. 지역회귀는 ‘95% 단지 중앙단가 예측범위’로 구분한다.
- 수정한 변환·검증·잔차 산식과 Twin 설명을 화면 도움말·AI 제품 지식에 동기화했다. 전체 설명 전수 감사는 남아 있다.
- 제목·닫기가 앱 헤더에 가리는 문제, 확대/Esc 복원 문제를 수정하고 같은 형식을 쓰는 5앱 위젯에 적용했다.
- 중첩 도움말에서 Esc 한 번에 부모 창까지 닫히던 오류를 수정했다. 최초 포커스·Tab 순환·닫기 후 복귀를 연결했다.
- 회귀 계수 표를 키보드로 포커스하고 스크롤할 수 있게 했다. 해당 표가 없는 임대·지역프로필에 회귀 표를 새로 만들지는 않았다.
- 어두운 테마의 보조 문구·추가 대상·토지 추정 경고 등의 대비를 수정했다. 전체 앱 접근성 기준 충족을 선언한 것은 아니다.

## 3. 유형별 수행 내용과 경계

### 3.1 복합 — 기본회귀·기존 Macro·상위지역

**반영한 내용**

- 기본 회귀의 계수 해석·분석 기준·검증 연도/실패 사유와 표기를 수정했다.
- 기존 Macro의 예측형·설명형·쌍둥이 확장 구조를 유지했다. 지역 내 탐색 → Twin1 재적합 → Twin2 재탐색의 미실행/진행/실패/완료/이전 선택 상태를 구분한다.
- 실행 범위·기준월·기간·조회/적합 수·확장 실행 당시 선택 지역을 표시한다. 현재 선택과 다른 확장 결과의 추정을 제한한다.
- Twin2 후 Twin1 재실행 및 실패 후 재시도에서 실행 플래그가 남던 경로를 수정했다.
- 상위지역의 ‘결과 보기/접기’는 이미 계산된 별도 모형을 펼치는 행동임을 명확히 했다. 실제 포함 변수·기준 범주·식별 제한과 공시지가 비교를 연결했다.
- 잔차의 ‘전체 대비’를 실제 산식인 ‘나머지 대비’로 수정했다. 영향 거래의 실제 ID·거래/추정금액·오차·면적·Cook 거리·레버리지를 상세로 확인한다.
- 상위지역 추정 제목이 ‘Macro 모형 적용 예시’로 나오던 문구를 공통 추정 제목으로 수정했다.

**남은 경계**

경고 통합, 후보별 변수 차이·확인 중인 후보의 강조, 설명형 비교 요약, Macro 탭 유지·상세 이동·번호 체계, 표 확대와 일부 개별 화면 QA는 남아 있다. 기존 Macro를 추천2로 대체하지 않았다. 원문: [복합 개선안](BUILT_REGRESSION_UX_IMPROVEMENT_PLAN.md).

### 3.2 주거 집합 — 개별 단지·인접단지

**반영한 내용**

- 학습 MAPE와 거래 5겹 CV를 분리하고, 후보 공통 표본·검증 기록을 제공한다.
- 추가 단지를 이름·주소로 검색하고 표시 제한/전체 결과 수를 확인할 수 있다.
- 대상별 조회/실제 적합 수와 FE 기준·포함·미포함 상태를 표시한다. 목록 거래수와 회귀 적합 수를 구분한다.
- 고급 특성의 실제 포함/생략/식별 제약을 표시한다.
- 선택 단지의 적합 거래 전체에 같은 확인값이 있을 때만 세대수·세대당 주차·공시지가를 명시적으로 불러온다. 결측·연도별 차이를 임의로 보충하지 않는다.
- 반기 선택·적용 시점을 제공하고, 입력·모형 변경 후 이전 결과/오류와 FE 제외 대상의 추정을 차단한다.

**남은 경계**

추가 단지 영역 접기·요약, 후보별 변수 차이·적용 전 요약, 결과 구역 이동·계수 크게 보기, 경고 통합, 전체 잔차 진단과 고급 특성/외삽의 남은 조건 검증은 남아 있다. 원문: [주거 단지 개선안](COLLECTIVE_RESIDENTIAL_REGRESSION_UX_IMPROVEMENT_PLAN.md).

### 3.3 비주거 집합 — 도로명 단위

**반영한 내용**

- 기간 필터·실제 거래 ID/정렬·필수 입력·적용 반기·층/범주 효과 해석의 정합성을 수정했다.
- 주거와 같은 결과·후보·대상 검색·검증 기록·추정 상태 규칙을 적용한다.
- 도로별 조회/실제 적합 수, 기준 도로·도로 FE 상태를 표시한다. 추가 도로 영역과 경고의 어두운 테마 대비를 수정했다.
- 집합상가와 집합공장 추가 도로 회귀를 실제 실행해 확인했다.

**남은 경계**

추가 도로 영역 접기, 단계별 경고 요약·다음 행동, 후보별 설정 차이, 표 확대, 전체 잔차 진단(C-09)과 남은 상가/공장 화면 QA는 남아 있다. 주거 전용 확인값 불러오기를 비주거에 형식적으로 복제하지 않는다. 원문: [비주거 개선안](COLLECTIVE_COMMERCIAL_REGRESSION_UX_IMPROVEMENT_PLAN.md).

### 3.4 주거 지역회귀 — 단지 중앙단가

**반영한 내용**

- 동일 조건 반복 실행의 정렬·표본을 안정화했다. 로그 R²·모형 척도 조정 R²와 원단가 지표의 혼합 표시를 수정했다.
- 단지 중앙단가·만원/㎡·단지 수를 명시하고, 학습/분리 검증 단지 수·실패 사유를 구분한다.
- 후보 공통 단지/분할, 기준지역의 같은 평가 단지를 사용한 확장 비교와 비교 불가 상태를 제공한다.
- 블록 비교에 현재 지역 더미·범주 결측 처리를 반영하고, 추정 재적합/필수 입력과 모형 서명을 확인한다.
- 학습 단지별 주소·거래수·실제/적합 단가를 제공한다. 학습 단지 오차를 독립 확인 결과로 부르지 않는다.
- 조건·입력 변경 시 이전 추정과 이전 오류를 해제하고, 계수 표의 형식·키보드 접근을 맞췄다.

**남은 경계**

결측 상세와 소표본 시 결측 변수 해제·재실행 행동은 기존 구현이 있으므로 미구현으로 분류하지 않는다. 원문이 요구한 단지별 구체 제외 목록·현재 조건의 추가 제외 영향 안내, 쌍둥이 선택 범위·설명 요약의 충족 범위를 대조해야 한다. 실제 단지/가상단지·유형 혼합·지역 더미·가중·최소 거래수의 남은 조합 검증과 원문 RG-01~08의 세부 완료 판정도 필요하다. 원문: [지역회귀 개선안](COLLECTIVE_REGIONAL_REGRESSION_UX_IMPROVEMENT_PLAN.md).

### 3.5 토지 — 신림동·봉천동 사례와 공시지가

**반영한 내용**

- 로그 면적·공시지가의 효과, 원면적/로그 단가 해석, 절편 설명과 원단가 평균 역변환을 수정했다.
- 공시지가 모형에서 보강 불가 지분거래를 구조적으로 제외한다. 나머지 거래의 미연결과 별도 집계하고, 지분 추정 요청을 거절한다.
- 동별 조회/적합·지분 제외·비지분 연결/미연결 수, 실제 기준 범주·거래/공시지가 연도를 표시한다.
- 별도 탐색 표본과 현재 공시지가 모형을 직접 비교하지 않도록 안내한다.
- 공시지가 부분회귀도를 제공하고 전체 모형 잔차 진단과 구분한다.
- 이전 추정 응답·오류·로딩 덮어쓰기를 막고, 어두운 테마 경고와 계수 표 키보드 접근을 개선했다.

**남은 경계**

동일 연결 비지분 표본의 공시지가 사용/미사용 비교, 같은 기준지역 평가 거래의 확장 비교(L-08), 전체 잔차 진단(L-09), 회귀 탭의 모달 제목 변경(L-06), 경고·표 확대·가시성 세부와 남은 조건 검증이 필요하다. 원문: [토지 개선안](LAND_REGRESSION_UX_IMPROVEMENT_PLAN.md).

## 4. 앞으로 수행할 작업

### T-01. 토지 동일 대상 비교 — 미구현 / L-08·WP-4

- 공시지가가 연결된 비지분 거래를 고정해 공시지가 사용/미사용을 비교한다.
- 원래 지역의 평가 거래를 고정하고 양쪽 학습에서 제외한 뒤, 인접지역 추가 전후를 비교한다.
- 평가 목적·분할·최소 표본 기준·평가 불가 처리를 확정하고 구현한다. 작은 표본에서 억지로 CV를 제공하지 않는다.
- **완료 기준:** 같은 평가 관측·분할·척도임을 응답/화면에서 확인하고, 다른 표본 참고 결과와 분리한다.

현재 다른 표본끼리의 비교 제한을 구현한 사실이 이 새 실험의 구현 완료를 뜻하지 않는다. 지분 공시지가 보충은 범위 밖이다.

### T-02. 토지·집합 전체 잔차 진단 — 미구현 / L-09·C-09·공통 주거

- 관측-적합·잔차-적합·이상/영향 거래와 실제 적합 표본 요약을 제공한다.
- 복합의 진단과 같은 의미·단위·경고 원칙을 사용하되 단가/금액과 관측 단위 차이를 유지한다.
- **완료 기준:** 진단에 사용한 모형·표본·관측 식별을 확인하고, 영향도가 자동 제외 근거가 아님을 설명한다.

토지 부분회귀도와 복합 영향 거래 상세는 이미 반영한 별도 기능이다.

### T-03. 경고 정보 구조 — 일부 미구현 / B-01·R-02/06·C-08·L-09

- 소표본·계수당 표본 부족·식별 제한·검증 미제공·외삽·이전 결과를 구분해 핵심 상태와 상세로 배치한다.
- 실제 값과 미달 기준을 함께 표시하고, 반복 경고·용도지역 주의·면책의 중복을 줄인다.
- **완료 기준:** 같은 경고가 반복되지 않고, 중복 제거로 필요한 제한이나 실제 실패 이유가 사라지지 않는다.

상태 데이터·일부 경고는 이미 존재한다. 남은 것은 표시 체계·분모/기준 설명·다음 행동의 정리다.

### T-04. 유형별 UI와 조작 흐름 — 일부 미구현 / M-01/04/05·R-03/04/10·C-07/09/10·L-06/09 등

- 후보별 현재 설정과의 변수/척도 차이와 적용 전 요약을 제공한다. 기존의 ‘설정 반영 후 재실행’ 동작은 유지한다.
- 추가 단지/도로 선택 영역을 접고 선택 수·표본을 요약한다.
- 결과 구역 바로가기·계수 크게 보기와 중첩 스크롤을 정리한다. 이번 키보드 스크롤 수정만으로 표 확대를 완료 처리하지 않는다.
- Macro의 탭 접근 유지, 확인 중인 후보와 기준선 구분, 후보 선택 후 상세 이동·번호 체계를 정리한다.
- 설명형/다른 표본 참고 결과와 상위지역의 세부 안내·입력 배치를 원문 요구와 대조한다.
- 토지 회귀 탭의 모달 제목을 분석 내용에 맞게 수정한다.
- **완료 기준:** 현재 조건·현재 확인 후보·적용 여부가 구분되고, 작은 창에서도 결과를 읽을 본문 공간과 주요 제어가 확보된다.

### T-05. 종단 상태·접근성 QA — 검증 잔여 / WP-8

- 재적합 중 입력 변경·조건 복원, 창 닫기·재열기, 후보 적용과 추정 무효화의 남은 조합을 검증한다.
- 주거 고급 특성 각각/전체·결측·상수·식별 제한, 비주거 상가/공장·추가 도로, 지역회귀 유형/가중/지역 확장, 토지 공시지가/FE/지분 조건을 대조한다.
- 유형별 상세·차트·추정 입력의 100/125/150%·좁은 창·밝음/어둠·Tab/Esc·포커스 복귀·대비를 확인한다.
- **완료 기준:** 통과한 조건과 미검증 조건을 구분하고, 실패는 재현·수정·재검증한다. 공통 셸 형식 변경은 같은 위젯이 있는 5앱에 적용한다.

### T-06. 설명·AI·원문 대응 판정 — 감사 잔여 / WP-7/8

- 활성 화면·도움말·AI context가 같은 대상·단위·척도·표본·현재/이전/미실행 상태를 가리키는지 전수 대조한다.
- 원문 B/M/U/R/RG/C/L 항목별로 완료·부분 완료·미구현·보류와 근거를 확정한다. 이 현황 문서의 유형별 요약만으로 원문 모든 세부 요구를 완료 처리하지 않는다.
- **완료 기준:** 통합 계획 §7.3을 항목별로 판정하고 코드·도움말·검증·문서 범위를 정리한다.

## 5. 검증 실적과 해석 범위

### 5.1 자동 검증

- **백엔드:** 4차 작업에서 관련 185개 테스트를 한 실행에서 통과했다. 이전 109/139/173개를 합산하지 않는다. 기존 Twin 완전적합 fixture의 statsmodels 경고 4개는 남아 있다.
- **프런트:** 5차 기준 15개(복합/공통 10 + 토지 5) 통과. 이전 오류·결과·로딩 보호와 실제 TanStack MutationObserver의 reset 이후 늦은 오류를 포함한다.
- **타입/빌드:** 공통 창 수정 후 5앱 검사를 통과했다. 이후 5차 회귀 표·추정 변경에서는 해당 토지·복합·집합 3앱을 재검사했다. 기존 큰 번들 경고는 남아 있다.
- **이번 현황 문서 작성:** 새 기능 코드 수정이나 전체 테스트 재실행은 하지 않았다. 위 결과는 차수별 실행 기록이다.

### 5.2 실제 API·화면

수치는 당시 로컬 데이터·요청 조건의 관찰값이며 고정 기대값이나 다른 기간의 표본 수가 아니다.

- 모형 서명: 정상 서명 성공, 다른 서명 409를 실제 API에서 확인했다. 토지 공시지가 사례는 적합 25건·지분 제외 347건을 확인했다.
- 복합: 신림동 기본 138건·상위지역 228건, 실제 영향 거래 상세와 기존 Macro/Twin 실행을 확인했다.
- 주거: 관악푸르지오+관악드림(동아) 807건에서 확인값 불러오기, 단일 406건의 5/5 검증, 38건의 최소 40건 부족 사유를 확인했다.
- 비주거: 집합상가의 실제 도로 회귀와 가산디지털1로/2로 집합공장 통합 적합 898건의 도로별 표본/FE를 확인했다.
- 지역회귀: 신림동 학습 31곳과 확장 학습 50곳에서 확대 표본 검증과 원래지역 비교 불가를 구분했다. 별도 관악구 사례에서 학습/분리 검증과 추정 응답도 확인했다.
- 지연·실패: 토지의 12초 응답 역전, Macro 단계별 실패/재시도 및 20초 지연 중 닫기/재열기, 주거·비주거·상위지역·지역회귀의 8초 이전 오류 차단을 확인했다.
- 접근성: 공통 AI 창 5앱의 기본/800×600·배율·테마, 집합 중첩 도움말의 Tab/Esc/포커스, 지역회귀·비주거 계수 표 배율/키보드를 확인했다. 측정한 대비는 해당 영역만의 결과다.

## 6. 진행 순서와 유지할 제약

다음 기본 순서는 **T-01 비교 설계/구현 → T-02 진단 → T-03/04 경고·UI → T-05/06 최종 검증·대응 판정**이다. 복합만 먼저 진행한다면 T-03/04의 복합 항목과 그에 필요한 T-05/06을 별도 묶음으로 처리할 수 있다.

- 기존 Macro를 유지하며 추천2로 대체하지 않는다.
- 토지 지분거래의 공시지가 보강이나 임의 보충을 하지 않는다.

- 공통 형식 수정은 같은 위젯이 있는 토지·복합·집합·임대·지역프로필을 함께 확인한다.
- 기존 다른 작업의 로컬 변경을 보존하고 관련 없는 파일을 함께 커밋하지 않는다.
- 로컬 반영, 테스트/API 검증, 실제 화면 검증, 운영 배포는 별도 상태로 관리한다. 이 문서 작성은 배포 요청이 아니다.
