# AI 화면 설명과 심층 분석 구분 — 후속 과제

2026-10-28 합의. 이번 잔차 진단 UI 작업에서는 기록만 하며 AI 프롬프트·실행 정책은 변경하지 않습니다.

## 화면 설명 — 기본 응답

- 현재 화면에서 실제 계산한 사실 3~5개와 짧은 결론을 자연스러운 존댓말로 설명합니다.
- 오차 방향, 오차가 큰 구간, 확인된 집단 차이, 주요 영향 거래를 우선합니다. 값이 없는 항목은 생략합니다.
- 내부 코드와 전문 용어는 쉬운 표현으로 바꾸고 필요한 용어만 짧게 풀이합니다.
- 확인된 결과와 해석의 한계를 구분합니다. 새로운 실험·모형 개선 연구계획은 기본 요약에 덧붙이지 않습니다.
- 화면에 없는 계산이나 실행하지 않은 실험을 수행한 것처럼 설명하지 않습니다. 적합 표본 안의 진단을 새로운 거래의 예측 성능으로 표현하지 않습니다.

## 심층 분석 — 사용자가 요청할 때

잔차 원인, 통계적 한계, 모형 개선 가능성을 검토하되 실제 확인된 사실과 가설·제안을 분명히 구분합니다. 추가 계산이 필요하면 아직 수행하지 않았음을 밝힙니다. 화면 설명 요청만으로 분석 실행이나 모형 변경을 시작하지 않습니다.

## 지표 의미 보존

오차율은 `(실제금액 − 예측금액) / 실제금액 × 100`입니다. 음수는 높게 추정한 방향입니다. 평균 오차는 오차율의 평균이며 과대 추정 거래 비율을 뜻하지 않습니다.

현재 잔차 표의 분위별 절대오차율은 **중앙값**입니다. 집단별 ‘오차율 차이’도 해당 집단과 나머지 거래의 **오차 중앙값 차이**입니다. 이를 평균 절대오차율이나 평균 차이로 바꾸어 설명하지 않습니다. 집단의 통계적 차이 여부는 기존 검정 결과를 따르며 인과적 효과로 단정하지 않습니다.

## 후속 완료 기준

대표 화면 요약에서 분량·쉬운 용어·지표 의미·미실행 계산 구분을 확인합니다. UI 잔차 계산이나 새로운 통계 기능 개발로 범위를 확장하지 않습니다.
