# 청주 가격 마트 우선 6개 — 원천 및 객체 키 검토

2026-10-05. [주소 조합 영향 측정](CHEONGJU_ADDRESS_PAIR_IMPACT_RESULT.md)에서 가격 마트가 거래 미관측 통계 PNU를 사용하는 6개 키를 원본과 대조했다. 로컬 읽기 전용 검토와 수정 제안 큐이며, 기존 객체 키·가격·건물 속성·회귀는 변경하지 않았다.

## 핵심 발견

**가격 숫자는 원본과 일치하지만, 가격을 붙이는 객체의 범위를 먼저 검토해야 한다.**

6개 모두 가격 마트의 PNU·2026년 기준연도·가격이 충북 개별공시지가 원본 CSV에서 재현됐다. 숫자 파싱 오류를 발견한 것이 아니다. 해당 필지의 가격이 원본에 있다는 사실은 그 필지가 해당 집합 객체에 속한다는 증거가 아니다.

6개 모두 같은 건물명으로 서로 다른 법정동의 거래가 하나의 `building_key`에 들어간다. 아파트 2개 키는 각각 3개 법정동, 나머지 4개는 각각 2개 법정동이다. 현재 `derive_building_key`로 각 거래 주소 그룹의 키를 계산하면 기존 키가 모두 재현된다.

이름이 있는 키는 `asset_type + addr1 + addr2 + addr3 + building_name`을 사용한다. 이번 거래에서 `addr3`는 구이고 `addr4`는 동이다. 동·법정동 코드·지번이 이름 키에서 빠져, 같은 구 안의 동명이 다른 건물이 합쳐질 수 있다. 이름 키를 같은 물리적 단지로 인증해서는 안 된다.

## 아파트 3개

- **case-1:** 흥덕구, 278거래, 3개 법정동·3개 관측 PNU. 기존 보강은 T등급이다. 관측 주소 중 하나에는 K-apt 원문 단지 코드가 있고, 나머지 주소에도 별도 표제부 건물명이 있다. 미관측 통계 PNU의 최신 원본 표제부는 이름이 없는 단독주택 1개다. 그 표제부를 아파트 단지 구성으로 승격하지 않는다.
- **case-2:** 상당구, 690거래, 3개 법정동·3개 관측 PNU. 각 관측 PNU가 서로 다른 **K-apt 단지 코드 3개**를 가리키며, 기본정보 원문의 단지명·법정동주소도 확보했다. 기존 C등급은 그중 한 단지에 연결돼 있다. 하나의 가격·단지 속성을 전체 묶음에 적용하기 전에 객체 분리 범위를 검토해야 한다. 미관측 PNU는 최신 전국 표제부에서 발견되지 않았다.
- **case-3:** 흥덕구, 132거래, 2개 법정동·2개 관측 PNU. 관측 주소에 **K-apt 단지 코드 2개**가 있고 원문 기본정보를 확인했다. 기존 C등급은 그중 한 단지에 연결돼 있다. 미관측 PNU의 최신 원본 표제부는 이름이 없는 단독주택 1개다.

K-apt PNU는 대표 주소 관측이다. 전체 대지 목록이나 모든 거래의 단지 소속을 인증하지 않는다. K-apt 코드가 여러 개라는 이유만으로 기존 키를 자동 분할하지 않았다.

## 연립다세대 3개

- **case-4:** 흥덕구, 3거래, 2개 법정동·2개 관측 PNU. 기존 T등급이다. 양쪽 실제 주소의 원본 건물명은 거래명과 연결되는 근거가 있지만 물리적으로 한 객체라는 인증은 없다. 미관측 PNU는 최신 전국 표제부에 없었다.
- **case-5:** 상당구, 5거래, 2개 법정동·2개 관측 PNU. 기존 T등급이다. 두 주소에는 각각 표제부 건물명이 있으며, 미관측 PNU에는 이름이 없는 단독주택 1개가 있었다.
- **case-6:** 흥덕구, 4거래, 2개 법정동·2개 관측 PNU. 기존 건물 속성 보강행이 없다. 양쪽 실제 주소에는 거래명과 대응하는 표제부가 있으며 미관측 PNU는 최신 전국 표제부에 없었다.

T등급 보강의 개별 원천 관리 PK가 이번 기존 속성행에 저장돼 있지 않으므로, 최신 동주소 표제부만으로 과거 T 적재의 출처를 확정하지 않았다. 최신 원본에 없는 3개의 주소도 멸실·과거 건물 부재로 해석하지 않는다.

## 수정 제안 큐

6개를 모두 `review_required`로 남겼다. 제안 순서는 **객체 키의 관측 주소별 묶음 검토 → 실제 단지/건물 소속 확인 → 대표필지 선택 → 공시지가·건물 속성 재공급 → 통계·회귀 병행 비교**다. 대표 PNU 하나만 교체해 혼합 객체 문제를 숨기지 않는다.

관측 주소별 검토 파티션은 아파트 3·3·2개, 연립 2·2·2개로 총 14개다. 이 파티션은 조사용 후보이며 새 객체 키가 아니다. 거래수 합계 1,112건을 보존하고 기존 대표필지·가격을 기준값으로 포함했다. 후보마다 원본 표제부 관리 PK와 K-apt 코드, 원천 근거 해시를 연결했다. 신규 대표 PNU와 신규 객체 키는 모두 null, 운영 적용은 false다.

식별자가 있는 근거와 큐는 로컬 연구 폴더에만 저장했다.

- `data/research/cheongju_ledger/priority_price_mart_source_evidence.json.gz`
- `data/research/cheongju_ledger/priority_price_mart_review_queue.json.gz`

식별자 없는 [집계 결과](lab/cheongju_priority_price_mart_source_review.json), [검토 코드](../pipeline/parcel_master/audit_cheongju_priority_price_mart.py), [검토 게이트 테스트](../pipeline/parcel_master/test_priority_price_mart_review.py)를 함께 남겼다.

## 검증과 경계

최신 전국 표제부의 전체 해시·행수를 이전 검사와 대조하고, 관련 20개 PNU의 원문·처리 표제부를 비교했다. 충북 공시지가 CSV, K-apt 대표필지·기본정보 XLSX, 청주 4개 구 토지특성 DBF 원문을 해시와 함께 보존했다. 개별공시지가 원문과 토지특성 원문은 서로 다른 출처·관측일이며 같은 시점으로 합치지 않았다.

신규 가격·키 검토 테스트 8개와 기존 검증 37개, **총 45개가 통과**했다. 가격 원문 6개 재현, 기존 이름 키 재현, K-apt 기본정보 원문 확보, 원본 표제부 PK 유일성·처리 PK의 원본 존재, 이전 주소 감사 근거 유지, 새 대표필지·운영 적용 없음, 검토 파티션 거래수 보존을 검사했다.

각 DB는 로컬 `REPEATABLE READ` / `READ ONLY`로 읽었다. 두 DB의 스냅샷은 별도이며 운영 VPS 감사나 과거 적재 실행 로그 재구성이 아니다. 최신 원문 대조는 독립적인 거래·단지 소속 인증을 대체하지 않는다.

원천 검토를 반복 실행해 사례 근거 내용 SHA-256이 동일함을 확인했다. 최종 큐의 6행·14개 파티션·1,112거래와 미할당 상태를 별도로 검사했으며 [검증 기록](lab/cheongju_priority_price_mart_verification.json)에 남겼다.

비주거는 도로명 군집이고 같은 대표 PNU 가격 마트가 없다. [이전 주거·비주거 주소 조합 감사](CHEONGJU_ADDRESS_PAIR_IMPACT_RESULT.md)의 비주거 306개 결과를 유지한다. 주거 키의 분할안을 비주거 군집에 그대로 적용하지 않는다.

## 다음 실행 단위

청주 전체 이름 키의 **서로 다른 법정동·단지 코드가 섞인 범위**를 측정한다. 검증된 하나의 단지가 여러 필지에 걸친 경우와 이름만 같아서 합쳐진 경우를 분리한 뒤, 주소 쌍·객체 식별자 보존 선택기를 병행 실험한다. 정책·이관·복구 조건 확정 전에는 기존 키나 제품 보강을 전환하지 않는다.
