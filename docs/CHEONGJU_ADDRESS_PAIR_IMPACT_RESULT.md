# 청주 집합 주소 조합 오류 — 전체 영향 측정

2026-10-05. 로컬 `collective_stats`의 읽기 전용 감사다. 운영 VPS 검증이나 제품 선택기 교체가 아니다. 기존 대표필지·가격 마트·집계·회귀는 수정하지 않았다.

## 결과

아파트·오피스텔·연립다세대 **1,381개 키 중 27개(1.96%)**에서 통계 주소의 법정동·지번 쌍이 해당 기간의 유효 거래에 존재하지 않았다. 아파트 16개, 오피스텔 1개, 연립다세대 10개다. 분양권 90개도 추가 검사했으며 1개를 발견했다. 전체 1,471개 중 28개(1.90%)다.

미관측 주소 28개는 모두 엄격히 PNU로 해석할 수 있지만, 그 PNU는 해당 기간 거래 주소 후보에도 없었다. 모든 대상에서 법정동과 지번의 **각각의 PostgreSQL MAX가 저장 주소를 재현**했다. 이전 조사에서 발견한 충돌 4개도 그대로 재현됐으며, 그중 3개의 주소 조합 부재를 다시 확인했다. 이번 결과는 특정 가격 마트 충돌 사례에 한정되지 않는다.

## 공시지가 마트에 노출된 범위

미관측 주소 28개 중 가격 마트가 있는 키는 9개다.

- **6개:** 가격 마트 PNU가 미관측 통계 주소의 PNU와 같다. 아파트 3개·연립다세대 3개이며, 상당구 2개·흥덕구 4개다. 모두 가격 기준연도는 2026년이다. 먼저 원천 주소와 실제 단지 소속을 검토할 대상이다.
- **3개:** 가격 마트는 거래에서 관측된 다른 PNU를 유지하고 있다. 이전 조사에서 주소 생성 오류가 확인된 3개와 일치한다. 기존 PNU가 물리적 대표필지로 독립 인증됐다는 뜻은 아니다.
- 나머지 **19개:** 가격 마트가 없다. 분양권 1개가 포함된다.

우선 대상 6개 키의 최장기간 거래수 합계는 1,112건이다. 이는 해당 키의 검토 범위이며 오매칭 거래 1,112건이나 가격 오차를 뜻하지 않는다. 실제로 존재하는 다른 필지의 가격이 연결됐는지, 대표필지 근거가 따로 있는지 추가 검토해야 한다. 이번에는 가격을 삭제하거나 대표필지를 자동 교체하지 않았다.

## 범위와 분모

청주 4개 구 코드에 걸리는 거래 키와 저장 통계 키를 합쳐 대상으로 정했다. 각 키의 최신 `as_of_month`에 저장된 **3·5·7년 모든 기간**을 검사했다. 같은 키에 연결된 청주 밖 거래도 자르지 않았다.

주거·분양권 통계 3,964행에서 미관측 주소는 **67행·고유 28개 키**다. 기간별로 3년 17행, 5년 22행, 7년 28행이며 기간별 수치를 더해 고유 오류 건수로 사용하지 않는다. 최신월·최장기간 한 행 선택은 기존 가격 마트 조회와 같은 방식이다.

최장기간 기준 구별 전체 키/미관측 주소는 상당구 385/7, 서원구 310/4, 흥덕구 491/13, 청원구 285/4다. 이 분모에는 분양권이 포함된다. 각 키의 최신 판본은 대부분 2026-09-01이며 연립다세대 1개는 2026-08-01이다. 따라서 동일한 전역 기준월의 전체 시장 오류율로 표현하지 않는다.

복수의 해석 가능한 PNU가 있는 키는 분양권 포함 74개다. 복수 주소만으로 잘못된 단지 키라고 확정하지 않는다. 엄격히 해석되지 않는 통계 주소는 13개로 아파트 1개·분양권 12개이며, 블록·로트 문자열을 임의 지번으로 바꾸지 않았다.

## 비주거 집합

도로명 군집 **306개 키·754개 기간 통계**를 함께 검사했다. 상가 295개·공장 11개다. 현행 생성기가 사용하는 주소 1~4와 군집 도로명의 다섯 필드를 하나의 관측 조합으로 대조했으며, 미관측 조합은 발견되지 않았다. 모든 행에서 개별 필드 MAX가 저장값을 재현했다.

비주거 분석 단위는 도로명 군집이므로 여러 필지가 있는 것을 단지 대표필지 오류로 해석하지 않는다. 이 결과는 군집 주소 다섯 필드의 관측 일관성 확인이며, 군집 구성의 물리적 정확도나 공시지가 공급을 인증하지 않는다.

## 검증 및 재현

- 신규 분류 테스트 9개와 기존 건물·관계·소비 입력 테스트 28개, **총 37개 통과**.
- 오류 67개 통계행을 별도 직접 SQL로 조회해 거래수·법정동 MAX·지번 MAX·주소 쌍 부재가 모두 일치함을 확인.
- 최종 감사를 반복 실행해 쿼리 입력 해시와 정규화 근거 내용 해시가 동일함을 확인.
- 이전 후보·대표필지 근거 gzip 파일의 SHA-256 유지, 새 대표필지 할당 없음, 통계 ID 유일성, 구별 분모 합계 확인.
- 두 도메인은 동일한 `REPEATABLE READ` / `READ ONLY` 트랜잭션에서 조회. 현재 입력에서는 저장 거래수와 조회 거래수의 차이가 없었다.

잘못 선택된 전국 정렬 인덱스 스캔 때문에 초기 조회가 60초 제한을 초과했다. `EXPLAIN`으로 확인한 뒤 감사 트랜잭션에서만 `SET LOCAL enable_mergejoin=off`를 적용했다. 최종 실행에서 주거 조회 두 개는 약 6.5초·7.3초, 비주거는 0.4초·1.9초였다. 서버 설정·제품 핫패스·인덱스는 변경하지 않았다.

## 다음 실행 단위

우선 가격 마트가 미관측 통계 PNU를 사용하는 6개의 원천 근거를 조사한다. 실제 함께 관측된 주소 쌍, 기존 가격 마트 출처, 건축대장·단지 소속을 대조해 수정 제안 큐를 만든다. 가격 존재나 거래수만으로 대표필지를 선택하지 않는다.

그다음 나머지 미관측 주소와 복수 주소 키의 정책을 검토하고 주소 쌍을 보존하는 선택기를 병행 실험한다. 공통 정책·이관·복구 조건 확정 전에는 제품 통계와 보강을 전환하지 않는다.
