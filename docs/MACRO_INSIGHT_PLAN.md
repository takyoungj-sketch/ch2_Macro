## 0. 한 줄

게이트웨이 **Macro Insight**는 분석 앱이 아니다. **질문 목록(FAQ)** 이다.

사용자는 주제를 골라 들어간다. 그 안에 (1) 우리가 시장에 물어본 **실험의 방법·숫자·한계·다음에 할 실험**과 (2) 제품이 이미 제공하는 **기능을 어디서·어떻게 쓰는지**가 같이 올 수 있다.

관리자(`/lab/`) 실험 전부를 옮기지 않는다. 제품 화면의 `?` 도움말을 통째로 복제하지도 않는다. 선별한 질문만 올린다.

목록 초안은 §3.1. 창·카드는 2026-09-16에 달았고, 공개 목록에는 본문이 있는 `#1`·`#2`·`#3`·`#4`·`#5`·`#6`만 올린다. 빈 번호 칸은 진열하지 않는다.

## 1. 왜 독립 창인가

| 창 | 하는 일 | 하지 않는 일 |
|----|---------|--------------|
| 토지·복합·집합·임대 | 한 시장을 **분석**한다 | 시장 일반 법칙을 선언하지 않음 |
| 지역프로필 | **이 지역**은 지금 어떤가 | 전국 실험 기록, 기능 FAQ 목차 |
| **Macro Insight** | 시장에 **무엇을 물어봤는가**, 그리고 그 기능을 **어디서 어떻게 보나** | 이 지역의 시세, 투자·전망, BOK 뉴스판, 실시간 분석 엔진 |
| 관리자 `/lab/` | 실험·검증·실패 포함 **전부** | 공개 게이트웨이 카드가 아님 |

프로필·분석 앱 안에 Insight 문장을  squirt하지 않는다. 한 지역 화면의 결론처럼 읽히기 때문이다. D-055의 「지역 단면」과 「전국 시계열」도 Insight 안에서 **다른 질문**으로 둔다.

`/lab/`을 게이트웨이에 노출하지 않는 규칙([CH2_ENTITLEMENT.md](./CH2_ENTITLEMENT.md))은 유지한다. Insight는 **랩의 공개본 + 제품 사용 예시**이지 랩 자체가 아니다.

## 2. 두 결 · 두 층

질문의 결은 둘이다. 목록에서 섞어 나열해도 되고, **한 질문 본문**에는 결을 섞지 않는 것을 기본으로 한다. 예외는 §3.1 #1처럼 실험이 본문이고 「제품에서 같은 숫자를 보는 곳」을 짧은 링크로만 붙이는 경우.

| 결 | 본문에 있는 것 | 예 |
|----|----------------|----|
| **실험 기록** | 질문, 방법, 결과, 한계, **추가 실험 예정** | #1 유동성과 부동산 |
| **기능 예시** | 질문, 사용 경로(앱·모달·탭), 산식 설명, 한계. 실험 숫자는 있을 때만 | #9 층별효용지수, #16 쌍둥이·트윈회귀 |

층:

```
관리자 실험  (/lab/?tool=…)     ──┐
제품 화면 (모달·탭·고정 카피)  ──┼→ 공개 여부 판단 (§4)
                                   → Macro Insight FAQ 목록
                                       → 질문 페이지
                                           → 게이트웨이 6번째 카드
                                             (공개 주제가 1개 이상일 때만)
```

| 층 | 누구 | 내용 |
|----|------|------|
| **실험** | 운영·개발 | 가설, 실패, 문턱 장난, 스냅샷, 미완 마트, 내부 메모 |
| **공개** | 감정평가사·일반 | 선별된 질문, 재현 가능한 방법 또는 제품 경로, 화면 숫자, 한계, (실험이면) 다음 실험 |

실험이 실패해도 랩에는 남긴다. 공개할지는 **별 판단**이다. 「실패 = 공개 금지」가 아니다. 「아직 질문이 서 있지 않음 / 표본이 안 됨 / 결이 섞임 / 제품 경로가 없음」이면 올리지 않는다.

## 3. 입구 — 질문이 버튼이다

주제 라벨이 아니라 **한 줄 질문**이 문이다. FAQ처럼 **여러 개**를 나열한다. 사용자는 원하는 주제에 들어가 실험 결과와 사용 예시를 본다.

하면 됨:

- 「유동성·금리의 변화는 전국 부동산 거래와 어떻게 같이 움직였는가?」
- 「층별효용지수는 어떤 식으로 산출되나?」
- 「쌍둥이 지역과 트윈회귀는 무엇을 보나?」
- 짧은 부제: 결(실험 / 기능) · 관련 앱

하면 안 됨:

- 「유동성 인사이트」
- 「유형별, 행정체급별 거래액 관계」
- 목록에서 「검증됨 / 관계 있음 / 성공」

목록 옆 상태는 관계의 판정이 아니다.

| 상태 | 뜻 |
|------|----|
| **실험함** | 이 창에 방법·숫자·한계가 있다 |
| **제품에 있음** | 기능 예시. 앱에서 재현 가능한 경로·산식 설명이 있다 |
| **실험 전** | 질문은 적어 두었으나 마트·실험·카피가 없다. **본문 없음** (접거나 숨김) |
| **표본 부족** | 실험은 했으나 남은 점이 적어 읽지 말라고 적는다 |

「관계 없음」도 목록 배지로 쓰지 않는다. 그건 본문 숫자가 말한다.

같은 결의 실험(유형 쌍 28개 등)을 28개 문으로 쪼개지 않는다. 본문에서 체급·쌍을 고른다. FAQ **전체 개수**는 5~7에 묶지 않는다. 기능 예시가 늘면 목록이 길어진다.

## 3.1 질문 목록 초안 (번호는 초안, 확정 아님)

지금 공개 목록에는 본문이 있는 `#1`·`#2`·`#3`·`#4`·`#5`·`#6`만 올린다. 번호 사이(7–8, 10–15 등)는 **나중에 채운다.** 빈 번호를 화면에 진열하지 않는다. #9·#16은 이 문서 초안이다.

### #1 유동성·금리의 변화는 전국 부동산 거래와 어떻게 같이 움직였는가?

- **결:** 실험 기록 (G3) · **구현 SSOT** [`MACRO_INSIGHT_01.md`](./MACRO_INSIGHT_01.md)
- **들어가면:** 전제 → 수준 패널(입구) → 왜 YoY인가 → YoY 실험 → 건수·거래액 r 표 → 특징 → 한계. 월·전년동월만. 합계는 토지 가중. 인과 아님.
- **지금:** `/insight/?q=1`. 랩 `?tool=g3`는 실험실.

### #2 같은 지역에서 유형은 함께 커지고, 가격 수준도 함께 움직이는가?

- **결:** 실험 기록 (D-058, 공간 단면) · **구현 SSOT** [`MACRO_INSIGHT_02.md`](./MACRO_INSIGHT_02.md)
- **들어가면:** ① 규모 8×8 히트맵(셀→산점도, 원래/인구 보정) → ② 패턴 요약(해석이 숫자보다 앞) → ③ 규모·건수 차이 카드 → ④ 단가 7×7 → ⑤ 시군구 내부는 접기 → 한계. 구성비 8×8 없음. 시계열 아님. 인과·동조 아님.
- **한 결:** 규모와 단가를 **한 표에 섞지 않는다.** 문은 하나. 위계는 ①이 메인.
- **지금:** `/insight/?q=2`. 랩 `?tool=size`는 실험실.

### #3 같은 연립·다세대에서, 윗층은 1층보다 비쌀까?

- **결:** 실험 기록 (연립·다세대 층×승강기) · **구현 SSOT** [`MACRO_INSIGHT_03.md`](./MACRO_INSIGHT_03.md)
- **들어가면:** 리드 → ① 표본 → ② 승강기 나누기 전 → ③ 나눈 뒤(1층=100 표) → ④ 그룹 표 → ⑤ 건물 사이 수준은 다른 질문 → 그림 세 줄 → 한계 → 다음. 전국 한 %를 제목으로 쓰지 않음. 제품 층 식 미변경.
- **한 결:** 건물 **안** 층 비교가 본체. 건물 사이 +26%를 13.5%에 더하지 않음. #9 아파트 단지 지수와 문을 섞지 않음.
- **지금:** `/insight/?q=3`. 랩 `?tool=rowhouse-floor`는 실험실.

### #4 같은 시군구·같은 지목에서, 큰 땅은 ㎡당 가격이 다를까?

- **결:** 실험 기록 (토지 면적×단가) · **구현 SSOT** [`MACRO_INSIGHT_04.md`](./MACRO_INSIGHT_04.md)
- **들어가면:** 리드 → ① 표본(광평=칸 안 P90) → ② 섞으면 → ③ 지목·체급 교차표 → ④ 같은 동 → ⑤ 초소형은 다른 질문 → 그림 세 줄 → 한계 → 다음. 전국 −20%를 제목으로 쓰지 않음. 제품 토지 회귀 식 미변경.
- **한 결:** **칸 안** 상대적 대형 vs 몸통이 본체. 초소형과 한 표에 더하지 않음. 토지 회귀 면적 계수와 문을 섞지 않음. 「대지는 클수록 비싸다」로 읽히면 안 됨.
- **지금:** `/insight/?q=4`. 랩 `?tool=area-elasticity`는 실험실.

### #5 부동산 거래액은 경제 규모와 비교하면 얼마나 클까?

- **결:** 실험 기록 (연 규모·구성) · **구현 SSOT** [`MACRO_INSIGHT_05.md`](./MACRO_INSIGHT_05.md) · 랩 [`lab/MACRO_ANNUAL_SCALE_LAB.md`](./lab/MACRO_ANNUAL_SCALE_LAB.md)
- **들어가면:** 리드 → ① 분모 세 개 → ② 총액 4선(부동산·GDP·M2·주식, 각각) → ③ 비율 3선 → ④ 8유형 거래액 구성비 → ⑤ 같은 해 r(수준·전년대비) → ⑥ 유형/GDP는 접기 → 한계 → 다음 실험(M2 상품×유형) · 관련(#1). 완결 연만. 「부동산이 GDP의 ○○%」금지. 원 금액 이중축 아님. 월 시차 r는 1번.
- **한 결:** **연·수준비·구성.** #1의 월·전년동월·상관과 문을 섞지 않는다. M2는 같은 시계열이어도 여기서는 분모(잔액)다. G3 탭으로 붙이지 않는다.
- **지금:** `/insight/?q=5`. 랩 `?tool=macro-scale`는 실험실.

### #6 도로 지목 토지의 거래단가는 비교 지목 토지의 몇 % 수준인가?

- **결:** 실험 기록 (토지 지목 상대가격) · **구현 SSOT** [`MACRO_INSIGHT_06.md`](./MACRO_INSIGHT_06.md) · 랩 [`lab/LAND_ROAD_JIMOK_RATIO_LAB.md`](./lab/LAND_ROAD_JIMOK_RATIO_LAB.md)
- **들어가면:** 같은 읍·면·동, 같은 용도에서 지목 도로 ㎡당 가운데 / 비교 지목 가운데. 동네별 비율을 모은 뒤 그 가운데. 주거 대지·녹지 대지·계획관리 대지·밭·논을 나눈다. 도시 전체 하나의 퍼센트는 쓰지 않는다. 1/3은 눈금이고, 틀렸다고 단정하지 않는다. 도시 밖 회귀는 단순 비교와 다른 종류의 참고값이다. 연도별 표·주거/녹지 각각의 회귀는 아직 본문 밖.
- **한 결:** 비교 대상에 따라 수준이 다르다. 지목 할인율·평가상 도로가 아니다. 제품 토지 식 미변경.
- **지금:** `/insight/?q=6`. 랩 `?tool=road-jimok`는 실험실.

### #9 층별효용지수는 어떤 식으로 산출되나?

- **결:** 기능 예시 (집합)
- **들어가면:** 집합 **주거**에서 특정 단지를 연 뒤 **심층분석 모달** → **층·동·면적 효용지수** 탭과 **회귀분석** 탭이 같은 회귀로 지수를 만드는 경로. 기준 칸=100, 면적·연식·시점 통제, 표의 평균(원자료)과 지수가 다를 수 있음. 게이트 n(효용지수 n≥50, 회귀 권장 n≥30). 적정가가 아님.
- **비주거**는 분석 단위가 단지가 아니라 **도로명 cluster**. 같은 질문 본문에서 주거/비주거 경로를 구분해 적는다 (형식 패리티, 단위만 다름).
- **산식 카피 SSOT 후보:** 화면 `FloorIndexMethodGuide` · 설명 헌법 `floor_utility_index`. Insight 문장이 화면 `?`와 어긋나면 화면을 따른다.
- **지금:** 공개 화면 **비움.** 제품에 있음.

### #16 쌍둥이 지역과 트윈회귀는 무엇을 보나?

- **결:** 기능 예시 + (선별) 실험 기록
- **들어가면:** 제품에서 Twin을 **어디서** 돌리는지(복합 Macro 탐색 ③ Twin1 · ④ Twin2 · ⑤ 비교. 집합이 같은 스토리면 같이). Twin1 = Local 식·척도 고정 + 쌍둥이 **1위** 표본 + 지역 더미 (D-073). Twin2 = 같은 1위 표본에서 식 재탐색(확인용). 후보는 가격이 아니라 구성·체급 (D-066). Twin이 이겨도 기본 통계 식을 덮지 않음.
- **실험에서 고를 수 있는 것:** 관리자 거리 실험(`?tool=twin`)·모형추천 벤치(`?tool=recommend-twin`)의 **선별** 결과·한계. 랩 탭 전체를 공개 FAQ로 옮기지 않는다.
- **지금:** 공개 화면 **비움.** 제품 Twin1/Twin2는 있음.

이후 질문이 생겨도 입구는 한 줄 질문이다. 결이 다른 질문은 **다른 문**이다.

## 4. 공개 게이트 (올리는 조건)

하나라도 안 되면 랩(또는 제품 `?`)에만 둔다.

### 4.1 실험 기록

아래를 **모두** 통과해야 한다.

1. **질문이 한 결이다.** 공간 단면과 시계열, 규모와 단가, 전국 거시와 지역 r을 한 페이지에 섞지 않는다. (D-055)
2. **재현된다.** as_of, 체급, 변수, 산식이 랩 API(또는 스냅샷)와 같고, 손으로 고친 r가 본문에 없다.
3. **한계가 본문에 있다.** n 붕괴, 양수 표본, 인구 보정 범위, 인과 금지를 숨기지 않는다. **다음에 할 실험**도 같은 구역에 적는다. 예정 실험을 이미 한 것처럼 쓰지 않는다.
4. **해석 문장이 실험 때 고정됐다.** 요청 시 LLM이 「무엇을 알 수 있나」를 새로 쓰지 않는다. ([설명 헌법](./CH2_EXPLAIN_CONSTITUTION.md) `?` 1차)
5. **문턱·배지가 제품 결론이 아니다.** 랩의 실험용 문턱을 「동조 기준」으로 올리지 않는다. (D-058)
6. **지금 숫자가 약해도, 질문이 서 있으면** 공개 후보다다. 다만 **오독이 기본이 되는 표**(구성비 합=1 행렬 등)는 올리지 않는다.

### 4.2 기능 예시

아래를 **모두** 통과해야 한다.

1. **제품 화면·산식과 같다.** Insight 카피가 앱 `?`·고정 가이드와 다르면 앱을 고치거나 Insight를 고친다. 둘을 다르게 두지 않는다.
2. **사용 경로가 본문에 있다.** 어느 앱, 어느 모달, 어느 탭인지. 공개 URL은 `/built/` · `/collective/` 등 **제품**이다. `/lab/`을 사용 경로로 쓰지 않는다.
3. **한계·게이트가 본문에 있다.** n 문턱, 기준=100의 뜻, 적정가 아님, Twin은 구조 후보이지 가격 후보가 아님 (D-066).
4. **해석을 LLM이 새로 쓰지 않는다.**
5. **실험 숫자를 붙이면** §4.1도 통과해야 한다. 기능 설명만이면 랩 스냅샷은 없어도 된다.

올리지 않음 (지금):

- D-058 시장 규모 랩 전체 — 장기 실험. 1차는 「규모는 인구·체급, 단가는 시군구 사이 입지」힌트이나 **공개 문장으로 고정하지 않음**. 목록 번호도 아직 없음
- G3 **공개 r 표** — 1번 구현은 [`MACRO_INSIGHT_01.md`](./MACRO_INSIGHT_01.md). 화면은 아직 비움. 연·월 합 대조는 한계에 남김
- 관리자 전용 도구 그 자체(검증로봇, 전환율 연구 원장, 대장DB, AI 사용량). Twin **거리 랩 전체**도 아님. #16은 제품 Twin 경로 + 선별 실험만
- 신규아파트·시공사·연식=0 랩 — 제품 식이 바뀌기 전에는 기능 예시 번호로 올리지 않음

## 5. 질문 페이지 템플릿

공개 페이지는 결마다 뼈가 조금 다르다. 성공/실패 도장 없음.

### 5.1 실험 기록

랩 `?`(방법·한계·의미)를 옮긴다.

| 구역 | 내용 | 출처 |
|------|------|------|
| **질문** | 한 줄 + 한 문장 설명 | 고정 카피 |
| **실험 방법** | 대상 · 기간 · 공간 단위 · 변수 · 통계 | 고정 카피. 산식은 CH2가 쓰는 것 |
| **결과** | 숫자 · 표 · 산점도. 체급 스위치 | **API / 스냅샷만** |
| **무엇을 알 수 있나** | 짧은 해석. 체급이 달라지면 같이 적음. **쉬운 말.** 논문 문체 아님 | 실험 확정 시 고정 카피. AI 생성 금지 |
| **한계** | 별 구역. 인과 금지, 표본, 해상도 | 고정 카피 + 화면에 보이는 n |
| **추가 실험 예정** | 랩 「이어서」와 같게. 아직 없는 숫자를 넣지 않음 | 고정 카피 |
| **관련 기능** (선택) | 제품에서 같은 주제를 보는 짧은 링크 | 제품 경로만 |

### 5.2 기능 예시

| 구역 | 내용 | 출처 |
|------|------|------|
| **질문** | 한 줄 + 한 문장 설명 | 고정 카피 |
| **어디서 보나** | 앱 · 대상(단지/cluster/지역) · 모달 · 탭 | 고정 카피. 딥링크는 제품 |
| **어떻게 계산하나** | 산식·기준(100)·통제 변수·게이트 | 화면 `?` / 가이드와 **동일** |
| **예시** | 한 단지를 고르는 수준의 사용 경로. 실시간 시세 계산 아님 | 고정 카피. 스크린 숫자는 스냅샷이 있을 때만 |
| **한계** | n, 적정가 아님, 주거/비주거 단위 차이 등 | 고정 카피 |
| **관련 실험** (선택) | 랩에서 같은 주제를 더 본 선별 결과 | §4.1 통과분만 |

AI는 다른 앱과 **같은 헤더 버튼 하나**다. 이 페이지를 보고 **추가 질문**할 때만 쓴다. 숫자를 재계산하지 않고, 실험의 결론을 지어 주지 않는다. ([AI 헌법](./CH2_AI_CONSTITUTION.md) Facts First · No Recalculation)

공개 본문은 논문이 아니다. 통계 기초만 있는 사람이 훑어 읽히게 쓴다. **실험 기록이지 결론이 아니다.** 같은 질문에 실험을 더하면 본문이 늘어날 수 있다. 물음표가 1차, AI가 2차 설명이다. 1번 말투·버튼·거절은 [`MACRO_INSIGHT_01.md`](./MACRO_INSIGHT_01.md) §1·§8.
