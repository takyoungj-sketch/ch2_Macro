## 0. 한 줄

관리자(`/lab/`)에서 시장 질문을 실험하고, 그중 **공개해도 되는 것만** 게이트웨이 **Macro Insight**에 질문 목록으로 올린다.  
정답을 압축하지 않는다. 「무엇을 물었고, 어떻게 봤고, 무엇이 나왔으며, 한계는 무엇인가」를 그대로 공개한다.

지금(2026-09-05) 랩 실험은 **유의미한 공개 주제가 거의 없다.** 당분간은 랩만 돌리고, 이 창은 비워 둔다.

---

## 1. 왜 독립 창인가

| 창 | 하는 일 | 하지 않는 일 |
|----|---------|--------------|
| 토지·복합·집합·임대 | 한 시장을 **분석**한다 | 시장 일반 법칙을 선언하지 않음 |
| 지역프로필 | **이 지역**은 지금 어떤가 | 전국 실험 기록, 한 지역 시계열 거시 r |
| **Macro Insight** | 우리가 부동산 시장에 **무엇을 물어봤는가** | 이 지역의 시세, 투자·전망, BOK 뉴스판 |
| 관리자 `/lab/` | 실험·검증·실패 포함 **전부** | 공개 게이트웨이 카드가 아님 |

프로필 안에  squirt하지 않는다. 한 지역 화면의 문장처럼 읽히기 때문이다. D-055의 「지역 단면」과 「전국 시계열」도 Insight 안에서 **다른 질문**으로 둔다.

`/lab/`을 게이트웨이에 노출하지 않는 규칙([CH2_ENTITLEMENT.md](./CH2_ENTITLEMENT.md))은 유지한다. Insight는 **랩의 공개본**이지 랩 자체가 아니다.

---

## 2. 두 층

```
관리자 실험  (/lab/?tool=…)
    → 공개 여부 판단  (이 문서 §4)
        → Macro Insight 질문 페이지  (고정 카피 + CH2가 계산한 숫자)
            → 게이트웨이 6번째 카드  (베타, 공개 주제가 1개 이상일 때만)
```

| 층 | 누구 | 내용 |
|----|------|------|
| **실험** | 운영·개발 | 가설, 실패, 문턱 장난, 스냅샷, 미완 마트, 내부 메모 |
| **공개** | 감정평가사·일반 | 선별된 질문, 재현 가능한 방법, 화면 숫자, 한계 |

실험이 실패해도 랩에는 남긴다. 공개할지는 **별 판단**이다. 「실패 = 공개 금지」가 아니다. 「아직 질문이 서 있지 않음 / 표본이 안 됨 / 결이 섞임」이면 올리지 않는다.

---

## 3. 입구 — 질문이 버튼이다

주제 라벨이 아니라 **한 줄 질문**이 문이다.

하면 됨:

- 「아파트 거래가 많은 곳은 상가 거래도 많을까?」
- 짧은 부제: 유형 × 유형 · 거래규모 · 시군구→읍→리

하면 안 됨:

- 「유형별, 행정체급별 거래액 관계」
- 「유동성 인사이트」
- 목록에서 「검증됨 / 관계 있음 / 성공」

목록 옆 상태는 관계의 판정이 아니다.

| 상태 | 뜻 |
|------|----|
| **실험함** | 이 창에 방법·숫자·한계가 있다 |
| **실험 전** | 질문은 적어 두었으나 마트·실험이 없다. **본문 없음** (접거나 숨김) |
| **표본 부족** | 실험은 했으나 남은 점이 적어 읽지 말라고 적는다 |

「관계 없음」도 목록 배지로 쓰지 않는다. 그건 본문 숫자가 말한다.

입구는 **큰 질문 소수**(대략 5~7)다. 유형 쌍 28개를 28개 문으로 쪼개지 않는다. 본문에서 체급·쌍을 고른다.

---

## 4. 공개 게이트 (올리는 조건)

아래를 **모두** 통과해야 게이트웨이 Insight에 올린다. 하나라도 안 되면 랩에만 둔다.

1. **질문이 한 결이다.** 공간 단면과 시계열, 규모와 단가, 전국 거시와 지역 r을 한 페이지에 섞지 않는다. (D-055)
2. **재현된다.** as_of, 체급, 변수, 산식이 랩 API(또는 스냅샷)와 같고, 손으로 고친 r가 본문에 없다.
3. **한계가 본문에 있다.** n 붕괴, 양수 표본, 인구 보정 범위, 인과 금지를 숨기지 않는다.
4. **해석 문장이 실험 때 고정됐다.** 요청 시 LLM이 「무엇을 알 수 있나」를 새로 쓰지 않는다. ([설명 헌법](./CH2_EXPLAIN_CONSTITUTION.md) `?` 1차)
5. **문턱·배지가 제품 결론이 아니다.** 랩의 실험용 문턱을 「동조 기준」으로 올리지 않는다. (D-058)
6. **지금 숫자가 약해도, 질문이 서 있으면** 공개 후보다다. 다만 **오독이 기본이 되는 표**(구성비 합=1 행렬 등)는 올리지 않는다.

올리지 않음 (지금):

- D-058 시장 규모 랩 전체 — 장기 실험, 제품화하지 않기로 함. 1차는 「규모는 인구·체급, 단가는 시군구 사이 입지」힌트이나 **공개 문장으로 고정하지 않음**
- G3 유동성·금리 — 전국 월별 총액 마트·대표 금리 1개 **미착수**. 질문만 목록에 걸지 않음
- 관리자 도구(검증로봇, Twin 거리, 전환율 연구 원장, 대장DB, AI 사용량)

## 5. 질문 페이지 템플릿

공개 페이지는 같은 뼈를 반복한다. 랩 `?`(방법·한계·의미)를 옮긴다.

| 구역 | 내용 | 출처 |
|------|------|------|
| **질문** | 한 줄 + 한 문장 설명 | 고정 카피 |
| **실험 방법** | 대상 · 기간 · 공간 단위 · 변수 · 통계 | 고정 카피. 산식은 CH2가 쓰는 것 |
| **결과** | 숫자 · 표 · 산점도. 체급 스위치 | **API / 스냅샷만** |
| **무엇을 알 수 있나** | 짧은 해석. 체급이 달라지면 같이 적음 | 실험 확정 시 고정 카피. AI 생성 금지 |
| **한계** | 별 구역. 인과 금지, 표본, 해상도 | 고정 카피 + 화면에 보이는 n |

성공/실패 도장 없음. 약한 결과도 같은 템플릿이다.

AI는 이 페이지를 보고 **추가 질문**할 때만 쓴다. 숫자를 재계산하지 않는다. ([AI 헌법](./CH2_AI_CONSTITUTION.md) Facts First · No Recalculation)

## 6. 랩에서 쌓는 것과 Insight 후보

랩은 계속 실험을 수행한다. Insight는 그중 게이트를 통과한 질문만 고른다.

| 랩 (지금) | Insight 후보가 되려면 | 지금 |
|-----------|----------------------|------|
| `?tool=size` 규모·단가 단면 (D-058) | 질문 5개 안팎으로 묶고, 카피 고정, 리 단가 빈 유형 안내가 본문에 있음 | **비공개** (장기 실험) |
| 인구↔거래 산점도 (프로필 G1) | 이미 제품에 있음. Insight로 **이중 게시하지 않거나**, 「인구가 많은 곳은 거래도 많을까?」로 **링크만** | 제품 = 프로필 순위 카드 |
| G3 전국 총액 ↔ M2·금리 | 랩 1차 = **연도**. 대표 CD 91일, 확인 국고 3년. M2는 다른 질문. 준비 [`lab/G3_TIMESERIES_LAB.md`](lab/G3_TIMESERIES_LAB.md). 월·시차·Insight **아님** | **준비** (ECOS 로더) |
| 전국 유형×유형 **시계열** | 같은 월별 총액 마트. G3와 **탭만 다름** | **실험 전** |

이후 질문이 생겨도 입구는 질문이다. 예(아직 실험 전, 목록에 올리지 않음):

- 유동성이 늘어난 달에 전국 거래액도 늘었는가
- 대표 금리가 오른 달에 전국 거래가 줄었는가
- 유형 단가는 해가 바뀌어도 같이 높은가

결이 다른 질문은 **다른 문**이다.

## 7. 게이트웨이 카드 (6번째 문)

공개 주제가 **1개 이상** 게이트를 통과하기 전에는 카드를 달지 않는다.

달 때의 초안 (미확정):

| 항목 | 안 |
|------|----|
| 위치 | `deploy/macro-gateway/` 그리드 6번째. 지역프로필·임대와 같은 베타 배지 |
| 제목 | Macro Insight |
| 설명 | 시장에 대해 물어본 실험 기록. 분석 앱이 아님 |
| 동작 | `/insight/` (가칭) — **랩 URL이 아님** |
| 무료/유료 | 미정. 랩이 아니므로 [권한 SSOT](./CH2_ENTITLEMENT.md)를 이 창용으로 **나중에** 한 줄 추가 |

설명에 「인사이트 제공」「검증된 동조」를 쓰지 않는다.

## 8. 하지 않음

- `/lab/`을 6번째 카드로 연결
- 실험 전부를 자동 게시
- 목록의 성공/실패·관계 있음 배지
- 본문 r를 카피에 박아 두기
- 미착수 거시 질문을 본문 있는 질문과 같은 무게로 진열
- 구성비 8×8을 Insight로 부활 (D-058)
- 시군구·읍·리에 M2·금리 r (D-055)
- 거래액 합을 가격지수로 쓰기, 인과·전망 문장
- Insight 전용으로 LLM이 해석 문장을 생성
- 외부조사로 「왜 가격이 움직였나」원인 카드 (D-062. 제품 AI 동의 조사와 Insight는 별개)

## 9. 다음에 할 일 (구현 아님)

순서만 적는다. 착수 지시는 별도.

1. 랩에서 실험을 계속한다. 스냅샷·`?` 도움말을 실험 SSOT로 유지한다.
2. 질문 후보가 생기면 이 문서 §4 게이트로 **공개 / 랩 잔류 / 실험 전**을 적는다. (계획일지 한 줄이면 됨)
3. 공개 1호가 정해지면: 고정 카피, API 숫자 연결, `/insight/` 뼈대, 그다음 게이트웨이 카드.
