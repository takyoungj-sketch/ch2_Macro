# 복합 지분거래 원칙 · 작업 계획

> **상태:** 원칙 확정 · Phase A–D 로컬 구현·원장 JOIN 백필 완료 (운영 DDL·백필·배포는 별도)  
> **결정:** [D-049](lab/decisions/D-049.json) · 2026-08-23  
> **관련:** [`BUILT_LEDGER_REBUILD_PLAN.md`](BUILT_LEDGER_REBUILD_PLAN.md) · [`BUILT_DATA_ENRICHMENT.md`](BUILT_DATA_ENRICHMENT.md) · [`CH2_CONSTITUTION.md`](CH2_CONSTITUTION.md)

한 줄: **거래는 숨기지 않는다. ㎡·단가·회귀의 기본 표본만 일반 거래를 쓴다.**

---

## 1. 왜 이 원칙인가

국토부 실거래 CSV를 그대로 쓰는 한, 지분 행의 **연면적과 대지가 같은 기준이 아니다.** 2026-08-23 등기 상세 대조:

| 사례 | 국토부 연면적 | 실제(전용·등기) | 의미 |
|---|---|---|---|
| 염창 243-4 | 936.74 | 전용 468.37 = **×2** | 연면적=건물 전체, 대지 117.9=대장 235.8의 **1/2** |
| 제천 116-15 | 136.9 | 전용 27.38 = **×5** | 대지 65는 이미 지분 |
| 이태원 64-10 | 295.21 | 건물 전용 221.41 + **2필지 일단지** | 한 줄이 64-10·64-11 |
| 옥천 대천리 57 | 212.36 | 상세와 동일 | 지분이어도 면적 기준이 어긋나지 않는 경우 |
| 불광 307-8 | 72.25 | 창고+대지 549 | 복원이 **391-180** 주택에 오탐 (A1) |

밸류맵·디스코는 위 거래를 공개하지 않는다. 숨기는 것과, 단가를 시세처럼 보여주는 것 둘 다 헌법의 **한계 노출**에 어긋난다.

원장은 보존한다. 7.1%를 삭제하는 정책이 아니다.

---

## 2. 비율 (원천 CSV, 구현 전 실측)

`raw/raw base/{상업업무,공장창고}_2021_2026`, 해제 날짜 행 제외, **유형=일반**(복합 적재 범위).

| 유형 | 살아 있는 거래 | 지분구분=지분 | 비율 |
|---|---|---|---|
| 상업업무 일반 | 90,793 | 7,388 | **8.1%** |
| 공장창고 일반 | 38,534 | 1,843 | **4.8%** |
| 합 | 129,327 | 9,231 | **7.1%** |

- **단독다가구:** CSV에 `지분구분` 칸 없음 → 플래그 불가, 제외 대상 아님.
- **집합 상가:** 지분 약 15%. 복합이 아니라 비주거 집합. 본 문서 범위 밖.
- 제품 `built_transactions`에는 아직 칸이 없다. 위 숫자는 CSV에서 센 값이다.

상업·공장 원본 21열에서 `지분구분`은 **iloc 16**(0-based). `pipeline/built/molit_schemas.py` 가 현재 이 칸을 매핑하지 않는다. (같은 파일의 해제=18, 거래유형=19. `BUILT_LEDGER_REBUILD_PLAN.md` §4.2 열 번호는 구버전이라 이 문서·스키마를 따른다.)

## 3. 화면별 기본값

```
원본 거래 (상업·공장 일반 + 단독)
 ├─ 일반 거래
 └─ 지분 거래 (상업·공장만 식별 가능)
        ↓
      원본 보존 · 해제는 ingest에서 삭제
        ↓
 거래목록          → 전체 표시 + 지분 열
 거래건수·금액 합  → 기본 포함
 중위·㎡당·분포    → 기본 제외
 회귀·예측·Twin 가격게이트 → 기본 제외
        ↓
 분석 체크 시 지분 포함 (목록은 그대로 전체)
```

| 표면 | 기본 | 비고 |
|---|---|---|
| 거래목록 모달 | **지분 포함 표시** | 열/배지. 기존 면적 필터와 무관 |
| 거래 건수, 거래금액 합 | **포함** | 실제로 일어난 거래 |
| 중위·평균 금액, ㎡당, 히스토그램 | **제외** | 연면적 정의가 다름 |
| 회귀 `/run`·추천·예측 | **제외** | 연면적 블록·단가 파생 |
| Twin 가격수준 게이트 `price/gross_area` | **제외** | `backend/app/built/regression/selection/pooling.py` |
| `built_scope_stats.tx_count` | **포함** | 마트 분리 필요 — §5.3 |
| `built_scope_stats.median_price` | **제외** | 同上 |

토지 앱은 바꾸지 않는다. 토지는 **포함이 기본**, 유료 「지분거래 제외」 체크(방향 2). 복합만 분석 기본이 반대다. 이유: 토지 지분은 대개 계약면적=그 지분, 복합은 연면적=전체·대지=지분이 섞인다. 체크 **모양**은 같고 기본값만 다르다.

## 4. UI 규칙

### 4.1 목록

- 지분 열 또는 배지. 원문 `지분` / 빈칸.
- 단독·비지분은 빈칸(또는 「—」). 「해당 없음」을 지분처럼 보이지 않게.
- 목록에서 지분 행을 숨기는 필터를 **기본으로 두지 않는다.**

### 4.2 분석 체크 — 목록 필터와 분리

지금 복합은 *「면적·연식 필터 = 회귀·목록·예측에 동일」*이다. 지분을 그 패널에 넣으면 목록에서 지분이 사라진다.

- 분석 패널 전용: **☐ 지분거래 포함** (기본 해제).
- 켜면 확인 팝업 한 번.

제안 문구:

> 지분거래는 건물 및 토지의 신고면적 기준이 일반 거래와 다를 수 있습니다. 포함하면 일부 면적·단가·회귀 결과가 달라질 수 있습니다.  
> **취소** / **포함하여 분석**

첫 방문 데이터 원천 안내(국토부·해제 삭제·미보정)와 **섞지 않는다.** 원천 안내는 별도(§5.5, 후순위).

### 4.3 n 표시 (필수)

회귀·기본통계·예측:

`n=1,240 · 지분 89건 제외`

포함 모드:

`n=1,329 · 지분 89건 포함`

7%를 몰래 뺀 것처럼 보이지 않게 한다(헌법 한계 노출).

IQR 이상치 제외는 **지분 제외 이후**에 적용한다.

## 5. 작업 계획

구현은 이 순서. 구조 표본 150건 감사(D-047)와 **병렬 가능** — 지분 적재는 enrichment와 독립이다.

### 5.1 Phase A — 원장에 칸 넣기 (선행)

1. DDL: `built_transactions.is_partial_ownership BOOLEAN NOT NULL DEFAULT FALSE`, `partial_ownership_label VARCHAR(32)` (토지와 같은 이름).
2. `molit_schemas.py` 상업·공장에 `"share_raw": 16`. 단독은 매핑 없음 → 항상 false/NULL.
3. `refine_built.py`: 라벨에 `지분`이 있으면 true. 금액·면적은 **수정하지 않음**.
4. ingest·월간 사이클 백필. 해시 충돌 없이 UPDATE.
5. 스모크: 상업 일반 지분율 ≈ 8%, 공장 ≈ 5%, 단독 0건.

완료 조건: 원장에서 염창·제천·용몽리 급 건이 `is_partial_ownership=true`.

### 5.2 Phase B — 목록 열

1. 거래목록 API·`BuiltTransactionRow`에 플래그.
2. 모달 테이블 열 「지분」.
3. 목록 total n은 **지분 포함**(지금과 같이 살아 있는 거래 전부).

완료 조건: 덕산읍 용몽리 `5**` / 2024-08-05 행에 지분이 보인다.

### 5.3 Phase C — 분석 기본 제외

1. 회귀·예측·추천 요청에 `include_partial: bool = false`.
2. Twin `price/gross_area` 게이트도 동일.
3. UI 체크 + 확인 팝업 + n 문구.
4. **마트:** `built_scope_stats` 한 행에 count(포함)와 median(제외)가 같이 있으면 안 된다.  
   - 안 A: grain에 `include_partial` 추가, 중위 행은 false / 건수 행은 별도 또는 true.  
   - 안 B: 중위·단가만 원장 live, 건수는 기존 마트.  
   구현 시 하나 고르고 월간 빌더를 맞춘다.
5. 물음표: 왜 복합만 기본 제외인지, 단독은 왜 빠지지 않는지.

완료 조건: 기본 회귀 n + 지분 제외 수 = 목록의 상업·공장 지분 수(같은 지역·기간·유형 필터). 체크 시 회귀 n이 그 수만큼 늘어남.

### 5.4 Phase D — 복원 매칭에서 지분 제외

`recover_address.match_all` 입력에서 `is_partial_ownership` 행을 빼거나, 맞아도 tier를 비운다.  
불광 5번: A1이 「범위 안 연면적 유일」일 뿐 참 필지가 아니다.

등기 전용으로 국토부 연면적을 **덮어쓰지 않는다.**

### 5.5 Phase E — 후순위 (이번 구현에 묶지 않음)

- 앱 첫 화면 원천·해제·미보정 안내 + 「다시 보지 않기」(버전 키).
- 집합 상가 지분 정책.
- 토지 기본값을 복합과 맞추기 — **하지 않음** (D-049).

## 6. 하지 말 것

- 지분 행을 원장·목록에서 삭제 (경쟁사와 동일).
- 등기 전용면적으로 연면적 치환.
- 지분 토글을 면적 표본필터에 넣어 목록까지 숨김.
- 단독을 휴리스틱으로 지분 추정.
- 토지 `exclude_partial` 기본값을 뒤집기.
- 복원 지번을 지분 행의 화면 주소로 쓰기.
