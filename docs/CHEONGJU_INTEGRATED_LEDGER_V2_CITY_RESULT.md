# 청주 통합 대장 v2.2 — 전체 확대와 제품 공급 병행

2026-10-05. 식별 규칙·4,000 PK 통합 공급을 마친 뒤 **동일 스키마·규칙·소비 계약으로 청주 전체의 세 고정 판본을 적재하고 복구를 검증했다.** 제품 공급은 기존 키와 새 원천 후보를 나란히 저장하는 첫 비교까지 수행했다. 운영 전환과 전체 제품 결과의 동등성 인증은 남아 있다.

## 같은 공급 체계의 청주 전체 실측

`data/research/cheongju_ledger/integrated_ledger_v2_cheongju.sqlite`를 별도로 생성했다. 건축 원본 전체 파일의 해시·행수·관리 PK 중복과 고정 청주 추출의 일치를 검사했다. 토지 후보는 건물 주소 수요에 제한하지 않고 청주 4개 구의 해당 연도 캐시 전체를 보존했다. 이전 v1·v2·4,000 PK DB와 원본은 유지한다.

- 2024-09: 건축 관측 **139,315개**, 토지 후보 **477,399개**, 최초 배치 적재 약 **60.6초**.
- 2025-07: 건축 관측 **141,420개**, 토지 후보 **478,750개**, 추가 판본 적재 약 **114.7초**.
- 2026-07: 건축 관측 **141,252개**, 토지 후보 **480,633개**, 추가 판본 적재 약 **230.5초**.

적재 시간에는 버전 비교와 전체 공개 포인터 재구축을 포함한다. 원본 준비·해시·멱등 재실행을 포함한 배치별 러너 구간은 약 109.9·172.8·316.1초였다. 복구·실패 주입·전체 상태 해시 검사를 포함한 최초 실행은 약 **890.6초**다. 운영 API 지연이나 순수 변경 행만 처리하는 증분 비용으로 해석하지 않는다.

최종 DB는 **2,030,292,992바이트(약 2.03GB)**다. 고유 관리 PK **144,247개**, 원문 버전 **283,404개**, 건물 속성 버전 **145,818개**, 건축 관측 **421,987개**, 토지특성 버전 **714,794개**, 토지·가격 관측 각각 **1,436,782개**, 정식 주소 관측 관계 **419,959개**를 보존했다.

최신 건축 관측 141,252개와 **last-seen만 남은 2,995개**를 구분한다. 최신 미관측을 말소·철거로 추정하지 않는다. 최신 본번 0000은 **620개**, 코드 2 블록은 **84개**이며 정식 PNU 관계를 부여하지 않는다. 최신 판본의 관측 수이므로 4,000 PK 표본의 44개 관측·16개 PK와 분모가 다르다.

원문은 검증한 선택 필드와 원본 참조이며 모든 건축 열을 복제한 것은 아니다. 청주 전체 토지의 DBF 원본 ZIP 인벤토리와 캐시 19열을 보존하되 전체 후보의 27열 DBF payload를 새로 복제하지 않았다. 확보된 4,000 PK DBF payload는 별도 표본 DB에 유지된다.

## 판본 차이·반복 실행·복구

2024→2025 건축 판본의 이전 대비 새 관측 PK는 3,240개·미관측 PK는 1,135개다. 2025→2026은 1,692개·1,860개다. 공유 PK의 가공 속성 해시는 각각 643개·928개가 달라졌다. 원문 해시 변화에는 구조·표현 변화도 포함하므로 실제 건물 변경 수로 표시하지 않는다.

토지 후보의 새 관측/미관측은 2025년 **7,170/5,819개**, 2026년 **4,386/2,503개**다. 공유 필지의 특성 내용 버전 변화는 **195,780개·72,965개**다. 가격 변화 집계는 원문 숫자·연도·상태를 포함하며 연도 변경과 숫자 변경을 실측 JSON에 따로 저장했다.

세 배치의 반복 실행은 모두 멱등이었다. 최초 판본→최신 판본 공개 포인터 복구는 약 **15.5초**였고 전체 테이블 해시가 정확히 일치했다. 20개 건물·20개 필지의 실패 주입 배치에서 전체 규모의 공개 포인터를 만든 직후 실패시켜도 기존 DB가 정확히 유지됐다. 실패 주입과 전체 상태 해시 확인 구간은 약 **51.8초**다. 실제 미래 월의 정상 증분 갱신을 검증한 결과는 아니다.

외래키, SQLite 무결성, 본번 0 정식 주소 차단, 고정 입력 해시 유지가 모두 통과했다. 원본 중복·추출 누락은 오류시 적재를 중단하며 이번 실행에 해당 충돌은 없었다. 전체 법적 건축물 모집단의 완전성 인증은 아니다.

## 기존 제품과 새 원천 후보의 병행 비교

`integrated_product_supply_paired.json.gz`에 기존 이름 키 **1,471개**, 주소 파티션 **1,565개**, 집계 거래 수 **108,077건**을 유지하면서 통합 DB의 원천 후보를 붙였다. 아파트 584개·오피스텔 68개·연립다세대 729개·분양권 90개다. 거래별 행을 새로 생성한 것이 아니라 고정 집계 수를 보존했다.

기존 대표 PNU의 **2026년 공시지가 1,302개는 새 공급의 같은 연도 숫자와 모두 일치**했다. 나머지 169개는 기존 가격이 없다. 기존 대표 선택의 정확성을 승인한 결과는 아니다. 대표필지가 실제 관측 주소인지 별도 필드로 남기며 복수 주소 가격을 합하거나 새 대표를 선택하지 않는다.

관측 주소에 최신 표제부 후보가 있는 키는 **1,391개**다. 후보 부재를 철거·단지 부재로 추정하지 않는다. 비주거 **306개 도로명 군집**은 기존 단위와 키를 보존한 대조군으로 함께 저장하며 주거 소속 규칙을 적용하지 않는다.

건축·특성·가격 값마다 [고정 소비 계약](LEDGER_SOURCE_CONSUMER_CONTRACT_V2_2.json)의 원천·기준시점·신뢰상태·마지막 관측·사용 허용을 전달한다. 새 제품 보강·수량 합산·회귀 허용은 모두 false다. 기존 가격·속성 매칭 metadata는 원형 그대로 보존한다.

**4단계 전체 완료는 아니다.** 고정 기준 자료의 건물 속성은 매칭 metadata이며 실제 숫자 속성을 포함하지 않는다. 실제 제품 속성·회귀 결과의 동등성을 인증하지 않았다. 복합 거래별 실제 소비 어댑터와 제품 결과 비교도 후속 범위다. 현재 결과는 기존 기준값과 공급 후보를 대조할 재현 가능한 출발점이다.
