# 신규아파트 회귀모델

> **작성:** 2026-08-18 · **상태:** **구현 SSOT** (2026-08-18 T·GPT 리뷰 반영 승격)  
> **제품 원칙:** [`CH2_CONSTITUTION.md`](CH2_CONSTITUTION.md) §3 (개별 AVM 아님) · 응답 4종은 [`COLLECTIVE_TWO_STAGE_HEDONIC_DESIGN.md`](COLLECTIVE_TWO_STAGE_HEDONIC_DESIGN.md) §0.1  
> **선행 데이터:** K-apt 단지 속성 P1–P2.5 · `rent_sale_building_map` · AL_D155(대전·충북) · 토지 `land_upper_stats_v2`  
> **적용:** `asset_type = 'apartment'`. 시뮬 본체는 **대전(30) 잠정**. 같은 M2를 **충북(43)** 에 복제해 구조를 확인한 뒤에 확정 여부를 판단한다.

이 문서가 본 프로젝트의 구현 SSOT다. 예전 「품질지수 2단계」 계획(`apt_regional_regression`)을 대체하지 않고 **상위 목적부터 다시 짠 뒤 승격**했다.  
품질지수 설계는 **트랙 C의 SSOT**로 유지한다. 신규 단지의 입력변수로 품질지수 \(Q\)를 쓰지 않는다.

## 0. 프로젝트 이름과 목적

**이름:** 신규아파트 회귀모델

| # | 목적 | 트랙 | 한 줄 |
|---|------|------|--------|
| **1** | 기존 통계로 **아직 없는 신규 아파트**의 평균 예측 가격 수준 | **A** | 입지·상품 조건 → ㎡당 가격 수준 + 기여도 |
| **2** | **시공사 밸류** 판단 | **B** | 트랙 A의 시공사 계수 γ (`exp(γ)−1`) |
| **3** | **기존 아파트**의 적정 수준·프리미엄 | **C** | 시군구 내 상대 점수 \(Q\) |

세 목적은 한 회귀식의 칸을 늘려서 동시에 달성하지 않는다. **데이터 층은 공유하고, 식과 화면 질문은 나눈다.**  
한 식으로 풀면 목적함수가 충돌한다 — A는 절대 가격, B는 시공사 효과, C는 상대 프리미엄.

### 0.1 하지 말 것

- 그 단지의 매매 평균단가·전세가율을 X로 넣어 Y(매매)를 설명하기
- 동(리) 평균단가를 X로 쓰기 — 단지 수가 적으면 정답 누설
- 준공연도 + 연식 + 기준시점을 한 식에 동시에 넣기 (연식 = 시점 − 준공)
- 품질지수 \(Q\)를 신규 단지 예측의 입력으로 쓰기
- 브랜드와 시공사군을 한 식에 동시 투입 (트랙 C 스펙 C는 진단만)
- 트랙 A의 γ와 트랙 C의 시공사 계수를 **같은 숫자로 합치거나** 한 화면에 “시공사 밸류”로 섞기
- 대전+충북을 단순 pool 해서 **대전 본체 모형을 바꿔 버리기**
- 데이터 보기 전에 학습 범위를 ‘신축 5년’으로 고정하기
- 버튼 하나 → 「적정 분양가 1,000만 원/㎡」 단일 정답 (헌법 §3)
- 기존 건물 회귀 엔진(`regression/engine.py`)에 시공사·토지를 끼워 넣기

### 0.2 사용자에게 항상 같이 줄 것

`equation` · `coefficients`(SE·t·p) · `warnings` · `sample_breakdown` · 기여도 분해 · 기준범주 · 학습 단지 수.  
점추정만 있으면 미충족이다.

## 1. 세 트랙 (확정)

```text
공유 데이터
  단지 × 시점 마트
  K-apt (세대수·층·주차·시공사·구조·준공)
  AL_D155 UQA → 읍×용도×대 토지 P50
  시군구/읍 매매·전세 (대상 단지 제외 또는 전년도)
        │
        ├─ Track A  신규 단지 가격 시뮬레이션
        │      시장 + 토지 + 규모·상품 + 시공사
        │      Y = ln(단지 중앙값 ㎡당 매매)
        │
        ├─ Track B  시공사 밸류
        │      = Track A의 γ_builder
        │      Track C 스펙 B는 교차검증만
        │
        └─ Track C  기존 단지 프리미엄
               quality_index / 2단계 헤도닉
```

| 트랙 | 질문 | 핵심 |
|------|------|------|
| A | 새 아파트를 여기 이렇게 지으면 얼마인가? | 절대 가격수준 예측 |
| B | 시공사가 가격에 얼마나 영향을 주는가? | 시공사 효과 (A의 γ) |
| C | 기존 단지가 주변 대비 얼마나 비싼가? | 상대적 프리미엄 \(Q\) |

\(Q\)는 트랙 A에서 **완전히 빼고** 트랙 C 전용이다.

## 2. 공유 데이터 (대전 1차)

**분석 단위:** 아파트 단지 × 연도. 셀당 거래가 얇으면 단지 × 5년 창 중앙값을 병행한다.  
**가중:** 거래 수 WLS.  
**Y 후보:** 단지 중앙값 ㎡당 매매 (평균은 비교용으로만).

| 블록 | 변수 | 규칙 |
|------|------|------|
| 시장 | 시군구(또는 읍) 아파트 P50, 전세 P50 | **전년도** 또는 **leave-one-out**. 그 단지 매매/전세 금지. 전세가율 금지 |
| 입지 | 지번 → AL_D155 `UQA*`만 → 읍×용도×`대` 토지 P50 | `ln(토지P50)` 우선. 용도 이름 더미는 나중. 혼재는 결측+사유. `UQA001`만 있으면 너무 굵음 |
| 상품 | 세대수, 최고층, 세대당 주차, 구조, 시공사군, 준공 vintage | K-apt A·B·C만. 품질 플래그 필드는 결측 처리 |
| 시점 | 기준연도 | vintage와 역할 분리. 연식과 vintage 동시 투입 금지 |
| 인구 | 읍 또는 시군구 | 트랙 A만. 트랙 C의 2단계 X에는 시군구 인구 금지 |

**1차 범위:** 대전(30)이 **시뮬 본체(잠정)**. 충북은 같은 M2를 복제하고, **대전 hold-out을 고정한 채** 학습에 넣을 때 대전 예측이 좋아지는지를 본다. 시공사 γ는 그 다음이다 (§4.1·§4.2).  
전국 AL_D155가 오기 전에 필지 용도지역을 전국 필수 X로 두지 않는다.

## 3. 트랙 A — 신규 평균 예측가

**질문:** 대전 서구 ○○동, 제3종, 1,500세대, 35층, 주차 1.6, 시공사 A, 준공 2028이면 ㎡당 어느 수준인가.

**식 — 본선은 구 아파트 P50을 넣지 않는다.**

구 아파트 P50은 입지(토지)와 겹친다. 신규 시뮬의 질문은 “이 위치의 토지가치 + 상품”이므로, 구 시세는 **진단용**이다.

| 갈래 | 질문 | 식 | 제품 |
|------|------|----|------|
| **M0** | 시점만 | 기준연도 더미 | 시장 사이클 |
| **본선 A** | 대전 전체에서 토지가 입지를 얼마나 설명하는가 | `ln(P) ~ 연도 + ln(토지P50)` → +상품 → +시공사 | **시뮬 본체** |
| **진단 B** | 구 시세를 이미 알 때 토지가 더 설명하는가 | `ln(P) ~ 연도 + ln(구아파트P50)` vs `+ ln(토지P50)` | 겹침 확인. 약해도 실패 아님 |
| **진단 C** | 같은 구 안에서도 토지가 움직이는가 | `ln(P) ~ 연도 + 구FE + ln(토지P50)` | 분석만. 신규 입지 예측에 구FE 고정 금지 |

본선 사다리: **M0 → M1-A → M2(대전 잠정 기준) → M3(시공사 탐색, 충북 이후)**.  
**M2는 대전 잠정 기준식이다. 충북 복제·전이 실험 전에는 최종으로 확정하지 않는다.** M3는 시공사 표본(단지≥30)이 충분할 때만 노출한다.  
동 안에서 토지 분산이 작으면 동 내부 R²가 낮아도, 시 전체 입지 변수로는 유효할 수 있다.

토지 P50의 역할: 미시적 단지 가격 차이를 맞히는 변수가 아니라 **신규 개발지의 거시·중간 수준 입지 가격대**를 설명한다.

각 갈래는 **전체 표본(A-1)** 과 **준공 후 5년 이내(A-2)** 를 나란히 적합한다. 학습 범위는 데이터 전에 고정하지 않는다 (§3.1).

### 3.1 학습 범위 — 전체 vs 신축 5년 (미확정, 비교 후 결정)

| 표본 | 구성 | 장점 | 위험 |
|------|------|------|------|
| **A-1 전체** | 전체 연식 + vintage | 표본이 큼. vintage가 노후·최근을 구분 | 오래된 시장구조가 섞임 |
| **A-2 신축 5년** | 준공 후 5년 이내 셀 | 신규 아파트와 가장 가까운 시장 | 표본 부족 가능 |

Phase 0–A2에서 둘을 비교하고, **신규에 가까운 hold-out**(준공 0~5년 단지) 성능을 기준으로 1차 학습 범위를 결정한다.  
예측 입력의 준공예정은 선택한 모형의 vintage/신축 구간에 넣는다.

### 3.2 A2 핵심 비교표 (설명력 + 예측력)

토지단가의 가치는 ΔAdj R²만으로 판단하지 않는다. 목적은 신규 **시뮬**이므로 아래를 **같이** 본다.

| 모델 | 갈래 | 표본 | Adj R² | hold-out MAE | MAPE | n |
|------|------|------|--------|--------------|------|---|
| M0 연도만 | — | A-1-land | | | | |
| M1-A 토지만 | 본선 | | | | | |
| M2-A +상품 | 본선 | | | | | |
| M3-A +시공사 | 본선 | | | | | |
| M1-B 구시세만 | 진단 | | | | | |
| M1-B 구+토지 | 진단 | | | | | |
| M2-B / M3-B | 진단 | | | | | |
| C 구FE+토지 | 분석 | | | | | |

- hold-out은 가능하면 **최근 준공 단지(0~5년)** 를 따로 잡는다.
- Adj R²가 올라도 hold-out MAPE가 나빠지면, 그 변수는 신규 예측에 도움이 됐다고 보지 않는다.
- 구 시세를 넣은 뒤 토지 ΔAdj R²가 작다고 **토지가 입지를 설명하지 못한다**고 단정하지 않는다. 구 시세가 입지를 먼저 가져간 것이다.

**화면:** 집합 기본통계(대전 아파트)에서 「신규아파트 실험」. 점추정 + 식·계수·n·경고 + 학습 테이블(토지 조인·이상치·잔차) + 구/연도 hold-out.  
기존 건물 상세 「회귀 분석」 탭과 섞지 않는다. 「분양가 보장」 문구 금지.

### 3.3 APE 오차 태깅 (M2 고정 후)

다음 식(M4)을 바로 넣지 않는다. 학습 테이블을 **단지 단위**로 묶어 오차를 태깅한다.

- 연도 셀을 한 단지로 합친다.
- **학습 잔차**와 **hold-out 오차**, **신축**과 **노후**를 나눈다.
- 갈래: 데이터 / 모델 외 / 구조 / 시장 시점.
- **같은 원인이 단지 5개 이상**일 때만 다음 변수 후보다. 1–2단지는 경고만.
- 노후·나홀로·상업지역 조인의 80% APE는 신규 시뮬 변수로 쓰지 않는다.

화면: 실험 모달 「오차 패턴」 탭 — **의사결정 도구**.

- 상단 판정: M2 기준식 고정 여부, 다음 변수 없음.
- **신축 대단지 과소예측** 은 별도 누적 카드 (단지 수·시공사 수·브랜드 수·구 수·평균 APE·방향). 한 구/한 시공사에 몰리면 레이어를 열지 않는다.
- 데이터 문제(상업지역 토지, n&lt;15)는 M2 본체를 바꾸지 않고 **정제 표본 hold-out 비교**만 한다.
- Track B는 누적이 문턱을 넘은 뒤 `M2` vs `M2+시공사` vs (별도) `M2+브랜드` 를 **hold-out MAPE**로 경쟁. 한 식에 시공사+브랜드 금지.

## 4. 트랙 B — 시공사 밸류

**질문:** 입지·시장·토지·규모·물리적 특성을 통제한 뒤, 이 시공사는 기준(기타) 대비 몇 %인가.

**본체는 트랙 A다. 시공사 전용 모형을 따로 만들지 않는다.**

```
트랙 A: ln(P) = 시장 + 토지 + 단지 규모 + 물리적 특성 + 시공사 + …
트랙 B 주 결과 = 그 식의 γ_builder
```

예: 기준 = 기타, A사 γ = 0.08 → `exp(0.08)−1 ≈ +8.3%`.  
단지 수·구간을 함께 보여 준다.

**정의 (1차):** 시공사 밸류란, 입지·시장·토지가치·규모·물리적 특성을 통제한 뒤에도 남는 **시공사별 평균 가격 효과**다.  
브랜드 가치의 완전한 측정치라고 단정하지 않는다. 현재 데이터로 측정 가능한 브랜드 프리미엄의 **핵심 추정치**다.

**트랙 C:** 기존 단지 상대 프리미엄(\(Q\)) 관점에서 시공사 효과가 비슷하게 나타나는지 **교차검증만**.  
A의 γ와 C의 시공사 계수를 같은 숫자로 합치지 않는다. A가 본체, C는 검증.

**성립 조건**

- 시공사당 단지 최소 **30**을 기본. 미달은 ‘기타’ 또는 **측정 불가** (0%로 위장하지 않음)
- 대전에 실적 없는 시공사 → 예측 불가
- 토지·시군구를 넣기 전/후 γ 변화 = 입지와 브랜드의 혼동 점검
- 브랜드 더미와 시공사 더미 동시 투입 금지. Track B를 열 때는 **M2+시공사**와 **M2+브랜드**를 따로 적합하고 hold-out MAPE로 고른다. 시공사를 1차로 본다.

### 4.1 대전 미달 시 충북 — 조건부, 본체는 대전

충북을 B 보조 표본으로 열 때 **단순 pool 금지.** 시공사 효과 안에 대전/충북 입지·시장 차이가 섞인다.

최소 스펙 (풀 비교용):

```
ln(P) ~ 지역 시장수준 + 토지 + 상품성 + 시공사 + 지역 FE
```

더 나은 운영:

| 모형 | 역할 |
|------|------|
| **대전만** | 기본 추정. 트랙 A 본체를 **바꾸지 않음** |
| **대전+충북** (+ 지역 FE) | 시공사 계수 **안정성 확인** |

나란히 비교한다.

```
A사    대전만 +7.2%    대전+충북 +6.8%   → 안정
A사    대전만 +12%     대전+충북 +2%     → 지역과 시공사가 아직 분리되지 않음
```

충북을 넣었다고 대전 모델 자체를 교체하지 않는다. 보조 표본을 쓸 때는 경고에 명시한다.

### 4.2 충북 M2 복제와 대전 hold-out 고정 전이

대전만으로는 시공사·브랜드·신축 대단지 패턴을 판단하기에 표본 범위가 좁다.  
그래서 **오차 패턴 탭을 키우기 전에**, 같은 M2를 충북에 복제한다.

```
ln(P) ~ 연도 + 지역(광역 또는 시군구) + ln(토지P50) + ln(세대수) + 최고층 + 세대당 주차 + vintage
```

| 모형 | 표본 | 목적 |
|------|------|------|
| **A** | 대전 | 현재 잠정 기준 |
| **B** | 충북 | 외부 지역에서 구조 확인 |
| **C** | 대전+충북 + 지역 FE | 표본 확대 효과. **단순 혼합 금지** |

비교: Adj R² · hold-out MAPE · 계수 방향 · 토지·세대수·주차·층.

**채택 기준은 통합 평균 MAPE가 아니다.** 충북 데이터가 많거나 쉬우면 평균만 좋아질 수 있다.

핵심 실험 (대전 고정 테스트):

| 학습 | 테스트 |
|------|--------|
| 대전 | 대전 hold-out |
| 대전+충북 | **동일한** 대전 hold-out |

충북을 넣었더니 같은 대전 테스트 단지 예측까지 좋아지면 구조 안정화 후보다.  
전체 평균은 좋아지는데 대전 hold-out이 나빠지면 통합을 채택하지 않는다.

순서: 대전 M2 → 충북 M2 → 대전+충북 M2 → +지역 효과 → (이후) 시공사군 → 신축 대단지 hold-out.  
**지금 M4는 넣지 않는다. M2 최종 확정도 보류한다.**

API: `GET /api/collective/analysis/new-apt/region-compare` · 화면 「충북 확장」 탭.

## 6. 구현 순서

코드보다 **대전 표본 집계**가 먼저다. 시공사 γ 노출 여부와 학습 범위는 숫자 다음에 정한다.

```
대전 Phase 0
  → 단지 × 연도 mart (A1)
  → M0·M1-A(토지 본선) vs M1-B(구시세 진단) · M2 · M3
  → M2를 대전 잠정 기준식으로 둠 (충북 복제 전 최종 확정 아님)
  → 구 통째·연도 통째 hold-out
  → UI: 집합 기본통계 「신규아파트 실험」 (학습 테이블·토지 조인·잔차)
  → 충북 M2 복제 + 대전 hold-out 고정 전이
  → 시공사 γ 노출 여부 (대전 vs 대전+충북 안정성)
  → 신축 대단지 hold-out
  → UI (실험 라벨)
```

| 단계 | 내용 | 완료 조건 |
|------|------|-----------|
| **0** | 대전 단지 수, 단지×연도 셀(거래≥10), 시공사별 단지 수, UQA 조인율·혼재율, 토지 셀 n&lt;15 | JSON 리포트 |
| **A1** | 단지×연도 마트 (Y, 지역 lag, 토지 P50, K-apt) | 셀 수·결측률 |
| **A2** | M0·M1-A/B·M2·M3 × (A-1 / A-2), 토지 분산, 구/연도 hold-out | 본선 A vs 진단 B. **M2 = 대전 잠정 기준식** |
| **A3** | 충북 M2 복제 + 대전 hold-out 고정 전이 (광역 FE) | 통합 평균 MAPE로 채택하지 않음. 대전 테스트가 좋아질 때만 안정화 후보 |
| **B** | 대전 γ + (필요 시) 대전+충북·지역 FE 나란히 | 단지≥30만 계수 노출. 흔들리면 미노출. **충북 M2 이후** |
| **C** | 품질지수 mart 빌드·열람 (이미 코드 있음) | mean(Q)≈0, 기존 회귀 엔진 불변. B 교차표는 선택 |
| **UI** | 집합 기본통계 → 「신규아파트 실험」(아파트). 비교표·충북 확장·오차 패턴 | 식·계수·경고·학습 테이블·hold-out·대전 고정 전이. 기존 회귀 탭과 분리 |

커밋은 UI(또는 리포트)를 T가 본 뒤에. 기존 건물 회귀는 손대지 않음.
