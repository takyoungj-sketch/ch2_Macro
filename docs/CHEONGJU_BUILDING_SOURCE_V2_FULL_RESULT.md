# 청주 원천 보존 v2 — 4,000개 표본 확대 결과

실행일: 2026-10-05. [118개 검토 표본](CHEONGJU_BUILDING_SOURCE_V2_RESULT.md)의 규칙을 기존 v1 관리 PK 4,000개에 확대했다. 원본 및 v1을 유지하고 별도 로컬 SQLite를 만들었다. 운영 DB·복합·집합 보강·회귀·배포는 변경하지 않았다.

## 표본과 원본 대조

기존 표본의 관리번호 목록 SHA-256이 v1 보고서와 일치했다. 이 표본은 최초 관측 구별 1,000개를 선정하면서 인접 판본의 PNU 변경 건물을 모두 포함한 것이므로 도시 전체 예외율을 추정할 수 없다. 2024-09·2025-07·2026-07 전국 표제부를 다시 읽고 파일 전체 해시·행수를 이전 조사와 대조했다.

관측은 각각 3,850개, 3,933개, 3,913개로 합계 11,696개다. v1의 모든 표본 관측을 원본에서 찾았고 대상 관리번호 중복은 없었다. 정식 주소는 각각 3,832개, 3,930개, 3,911개로 합계 11,673개가 v1과 동일했다. 정식 판정 주소의 불일치는 0개였다.

대지구분 코드 2는 고유 건물 18개의 관측 23개다. 2024년 18개, 2025년 3개, 2026년 2개이며 모든 원문을 남기고 PNU 관계는 보류했다. 예전 118개 검토 표본의 예외 건물 3개보다 범위가 넓어진 결과다. 시점별 건수 차이를 코드의 법적 정정이나 동일 자산 승계로 단정하지 않는다.

격리 DB `building_source_staging_v2_full.sqlite`에는 원천 배치 3개, 건물 4,000개, 원문 버전 7,986개, 관측 11,696개, 주소 관계 11,673개가 있다. 선택 공통 필드의 원문 보존이며 76/77열 전체 이관이 아니다. 가격/토지 이력과 현재 상태 복구 전체 기능의 v2 통합도 아직 남아 있다.

## 공통 입력 미리보기

[소비 계약 초안](LEDGER_CONSUMER_CONTRACT_DRAFT.md)에 따라 원천 주소를 공시지가 관측과 연결하는 읽기 전용 미리보기를 만들었다. 제품 키 연결이나 회귀 입력을 만든 것은 아니다.

- 2024년: 3,850개 건물 관측 중 기준연도가 있는 양수 가격 3,513개, 해당 판본 가격 미관측 305개, 식별 보류 18개, 원본 오버플로 14개. 양수 가격의 고유 PNU는 3,354개다.
- 2025년: 3,933개 중 양수 가격 3,656개, 미관측 257개, 식별 보류 3개, 오버플로 17개. 양수 가격의 고유 PNU는 3,444개다.
- 2026년: 3,913개 중 양수 가격 3,688개, 미관측 215개, 식별 보류 2개, 결측/비양수 8개. 양수 가격의 고유 PNU는 3,469개다.

이는 표제부 관측별 집계이므로 같은 필지 가격이 여러 건물 입력에 등장할 수 있다. 건물 관측 수와 고유 필지 수를 따로 표시했다. 가격 단가를 더하거나 필지면적을 중복 합산하지 않는다. 2026년 결측/비양수 8개 관측도 고유 결측 필지 8개라는 뜻은 아니다.

시점 정책은 같은 연도 연구용이다. 계약 당시 자료 가용성, 최신 대표필지 선택, 독립 거래/단지 연결 정확도를 인증하지 않는다. 보류된 식별 23개에는 가격을 붙이지 않았다.

## 검증과 산출물

확대 v2에서 3판본 재실행, 고의 실패 후 모든 테이블 원상 유지, 원문 저장값 일치, 외래키·미확정 연결 차단·기존 v1 상태 유지·원본 관측 누락 없음 등 10개 검증이 통과했다. 미리보기는 키 유일성·관측당 한 행·변환 규칙/원본 출처 참조·보류 가격 차단·제품 연결 미생성·가격 연도 일치·입력 DB 원상 유지 7개 검증이 통과했다. 기존 검증과 가격 입력 예외 테스트를 합쳐 19개 테스트도 통과했다.
