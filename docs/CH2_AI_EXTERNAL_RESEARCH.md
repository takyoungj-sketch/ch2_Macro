## 0. 한 줄

기본 AI는 **CH2 데이터만** 해석한다.  
개발사업·뉴스·공고처럼 원장에 없는 질문은 **못 한다**가 아니라 **외부조사를 켤지 묻는다.**  
켠 뒤에도 CH2 칸과 외부 칸을 나누고, **그래서 가격이 움직였다**고 쓰지 않는다.

---

## 1. 왜 나누는가

CH2 Macro의 차별은 인터넷 부동산 글을 요약하는 것이 아니다. **CH2가 만든 거래 통계를 근거로 시장을 읽는 것**이다.

웹을 기본으로 붙이면 사용자는 무엇이 표본에서 나왔고 무엇이 기사인지 구분하지 못한다.  
그렇다고 「CH2에 없습니다」로만 끝내면, 개발사업처럼 **원장에 없는 질문**을 물을 자리가 없다.

그래서 검색 자체를 없애는 것이 아니라, **검색을 기본에서 빼고 동의한 조사로만 연다.**

---

## 2. 두 영역

| | CH2 분석 | 외부자료 조사 |
|--|----------|----------------|
| 근거 | Bundle · History · 화면 통계 | 검색 스니펫 · URL |
| 예 | 건수·액·단가·회귀·추세·유형 구성. 프로필 **인구**(그 화면 값) | 개발사업, 재개발·재건축, 도시계획, 산업단지, 교통·철도, 기업 투자, 정책 공고·뉴스 |
| 켜는 때 | 기본 | 사용자가 동의한 뒤만 |
| 금리는? | 제품 Bundle에 있을 때만 CH2. 랩 G3(ECOS)는 관리자. 없으면 웹에서 끌어와 「CH2 금리」라고 하지 않음 | 한국은행·기준금리 **뉴스·공고**는 외부 |

인구를 웹 키워드로 보내지 않는다. 프로필에 있는 인구는 CH2다.

---

## 3. 질문 흐름

```
사용자 질문
    │
    ├─ 적정가·투자·전망 → Refusal (기존)
    ├─ CH2로 답 가능 → 기존 경로 (Facts / Explain / Statistics / Opinion)
    └─ CH2 원장 밖 (개발사업·뉴스·공고 등)
            │
            ▼
     offer_external
     「이 질문은 CH2 밖입니다. 외부자료를 조사할까요?」
            │
            ├─ 아니오 / 화면 통계만 → CH2로 복귀
            └─ 예 / 조사해 주세요 / `external_research=true`
                    │
                    ▼
                 route=web
                 검색 → 외부 칸만 채움
```

자동으로 `route=web` 하지 않는다. (구: 금리·정책·뉴스 키워드면 바로 검색)

### 동의 방법 (P0)

1. 제안 답의 후속 질문 **「외부자료를 조사해 주세요」**
2. 짧은 확인: 네 / 예 / 조사해 / 찾아줘 (직전 답이 `offer_external`일 때만)
3. API `external_research=true` — UI가 원래 질문을 다시 실어 보낼 때 (칩 버튼은 P2)

### 카피 원칙

금지: 「웹 검색을 못 합니다」「능력 부족」  
허용: 「CH2는 거래 통계를 해석합니다. 이 정보는 원장에 없어 외부조사가 필요합니다.」

---

## 4. 답을 나누는 법

조사 후에도 **한 문장으로 합치지 않는다.**

허용:

- CH2: 2019–2021년 해당 지역 거래액·건수가 늘었다 (Bundle 숫자만).
- 외부: 같은 기간 ○○사업 착공 기사가 있다 (URL).
- 해석: **시기가 겹친다. CH2는 그 사업의 효과를 측정하지 않았다.**

금지:

- 「SK 투자로 복대동 가격이 올랐다」
- 「배후 수요가 늘어 상승했을 가능성」처럼 사용자가 인과로 읽게 쓰는 문장
- 외부 숫자를 CH2 표본·계수인 것처럼 인용

웹 요약 LLM도 위 금지를 따른다. 출처 URL은 `evidence[]` type=`web`.

검색은 망라가 아니다. 빠진 사업이 있다고 한계에 쓴다.

---

## 5. 단계

| 단계 | 내용 | 상태 |
|------|------|------|
| **P0** | 키워드 자동 검색 중지. `offer_external`. 동의(후속 문장·플래그) 후에만 `web` | **이 커밋** |
| **P1** | 동의 후 검색 품질(Tavily 키). 답 본문을 CH2 칸 / 외부 칸 제목으로 고정 | 다음 |
| **P2** | `＋ 외부자료 조사`와 주제 칩(개발사업·교통·산업·도시계획·정책·기타) | 다음 |
| **하지 않음** | Macro Insight에 「왜 가격이 움직였나」원인 카드. 게이트웨이 공개 | 구상만, Insight 계획 유지 |

1호 사례는 **개발사업**이다. 칩이 없어도 질문 문장으로 P0가 제안을 띄운다.

## 6. 현재 코드와의 간격

| 구 | 신 (P0) |
|----|---------|
| `classify_route`: 금리·국토부·정책·뉴스·인구… → 즉시 `web` | 개발사업·뉴스·한국은행 등 **원장 밖 힌트** → `offer_external`. 맨 단어 「정책」「인구」는 넣지 않음 (이상치 정책·프로필 인구와 충돌) |
| `handle_chat`이 바로 `web_search` | 동의 전 검색 호출 없음 |
| DuckDuckGo Instant 폴백 | 동의 후에만. 품질은 P1 |

`TAVILY_API_KEY`가 없으면 Instant라 **한국 지역 사업 목록은 빈약**하다. 켜도 망라가 아님을 답에 남긴다.

- 검색 결과를 거래 원인으로 단정
- 「웹을 못 해서」라는 제품 문장
- 구독 티어와 외부조사 연동 (D-043과 무관, 관리자 인증과도 무관)
