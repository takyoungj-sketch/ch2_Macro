# 통계 학습페이지 연계 개선사항

학습 콘텐츠 범위 밖의 검토 사항을 누적합니다. 확인된 구현 사실과 추가 감사가 필요한 위험을 구별합니다. 실제 Macro 변경은 사용자 검토·승인 후 별도 작업으로 진행합니다. 2026-10-25 기준 관련 학습 전용 보류 관리 문서를 찾지 못해 생성했습니다. 기존 다른 업무의 backlog는 수정하지 않았습니다.

- 제안: 선택용 검증 명칭·사용 이력과 별도 최종 시험 필요성을 검토합니다.

## LS-010 — 서비스 CV 분할·집계·OOF 추적 계약

- 발견 장·기능: 26장, 복합 롤링 CV 및 지역회귀 Holdout
- 구분·분류·우선순위: 추가 감사·기능 아이디어 / 통계적 정확성·UI / 중간
- 검증 근거·재현: 복합 `_rolling_time_cv_mape`는 계약연도로 과거 학습→이후 연도 평가를 구성하고 관측별 APE를 모아 평균합니다. `CvPhase`와 관련 응답은 점수·평가 연도·유효 폴드 등의 요약 중심입니다. 지역회귀 `_split_hold`는 시드 42의 무작위 분리 경로입니다. 확인한 경로에서 일반 사용자가 교재처럼 관측별 OOF 전체를 보관·조회할 수 있다는 근거는 확인하지 못했습니다. 미확인을 기능 부재 전반의 증명으로 확대하지 않습니다.

- 처리 상태: 보류. 학습 페이지에 차이를 설명만 했습니다. 제품 통계, 시각화, 이상치 정책은 변경하지 않았습니다.
