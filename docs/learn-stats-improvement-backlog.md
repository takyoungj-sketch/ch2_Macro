# 통계 학습페이지 연계 개선사항

학습 콘텐츠 범위 밖의 검토 사항을 누적합니다. 확인된 구현 사실과 추가 감사가 필요한 위험을 구별합니다. 실제 Macro 변경은 사용자 검토·승인 후 별도 작업으로 진행합니다. 2026-10-25 기준 관련 학습 전용 보류 관리 문서를 찾지 못해 생성했습니다. 기존 다른 업무의 backlog는 수정하지 않았습니다.

- 제안: 선택용 검증 명칭·사용 이력과 별도 최종 시험 필요성을 검토합니다.

- 영향: 실제 추천 UI·검증 정책 및 21~23·26장 설명. 사용자 승인 전 정책 변경 금지.

- 26장 추가 확인: `frontend-built/src/components/RecommendStagePanel.tsx`는 탐색 CV로 순위를 정하고 확인 CV로 대표모형 확정을 가르는 경로를 설명합니다. 확인 CV도 그 결정에 쓰인다는 사용 이력을 밝혀야 하며, 이를 무조건 독립 최종 시험으로 부르지 않습니다. 기존 지역회귀 Holdout 문제와 함께 관리하고 실제 정책은 변경하지 않습니다.

## LS-010 — 서비스 CV 분할·집계·OOF 추적 계약

- 발견 장·기능: 26장, 복합 롤링 CV 및 지역회귀 Holdout
- 구분·분류·우선순위: 추가 감사·기능 아이디어 / 통계적 정확성·UI / 중간
- 검증 근거·재현: 복합 `_rolling_time_cv_mape`는 계약연도로 과거 학습→이후 연도 평가를 구성하고 관측별 APE를 모아 평균합니다. `CvPhase`와 관련 응답은 점수·평가 연도·유효 폴드 등의 요약 중심입니다. 지역회귀 `_split_hold`는 시드 42의 무작위 분리 경로입니다. 확인한 경로에서 일반 사용자가 교재처럼 관측별 OOF 전체를 보관·조회할 수 있다는 근거는 확인하지 못했습니다. 미확인을 기능 부재 전반의 증명으로 확대하지 않습니다.

- 제안: 군집분석을 현재 서비스가 제공한다고 소개하지 않습니다. 기능을 넣을 경우에는 생성 변수와 사후 해석 변수를 구분하고, 표준화·결측 기준은 학습 자료로만 정하며, 범주 코드에 순서를 부여하지 않습니다. 번호 일치율 대신 함께 묶인 관측이나 Adjusted Rand Index처럼 라벨 순서에 영향받지 않는 비교를 검토합니다. 초기 중심을 자유롭게 옮기는 실험과 다른 연결 기준의 덴드로그램은 학습 화면에만 나중에 더할 수 있습니다.
- 처리 상태: 학습 설명과 K=2 단계 시연, K=1~6의 W, 실루엣 선택, 완전연결 절단은 반영. 실제 군집 기능과 안정성 실험, 자유 초기 중심, 다른 연결 기준의 그림은 보류.
- 위치: `deploy/hub/learn/stats/clustering/`; 확인 범위는 위 다섯 경로.
- 실제 Macro 영향: 군집을 회귀·모형추천·쌍둥이 탐색에 넣으면 시장 구분과 유사거래 결과가 바뀝니다. 사용자 승인 없이 구현하지 않습니다.

## LS-019 — 다중검정·민감도 일괄 실행·재현 묶음

- 발견 장·기능: 32장, 토지·복합·집합의 회귀와 모형추천
- 구분·분류·우선순위: 추가 기능 아이디어 / 기능 / 중간. 32장의 공통 자료 계산에서 새 수치 오류는 확인되지 않았습니다.
- 검증 근거: `backend/app`에서 Bonferroni, FDR, `multipletests`에 해당하는 코드를 찾지 못했습니다. 이 검색을 저장소 전체의 부재 증명으로 확대하지 않습니다. 32장은 여러 검정을 반복하면 거짓 양성이 늘 수 있다는 설명만 두고, 보정 계산을 서비스에 넣지 않았습니다. 기간·지역·이상치·함수 형태를 자동으로 훑는 민감도 실행과, 판본·필터·시드·분할을 한 묶음으로 남기는 재현 정보도 이번 학습 페이지에서 만들지 않았습니다.
- 제안: 탐색으로 고른 결과와 미리 정한 가설의 검증을 화면에 구분하는 방안, 합리적인 대안을 정해 둔 민감도 비교, 분석 시점의 자료 판본과 표본수를 결과에 함께 남기는 방안을 별도로 검토합니다.
- 처리 상태: 보류. 학습 문장과 다섯 단계·효과 구간·세 평가·외삽 조작만 반영했습니다.
