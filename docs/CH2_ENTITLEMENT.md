# CH2 Macro — 무료 / 유료 권한 (Entitlement)

> **상태:** 제품 정책 SSOT (D-043, 2026-08-16)  
> **결정:** [`DECISIONS.md`](./DECISIONS.md) D-043 · 카드 [`lab/decisions/D-043.json`](./lab/decisions/D-043.json)  
> **가격·결제 채널:** [`CH2_SUBSCRIPTION.md`](./CH2_SUBSCRIPTION.md) (D-052). 이 문서는 **무엇을 잠글지**만 정한다.  
> **대체:** D-010의 「무료 = 법정동/리 단건만」은 **폐기**. 복수지역 한도(유료 시군구 미만 최대 10 등)는 유료 쪽에 유지.

결제·로그인이 없어도 **권한 규칙은 먼저 고정**한다. UI만 숨기고 API가 열려 있으면 안 된다.

---

## 1. 적용 범위

| 포함 | 제외 |
|------|------|
| 토지 · 복합 · 집합(주거·비주거) · 임대 · 지역프로필 | **랩(`/lab/`)** — 관리자 도구. 유료 기능이 아님. 공개 게이트웨이에 노출하지 않음 |

다섯 앱은 **같은 화면·같은 산식**을 쓴다. 무료는 깊이를 줄일 뿐, 다른 통계를 보여 주지 않는다.

`/api/free/v2/...` 는 **V2 통계 엔진 경로 이름**(D-001)이다. 제품 티어 「무료」와 같지 않다.

---

## 2. 공통 규칙

| 항목 | 무료 | 유료 |
|------|------|------|
| UI · 산식 · 표본 정의 | 동일 | 동일 |
| 지역 해상도 | **한 곳**, 시·구·읍·리 **어느 결이든** | 기존 앱 한도(복수·인접 추가 등) |
| 복수 지역 | 불가 | 앱별 기존 한도 |
| 롤링 창 | **5년만** | 3 · 5 · 7 (앱이 제공하는 창) |
| 물음표(`?`) glossary | **유지** | 유지 |
| AI | 불가 | 허용(헌법 범위) |
| 회귀 · 모형 추천 · Twin pool | 불가 | 허용 |
| CSV보내기 | 불가 | 허용 |
| 모달 | **같은 껍데기**. 유료 깊이 탭은 숨기지 않고 「유료」로 잠금 | 전 탭 사용 |

잠글 탭의 예: 회귀 · 효용 · 코호트 · 3년/7년 창 · CSV · AI.  
탭을 없애면 무료/유료가 다른 제품처럼 보인다. **잠금 + 「유료」 표시**가 규칙이다.

---

## 3. 서버 강제

프론트 토글·탭 숨김만으로 권한을 나누지 않는다.

- 무료 세션에서 3·7년, 복수 지역, 회귀/추천/Twin pool, CSV, AI 엔드포인트는 **거절**.
- 거절 이유는 사용자에게 「유료 기능」으로 읽히게. 내부 구현 세부를 노출하지 않음.
- 랩 API는 관리자 인증. 유료 구독과 무관.

구현 전에는 본 문서가 **목표 계약**이다. 앱마다 다른 무료 규칙을 다시 만들지 않는다.

---

## 4. 토지 — 현재 구현 (2026-08-16)

토지 앱의 **제품 무료 모드**(좌측 「무료 통계」탭, 법정동/리 단건 강제)는 **제거**했다.

- 토지 `/land/` 는 종전 **유료 분석**과 동일하게 동작한다 (모든 행정 결, 3/5/7년, 복수·지도 인접, 필터 분석).
- 통일 무료 게이트(§2: 5년·단건·모달 잠금)는 **아직 다섯 앱에 미적용**. 결제 연동 시 본 문서를 따른다.
- 토지만 「무료=법정리」로 되돌리지 않는다.
