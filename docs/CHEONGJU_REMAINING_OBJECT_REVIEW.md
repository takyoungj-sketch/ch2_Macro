# 청주 나머지 35개 키와 미확인 두 주소 — 원본 검토

2026-10-05. [아파트 17개 검토](CHEONGJU_APARTMENT_SITE_REVIEW.md)에 이어 기존 52개 큐의 나머지 35개를 조사했다. **52개 전체의 원인별 검토 자료를 확보했으며 실제 거래 소속·새 객체 경계는 계속 미확정이다.** 운영 키·가격·속성·통계·회귀는 유지했다.

## 나머지 35개의 구분

- **법정동 교차·관측 지번 24개:** 주소별 최신 표제부·K-apt 근거와 실제 거래월을 보존했다. 서로 다른 주소 관측은 실제 단지 관계 인증과 구분한다. K-apt 코드 하나가 일부 주소에만 있는 사례도 전체 단지로 승격하지 않는다.
- **한 필지·복수 관리코드 9개:** 서로 다른 6개 PNU에 해당한다. 같은 필지에 여러 단지·관리 단위가 있거나 코드 별칭이 있을 수 있으므로 자동 분할·병합하지 않는다. 4개 키에서 관리코드 사이 공통 승인일이 관측됐지만 승인일 일치도 별칭 인증은 아니다.
- **개발사업 블록 주소 분양권 2개:** B1·B2 블록의 용암동·운동동 관측 주소 4개를 원문으로 보존했다. `BL-B1`, `BL-B2`를 지번으로 해석하거나 대표 PNU를 만들어내지 않는다. 사업 구역·블록과 실제 필지의 연결 자료가 필요하다.

주소 파티션 **67개**, 기간 거래 **3,726건**을 보존했다. 주소 파티션은 같은 필지의 여러 키에서 반복될 수 있으며 독립 필지 수가 아니다. 원본 조회 대상은 나머지 큐의 서로 다른 60개 PNU와 앞 검토의 두 주소, 총 62개다.

67개 파티션 중 최신 원본 표제부가 있는 것은 **61개**, 비정규 블록 주소는 **4개**, 최신 판본에 표제부가 없는 관측 주소는 **2개**다. 표제부 부재를 건물 부재·철거·거래 오류로 확정하지 않았다.

최신 판본 부재 주소는 가경동 633-5의 분양권 ‘가경 아이파크 5단지’, 봉명동 191-8의 연립다세대 ‘동향주택’이다. 이전 주소·사업 지번·정정 이력 등 별도 관계 증빙이 필요하다. 현재 연결을 자동 교체하지 않는다.

## 앞 검토의 두 주소를 세 판본에서 대조

2024-09, 2025-07, 2026-07 원본 표제부를 직접 읽었다. 세 파일의 전체 행수·SHA-256이 이전 고정 원천 기록과 일치했다.

- **우암동 50-4:** 세 판본 모두 같은 관리 PK 6개가 관측됐다. 공동주택의 세부용도는 연립주택 5행, 공동주택·점포 1행이다. 아파트 거래 유형과 대장 분류 차이는 추가 관계 확인 대상으로 남긴다.
- **서운동 21-7:** 세 판본 모두 같은 관리 PK 3개가 관측됐다. 공동주택 아파트·관리실 및 단독주택이 각각 관측됐다. 주소만으로 세 건축물 중 거래 소속을 선택하지 않는다.

같은 PK가 같은 주소에서 반복된 사실을 확인했지만, 거래와 건물의 관계나 전체 행정코드 변경 이력을 인증한 것은 아니다. K-apt 대표주소 근거가 없는 두 주소를 오류로 확정하거나 거래에서 제외하지 않았다.

## 검증과 보존

신규 분류·관리코드 비교 테스트 6개와 기존 61개, **총 67개 테스트 통과**. 현재 로컬 DB에서 유효·양수 단가·통계 기간을 일치시켜 실제 월별 거래를 읽었고, 기존 키별·주소별 거래수와 PNU 범위를 대조했다. 비정규 주소도 원문 주소 쌍으로 대조해 거래를 보존했다.

표제부 관리 PK 중복 검사, 세 판본 원천 해시 확인, K-apt 원천 해시 보호 및 앞 단계 근거 파일 불변 검사를 통과했다. 이번 원본 조회는 한 번 실행했으며, 별도 검증은 저장 근거의 분류·주소별 거래수·세 판본 관리 PK 교집합을 독립 재계산한다.

원문 근거는 로컬 연구 파일 `data/research/cheongju_ledger/remaining_object_review_evidence.json.gz`에 저장했다. 새 객체 키·대표 PNU를 할당하지 않고, 혼합 키 전체의 가격·속성을 개별 파티션에 승계하지 않는 실험용 보류 게이트를 유지했다.
