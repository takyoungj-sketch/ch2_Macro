## 0. 한 줄

금리와 시중 돈이 늘거나 줄 때, 전국 부동산 거래(몇 건, 얼마)가 **같은 방향으로 움직였는지**를 살펴본다.

앞의 네 그래프는 「그때 시장이 어떻게 생겼나」만 보여 준다. 같이 움직였는지는 **작년 같은 달과 비교한 변화**와 **상관계수 표**로만 말한다. 금리가 거래를 줄였다는 말이 아니다. 앞으로의 예측도 아니다. **지금 본문이 이 질문의 끝도 아니다.**

---

## 1. 누구를 위한 글인가

공개 본문은 **논문이 아니다.** 통계학 기초(평균, 퍼센트, 꺾은선)만 있는 사람이 **대충 훑어도** 다음에 답할 수 있어야 한다.

- 무엇을 물어봤나
- 그림은 무엇을 보나 (무엇을 보지 않나)
- 표의 숫자가 「같이 / 반대로 / 거의 안」 중 어디에 가까운가
- 이 분석이 말하지 않는 것은 무엇인가

회귀, 시계열 이론, 한은 원표 읽는 법은 전제하지 않는다. 어려운 말은 나오자마자 풀어 쓴다. 파일명·API·실험실 로그는 본문에 두지 않는다.

더 알고 싶으면 **물음표**를 먼저 보고, 그래도 모자라면 헤더의 **AI 어시스턴트**(다른 앱과 같은 버튼 하나)에 추가 질문한다. AI는 같은 화면을 쉬운 말로 풀어 준다. 숫자를 새로 계산하지 않는다.

이 글은 **지금까지 본 실험 기록**이다. 결론 절을 두지 않는다. 같은 질문에 실험을 더하면 그림·표·문장이 **뒤에 붙을 수** 있다.

하면 안 됨: 「유동성 인사이트」「금리가 거래를 줄였다」「검증된 동조」「이것으로 확인됐다」.

## 3. 화면에서 읽는 순서

시계열 FAQ의 뼈다. 인구 산점도처럼 **한 시점의 지역 비교** FAQ에는 이 순서를 강제하지 않는다.

```
질문 · 기간 · 짧은 도입
무엇을 확인하나?     질문 · 분석 대상 · 비교 방법 · 상관계수 한 번
시장의 흐름          수준 그래프 4장. 해석 없음
변화율로 비교하기    왜 전년동월인가 → 금리/M2 변화 그래프
숫자로 확인하기      표 4
분석에서 확인되는 패턴  표에서 보이는 결 4개
이 분석의 한계       인과·예측은 여기 한 번
```

방어 문장(인과가 아니다, 결론이 아니다, 읽으면 안 된다)은 **한계와 상관계수 한 문장**에만 둔다. 본문에 반복하지 않는다.

AI는 본문 옆 창이 아니라 **헤더의 공통 버튼** 하나다.

개발 로그(파일명, GROUP BY, 미커밋)는 본문에 두지 않는다.

## 4. 글의 결 (공개 본문)

| 구분 | 규칙 |
|------|------|
| **독자** | 기초 통계. 한 번에 한 생각. 문장은 짧게 |
| **어려운 말** | 본문에 쓰려면 **바로 다음에 쉬운 말**. 예: 상관계수 r → 「두 숫자가 −1~+1 사이로 같이 움직인 정도」 |
| **기호** | `r`·`n`·`as_of`는 표·각주. 본문 첫 문장에 기호를 앞세우지 않음 |
| **영어 약어** | 제목·본문에서 YoY, Pearson, lag를 기본으로 쓰지 않음. 필요하면 괄호 |
| **r 숫자** | 표가 기본. 패턴 ②만 합계 건수 시차 r를 **표와 같은 칸**에서 인용 |
| **질적 문장** | `frontend-insight/src/copy/insight01.ts`. LLM이 보고서 본문을 새로 쓰지 않음 |
| **기간** | **달력 월**만. 연도 표와 월 표를 섞지 않음 |
| **합계** | 「모든 부동산」이 아님. **여덟 유형을 더한 합**이며 규모가 큰 유형에 기울 수 있음. 전제·특징에 적음 |
| **대표 금리** | 본실험 **CD(91일)**. 확인용 국고 3년·기준금리는 전제에만 |
| **건수 / 액** | 본실험 **건수**. 거래액은 같은 뼈의 **둘째 표** |
| **거래액** | 가격지수가 아님. 「몇 건 × 얼마」가 섞인 합 |
| **인과** | 「줄였다」「늘렸다」「민감하기 때문」금지 |
| **결론** | 「결론」「확인됐다」「법칙」금지. 관찰·한계·이어서만 |

연도 1차(해가 열댓 개)는 본문 표에 넣지 않는다. 연·월 합을 **대조한 뒤에만** 「방향이 같다」한 줄 각주를 검토한다.

## 5. 공개 본문

화면 문자열 SSOT: `frontend-insight/src/copy/insight01.ts`. 이 절은 역할만 적는다.

1. **질문·도입** — 제목, 전국·월·기간, 두 문단 도입.
2. **무엇을 확인하나?** — 질문, 분석 대상, 비교 방법. 상관계수=함께 나타난 정도라는 설명은 **여기 한 번**.
3. **시장의 흐름부터 살펴보기** — 수준 4패널. 해석하지 않음. 「먼저 시장의 흐름을 확인합니다.」 캡션은 축 단위 안내만.
4. **변화율로 비교하기** — 규모·추세 때문에 전년동월을 쓰는 이유. 금리 변화 그림, M2 변화 그림. 칩: 거래건수|거래액, 같은 달|1·3·6개월 뒤.
5. **숫자로 확인하기** — 표 4. 표 앞 문장은 copy의 `table1`–`table4`.
6. **분석에서 확인되는 패턴** — 유형 차, 시차가 길수록 약해짐(합계 건수 r는 표와 같은 칸), M2의 유형 차, 건수≠거래액.
7. **이 분석의 한계** — 인과·다른 요인·전년동월 vs 수준·합계의 가중·시차의 뜻. 닫는 문장 한 줄.

수준 패널 제목: 금리 / 유동성 / 거래활동 / 거래규모. 한 그림에 금리·M2·건수·액을 올리지 않는다. 차트 라이브러리 추가 금지.

## 6. 물음표 (`?`)

설명 헌법: **본문 → 물음표 → AI 추가 질문.** AI를 켜야만 기본 뜻을 알게 두지 않는다.

이 페이지에서 물음표를 다는 말. 쉬운 설명을 먼저, 기호는 뒤에. 기존 `pearson_r`을 재사용하고, Insight 전용은 키를 따로 둔다.

| 화면 말 | glossary 키 (가칭) | 한 줄 |
|---------|-------------------|--------|
| 상관계수 | `pearson_r` | 두 숫자가 −1~+1로 같이 움직인 정도. 원인 아님 |
| 작년 같은 달과 비교 | `insight_yoy` | 올해 3월 vs 작년 3월. 장기 성장만으로 같이 커 보이는 것을 줄임 |
| 수준 그래프 | `insight_level` | 그때 얼마였나. 관계의 증거가 아님 |
| 시차 | `insight_lag` | 왼쪽 그달과 오른쪽 몇 달 뒤를 짝. 인과 시점 아님 |
| 합계 | `insight_total` | 여덟 유형 단순 합. 규모가 큰 유형에 기울 수 있음. 부동산 전부 아님 |
| 시중 돈 (M2) | `insight_m2` | 시중에 풀린 돈의 한 지표. 한은 |
| CD 금리 | `insight_cd` | 이 글의 대표 시장금리 (91일) |
| 거래액 | `insight_amount` | 건수×가격이 섞인 합. 집값 지수 아님 |

물음표 본문 뼈: 무엇인가 → 이 글에서 어떻게 쓰나 → 어떻게 읽나 → 주의.

## 8. AI 어시스턴트

다른 앱과 **같은 공통 버튼 하나**다. `AiAssistantPanel`을 헤더 오른쪽에 둔다. 본문 옆 전용 챗창, 본문 아래 질문 칩 줄은 두지 않는다. 추천 질문은 그 버튼 안 패널이 보여 준다.

이 페이지를 보고 **추가 질문**만 받는다. 보고서 본문을 새로 쓰지 않는다. 숫자를 재계산하지 않는다. 결론을 지어 주지 않는다. ([설명 헌법](./CH2_EXPLAIN_CONSTITUTION.md) 제3조 · [AI 헌법](./CH2_AI_CONSTITUTION.md) Facts First · No Recalculation · Limitations First)

### 8.1 역할

| | 본문 | 물음표 | AI |
|--|------|--------|-----|
| 하는 일 | 훑어 읽히는 보고서 | 반복되는 뜻 | 이 화면을 쉬운 말로 더 풀어 줌 |
| 바꾸면 | 이 문서 §5·§7 | glossary | 같은 SSOT를 인용 |
| 하지 않음 | 논문 문체 | 개별 후속 질문 | 새 r 계산, 「왜 토지인가」창작 |

질문 주제를 미리 좁힌 목록만 두지는 않는다. 통계·이 화면·산출·한계는 받는다. 적정가·투자·전망·이 지역 시세는 거절한다.

### 8.2 말투

이용자는 통계 기초만 있다고 가정한다.

- 짧은 문장. 한 답에 한 생각.
- 기호보다 **말**. `r = −0.55`를 인용할 때도 「아래 표에서 토지·같은 달은 반대 방향으로 비교적 크게 붙어 있습니다」를 먼저.
- 수식·그리스 문자·영문 약어 나열 금지. 필요하면 괄호.
- 비유는 짧게 허용. (수준 vs 변화 = 키 vs 올해 얼마나 자랐나)
- 한계를 **한계 질문**에서 한 번 분명히. 본문 설명을 방어 문장으로 시작하지 않음.
- 교수 강의·논문 투고 문체 금지.

### 8.3 화면 맥락 (구현 시)

착수 때 `AiApp`에 `insight`를 추가한다. 공개 창이 랩 API를 부르지 않는 것과 같다.

```
app: insight
panel: Insight01
purpose: statistics
scope.region_label: 전국
explain: §5·§7 고정 카피 + 한계
facts: 화면에 올라 있는 것만
        as_of, 기간, grain=month,
        수준 시계열(합계 건수·액, CD, M2),
        변화 시계열, 표 4장의 r·n
```

Bundle에 없는 칸을 만들지 않는다. 연도 표, 시군구 r, 「왜 토지인가」외부 조사는 facts에 없다.

### 8.4 잘 받는 질문 / 거절

**잘 받는 예**

- 상관계수가 뭔가요? → 물음표와 같은 뜻 + 이 표에서 어떻게 읽나
- 왜 금액 그래프만 보면 안 되나요? → §5.3을 쉬운 말로
- 합계는 모든 부동산인가요? → 여덟 유형을 더한 합. 규모가 큰 유형에 기울 수 있음
- 한 달 뒤·세 달 뒤는 무슨 뜻인가요? → 시차. 인과 시점 아님
- 금리가 거래를 줄인 건가요? → **아니다.** 같이 움직인 정도만. 한계 먼저
- 거래액과 집값의 차이가 뭔가요?
- 시중 돈(M2)이 뭔가요?

**거절·되돌림**

- 앞으로 금리 오르면 거래가 줄까 → 전망. 거절 후 「이 글이 본 것」으로
- 우리 동네는? / 이 단지 살까 → 전국 보고서가 아님. 분석 앱 경로만
- 토지가 유동성에 민감해서 그런가 → 원인 창작 금지. 「더 봐야 하는 차이」
- 표에 없는 r를 구해 달라 → No Recalculation

### 8.5 답 길이 예시 (말투만, 숫자는 화면)

질문: *금리가 거래를 줄인 건가요?*

> 아닙니다. 이 글은 **원인**을 본 적이 없습니다.  
> 같은 달의 금리 변화와 거래 건수 변화가, 어떤 유형에서 반대로 붙어 있는지를 본 기록입니다.  
> 경기·정책·공급도 거래에 붙을 수 있고, 여기서는 그것들을 빼 보지 않았습니다.  
> 표 1의 오피스텔·연립다세대·토지·같은 달을 보시면, 반대 방향이 아파트보다 크게 나옵니다. 분양권은 거의 붙어 있지 않습니다. 합계도 음의 방향입니다.

질문: *왜 앞의 네 그래프만으로는 부족하나요?*

> 시중 돈과 거래액은 해가 갈수록 커지는 일이 많습니다.  
> 실제 금액만 보면 둘 다 커져서 같이 늘어난 것처럼 보일 수 있습니다.  
> 그래서 작년 같은 달보다 **얼마나 달라졌는지**를 따로 봅니다.

### 8.6 추천 질문 (공통 AI 패널 안)

버튼 안 제안 질문. 본문에 따로 칩을 깔지 않는다.

1. 상관계수가 뭔가요?
2. 왜 금액 그래프만 보면 안 되나요?
3. 합계는 모든 부동산인가요?
4. 한 달 뒤는 무슨 뜻인가요?
5. 금리가 거래를 줄인 건가요?

시작점이다. 이용자가 다른 통계 질문을 쳐도 받는다. 「이 실험의 결론은?」에는 결론이 없다고 답한다.

## 9. 데이터 · API

실험 계산은 G3와 **동일**하다. `compute_macro_ts(..., grain="calendar_month")`. 공개 창이 랩 URL·랩 API를 부르지 않는다.

거래 건수·액 출처: 정제 원장 GROUP BY가 아니라 국토부 CSV 전국 월 마트. [`lab/MACRO_TS_RAW_MONTH_MART.md`](./lab/MACRO_TS_RAW_MONTH_MART.md). 로컬 마트 게이트 통과(2026-09-16). 공개 표·본문은 이 마트로 다시 계산한 r에 맞춘다.

|------|-----------|
| 공개 경로 예: `GET /api/insight/01` 또는 커밋된 월 스냅샷(시계열+pairs+`as_of`) | `GET /api/regional-profile/lab/macro-ts` 를 브라우저에서 직접 |
| 페이로드: 기간, 수준 `values`, 변화율/`d_pp`, pairs, sources, coverage_notes | 파일명만 본문에 나열 |
| 지금 `docs/lab/macro_ts_monthly_run.json`은 **r만**. 수준·변화 선을 쓰려면 시계열을 넣은 공개 스냅샷을 **새로** 뽑음 | 손 CSV |

권한: `/insight/`와 같은 제품 창. 랩 Basic Auth가 아님. 런칭 전 사이트 비밀번호는 다른 앱과 같음.

성능: 월 GROUP BY가 느리면 스냅샷을 빌드에 심거나 얇은 마트를 둔다. 요청마다 원장 스캔이 기본이 아니게 한다.

AI `facts`는 이 공개 페이로드와 **같은 숫자**다. 랩 전용 연도 표를 몰래 넣지 않는다.
