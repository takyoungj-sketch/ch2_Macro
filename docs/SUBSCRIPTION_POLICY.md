# CH2 구독 정책 (D-086)

> **상태:** 정책 SSOT · 구현·검수 중, 운영 적용 전
> **결정일:** 2026-11-19
> **결정:** [D-086](./DECISIONS.md#d-086-통합-구독-1만-원30일-체험웹-토스), **D-052 대체**
> **정책 원본:** `CH2_SHARED_OPS/tasks/FN-000/DECISION.md` (§5 포함)
> **시행일:** FN-002·FN-006·FN-007 통합 운영 배포일. 환불 문구는 T의 전문가 확인 뒤 공개.
> **기능 게이트:** [`CH2_ENTITLEMENT.md`](./CH2_ENTITLEMENT.md) (D-080·D-086)
> **공개 페이지:** `/subscription/`, `/refund/`, `/terms/`

## 1. 상품과 무료 범위

- Macro + FieldNote 통합 1종, **월 10,000원**(상시). 단독 상품·15,000원 통합 상품은 폐지한다. 연간 구독·기간 할인은 없다.
- Viewer는 무료다.
- 비로그인 무료: Macro 토지·집합 기본통계(기본 조건 5년 롤링 포함, D-080)와 FieldNote 기록(촬영·메모·녹음·GPS·저장·PC 내보내기·백업).
- Macro 고급 기능, FieldNote 지도 허브·AI(사진 분석·주소표 AI 변환·문구 작성)는 체험·유료 이용 기간에 제공한다. 관리자 전용 비공개 기능(D-085)은 별도다.
- 체험·구독 종료 후 지도 허브·AI는 제공하지 않는다. 기존 지도 허브 프로젝트의 기록 목록 열람·조사 탭으로 열기·내보내기·백업은 허용한다. 지도 위 동선 화면과 새 지도 허브 만들기는 잠근다. 기록 데이터는 삭제하지 않는다.

## 2. 30일 체험

- 가입하면 **카드 없이 30일**. 체험 만료 시각 = `max(가입 시각, 정책 시행 시각) + 30일`. 기존 가입자도 같은 식을 적용하고 중복 지급하지 않는다.
- 체험 중 카드 등록은 청구가 아니다. **첫 청구는 체험 만료 시점**이며 체험 기간을 앞당기지 않는다.
- 카드 미등록 또는 첫 청구 처리 전 해지 시 체험 종료 후 청구하지 않는다.
- 체험 AI 한도는 30일 동안 한 번: 사진 분석 125장, 문구 25회, 주소표 25회, Macro 질문 60회. FN-000 §5-3의 출발값이며 실제 비용을 보고 조정한다.
- 유료 AI 잠정 기준: 사진 500장, 문구 100회, 주소표 100회, Macro 질문 250회/월. 계정 단위 서버 한도. 체험에서 유료로 전환하면 새 기간이다.

## 3. 결제와 이용 기간

- **웹 토스페이먼츠 카드 자동결제만** 제공한다. 앱에는 결제 기능과 웹 결제 안내를 두지 않는다. Play 결제 코드는 비활성화하고 운영 stub를 차단한다. 별도 계좌이체 상품은 이번 정책에 두지 않는다.
- 체험 뒤 카드 등록 시 결제를 진행하고 승인 후 유료 이용권을 부여한다.
- 이용 기간은 **한국 시간 기준 달력 한 달**(같은 날·같은 시각, 그 날이 없는 달은 말일). 31일 고정 계산 금지. 최초 기준일을 유지하여 1/31 → 2월 말일 → 3/31로 계산한다.
- 체험 만료·월 갱신 경계에서 결제 승인 전 유료 기능 유예는 없다. 갱신 작업은 10분마다이며 토스 응답 시간만큼 더 지연될 수 있다. 결과 불명은 확인될 때까지 이용권을 주지 않는다.

## 4. 해지

- 일반 해지는 **다음 자동결제 중단**이다. 위약금 없이 이미 결제한 남은 기간을 이용한다. 환불과 구분한다.
- 처리 전 해지: 미승인 확인 후 추가 청구 없이 종료. 체험 중 첫 청구 전 해지하면 체험 만료까지 이용하고 청구하지 않는다.
- 처리 중 해지: 그 기간 청구는 진행한다. 승인되면 해당 기간 이용, 다음 자동결제부터 중단한다.
- 결과 불명 뒤 해지: 다음 조회에서 이미 승인됐으면 해당 기간 이용·다음 자동결제 중단, 미승인이면 추가 청구 없이 종료한다.

## 5. 환불 (전문가 확인 전 초안)

- 해지와 별도 요청. **남은 유료 이용 기간 일할 환불**, 관리자 수동 처리로 시작한다.
- 남은 기간 정산·토스 부분 취소·이용권 회수(구독 행과 이용권 미러)를 같은 날 맞춘다. 운영 DB 쓰기는 T 승인 절차에 따른다. 환불 자동화는 FN-002 범위가 아니다.
- 7일 청약철회 등 법정 권리를 보장한다. 정확한 법적 의무·정산 기준은 전문가 확인 후 약관 확정. 탈퇴 시에도 일률적으로 환불을 배제하지 않는다.
- `/refund/` 맨 위 초안 주석과 화면 표시를 유지한다. T 전문가 확인 전 공개 금지. 구체적 질문은 `CH2_SHARED_OPS/tasks/FN-007/RESULT.md`에 둔다.
