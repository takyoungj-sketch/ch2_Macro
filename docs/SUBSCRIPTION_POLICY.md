# CH2 구독 정책 (방향 확정)

> **상태:** 방향 SSOT  
> **일자:** 2026-08-28 (D-052 개정: 둘 다 15,000원, 무료체험 1개월)  
> **결정:** D-052  
> **기능 게이트(무료/유료 화면):** [`CH2_ENTITLEMENT.md`](./CH2_ENTITLEMENT.md) (D-043)  
> **공개 페이지:** `/subscription/`, `/refund/`, `/terms/`, `/privacy/`

지금 단계에서는 장기 할인으로 묶는 것보다 **상품 구조와 결제 흐름을 단순하게** 유지한다. 웹 실결제는 토스 심사 후.

---

## 1. 가격 (월 구독만)

| 구독 상태 | 월 금액 | 의미 |
|-----------|---------|------|
| 제품 1개 (Macro **또는** FieldNote) | 10,000원 | 단독 |
| 제품 2개 (Macro **and** FieldNote) | 15,000원 | 둘째 +5,000원 |
| Viewer | 0원 | 구독 대상 아님 |

- **연간 구독 없음.** 유지율 데이터를 본 뒤에만 재논의.
- 세 번째 제품 가격은 정하지 않는다.
- 토스가 “할인 쿠폰”을 붙이지 않는다. 청구 금액이 1만 또는 1.5만이다.

---

## 1.1 무료 체험

CH2 계정(Google 또는 Kakao)으로 Macro·FieldNote 유료 기능을 **1개월** 무료 이용. Viewer는 원래 무료라 체험 대상이 아님. 체험 중 해지·탈퇴 시 이용료 없음. 체험 종료 후 유지하려면 결제.

---

## 2. 구독 모델 — CH2 계정 하나

사용자는 제품을 켜고 끄고, **결제는 구독 한 줄**이다.

```
CH2 계정
  └── 구독 (최대 1개)
        ├── Macro on/off
        ├── FieldNote on/off
        ├── 금액 10,000 | 15,000
        └── source  play | web | bank_transfer
```

금지: Play FieldNote와 웹 Macro를 **동시에 과금**. 합치면 1만+1만이 되어 1.5만 정책과 모순이다.

---

## 3. 결제 채널

### 3.1 웹 (복수 제품의 중심)

`ch2data.com` 구독 관리. 한 결제 수단, 금액은 체크된 제품 수에 따라 1만 또는 1.5만.

| 수단 | 역할 |
|------|------|
| **토스페이먼츠** | 웹 기본 PG. 카드·간편결제. **카카오페이는 토스 상점의 결제 수단**으로 켠다 (별도 카카오 상점 과금 아님). |
| **카카오페이 단독 PG** | 토스 심사가 거절되거나 카카오페이를 토스에서 못 켤 때만 검토. |
| **계좌이체** | 운영자가 지정한 **CH2 계좌**로 입금. 자동 CMS가 아님. 입금 확인 후 권한. 법인·세금계산서용 예외 채널로 우선. |

토스 심사는 2026-08 신청, 승인 후 키 연동.

### 3.2 앱 (FieldNote 단독만)

FieldNote Android **만** 쓰는 사람은 Google Play 월 10,000원.

둘 다 쓰려면 웹 통합 구독(15,000원)으로 옮긴다. 앱 설정에서 Play 구매와 웹 구독이 **동시에 출금되지 않게** 막는다.

Play로 FieldNote만 쓰는 사람이 Macro를 추가하면 **기다리지 않는다.**

- 이번 결제기간(이미 낸 1만)으로 **두 제품 즉시 사용**. 추가요금 없음.
- Play 구독은 사용자가 **지금 해지**(해지해도 Google은 만료일까지 FieldNote 유지).
- **다음 결제일**부터 웹에서 15,000원 한 줄. 그날 Play가 1만을 또 받으면 안 된다.

금지: Play 1만이 살아있는 채로 웹에서 Macro 1만 또는 +5천을 **따로 출금**. 사용자에게는 요금제 변경이고, 내부는 만료일에 source를 play→web으로 바꾼다.

**구글에서 안 내도 되나 (장소만):**

| 누가, 어디서 | 결제 |
|--------------|------|
| 앱 안에서 FieldNote만 산다 | **반드시 Play.** 앱에 웹 결제 버튼·「웹이 더 싸요」 금지 |
| 웹에서 Macro만, 또는 둘 다 15,000원 | **웹 (토스·카카오페이 수단·계좌).** 앱은 로그인만 |
| Play FieldNote 쓰다가 웹에서 Macro를 붙인다 | 전환은 **ch2data.com**에서. Play 해지는 Google 구독 화면. 앱이 웹 결제로 보내지 않음 |

앱은 디지털 구독을 Play로 파는 상점이다. 웹에서 이미 산 CH2 이용권을 로그인으로 쓰는 것은 별 채널이다. 둘을 앱 안에서 한 결제처럼 갈아타게 하면 Play 정책과 맞는다.

한국 「개발자 제공 결제」는 등록·보고가 있어 지금은 쓰지 않는다. 심사가 막히면 앱 IAP를 끄고 결제는 전부 웹(W안).

> 지금은 **P안**(단독=Play, 둘 다=웹). 앱 안 FieldNote Pro를 웹 결제만으로 켜거나, 앱이 웹 결제를 유도하면 리스크다.

### 3.3 계좌이체 운영 (방향)

- 구독 화면에 계좌·입금 금액·입금 메모(예: `CH2-{user_id}-{YYYYMM}`)를 보여 준다.
- 운영자가 입금 확인 후 해당 월 권한을 켠다 (Admin 또는 게시판 접수).
- 다음 달 미입금이면 만료일에 권한 종료. 일할 환불 없음.
- 월마다 이체해야 하므로 자동 카드/페이보다 CS가 많다. **기본 경로는 토스(+카카오페이 수단)** 이고, 이체는 요청 시에 연다.

## 4. 추가·해지 공통 규칙

중간 환불·일할 정산 없음. 해지·탈퇴 시 이미 시작된 이용기간 환불 없음.

| 행동 | 지금 | 다음 결제일 |
|------|------|-------------|
| 제품 추가 | **즉시 사용**. 이번 기간 요금은 그대로(추가요금 없음) | 켜진 제품 수로 1만 또는 1.5만 |
| 제품 해제 | 이번 기간 끝까지 사용 | 남은 제품 수로 1만 (없으면 종료) |

예: 10월 1일 Play FieldNote 1만 → 10월 10일 Macro 추가 → 10월 10일~만료일까지 둘 다 사용(추가 0원) → 다음 결제일 웹 15,000원.

예: 10월 1일 웹 15,000원 → 10월 15일 Macro 해제 → 만료일까지 둘 다 사용 → 다음 결제일 FieldNote 10,000원.

## 5. 상태와 전이

| 상태 | Macro | FieldNote | 금액 | source |
|------|-------|-----------|------|--------|
| none | off | off | 0 | — |
| fn_play | off | on | 10,000 | play |
| web_one | 둘 중 하나만 on | | 10,000 | web 또는 bank_transfer |
| web_both | on | on | 15,000 | web 또는 bank_transfer |

| 지금 | 하려는 일 | 결과 |
|------|-----------|------|
| none | 웹에서 Macro 또는 FieldNote | web_one, 이번 달 1만 |
| none | 앱에서 FieldNote | fn_play |
| web_one | 다른 제품 체크 | web_both. 추가는 즉시 사용, 다음 청구 1.5만 (일할 없음) |
| web_both | 하나 해제 | 다음 결제일부터 1만. 이번 달은 이미 낸 달 |
| fn_play | Macro 추가 | Macro **즉시**. Play는 해지(만료일까지 FN). 다음 결제일 web_both 15,000원 |
| any | 해지·탈퇴 | 만료일까지 사용, **부분 환불 없음** |

## 6. 환불

- 월 구독만 있으므로 “이번 달분은 사용, 다음 결제일부터 해지”.
- 탈퇴해도 이미 시작된 이용기간은 환불하지 않는다.
- 무료 체험 중 해지·탈퇴는 이용료 없음.
- Play 환불은 Google 절차. 웹(토스·카카오페이)은 이용 개시 후 환불하지 않는 것이 회사 원칙. 결제 착오만 취소.
- 연간·교차 채널 일할 정산은 만들지 않는다.

---

## 7. 구현 시 스키마 방향 (아직 적용하지 않음)

계정당 구독 **1행**. `items(macro, fieldnote)` + `amount_krw` + `source(play|web_toss|bank_transfer)`.  
지금 DB의 `product=bundle`·연간 SKU는 이 정책과 맞지 않으니 구현 때 정리한다. 번들 월 금액은 **15,000**.

---

## 8. 하지 않음 (지금)

- 연간 구독·연간 할인
- Play 10,000이 **갱신되는 동안** 토스 5,000 또는 10,000을 또 출금
- 토스와 카카오페이를 **서로 다른 상점**으로 이중 과금
- 둘째 추가를 다음 달까지 기다리게 하기 (사용은 즉시, 요금만 다음 결제일)
