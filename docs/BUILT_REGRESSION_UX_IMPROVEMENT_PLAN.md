## 1. 범위와 전제

이 문서는 세 분석 영역의 정보 구조, 조작 편의성, 가시성, 결과 표시 정확성, 화면 설명문구를 함께 개선하기 위한 구현 기준안이다. 통계 엔진의 결과를 문체 수정으로 덮지 않는다. 표시 산식이나 비교 기준이 잘못된 항목은 계산·응답 계약부터 확인하고 수정한다.

- **기본회귀:** 사용자가 선택한 변수·척도·표본 조건으로 적합한 결과를 확인한다.
- **Macro 모형 탐색:** 기존 `Macro 모형 탐색` 섹션의 `창 열기 / 결과 보기`가 대상이다. 예측형·설명형·쌍둥이 확장을 검토한다.
- **상위지역 재적합:** 상위 행정 단위 표본에서 별도로 적합한 결과를 참고한다. 모형 조합을 다시 찾는 Macro 재탐색과 구분해 **재적합**으로 명칭을 통일한다.
- **모형추천2:** 사용자는 기존 모형추천을 대체하지 못하는 것으로 결정했다. 이 개선안은 추천2로의 교체·통합·승격을 포함하지 않는다. 추천2의 별도 존치·삭제도 이번 문서에서 정하지 않는다.
- Macro·Twin·상위지역 결과가 기본회귀의 변수·척도·지역을 자동으로 변경하지 않는 원칙을 유지한다.
- 본 문서는 제안서다. 코드 구현, 배포, 계획일지 갱신 또는 새 결정 번호 발급을 완료했다는 의미가 아니다.

기존 [회귀 분석 UI 문서](BUILT_REGRESSION_ANALYSIS_UI.md)는 세로 섹션 중심의 이전 설계 기록이다. 이번 화면에서는 Macro 안에 **예측형·설명형·쌍둥이 확장 탭**이 확인됐다. 이전 문서를 근거로 탭을 제거하거나 기존 동작을 되돌리지 않는다. 구현 시 엔진 규칙은 [추천 엔진 설계](CH2_RECOMMENDATION_ENGINE_DESIGN.md), [후보 평가 설계](CANDIDATE_EVALUATION_DESIGN.md) 및 실제 코드와 대조한다.

## 2. 검토 사례와 증거의 한계

### 2.1 화면에서 확인한 조건

- 서울특별시 서초구 방배동 / 상업 / 7년 / 기본회귀 선형.
- 건축물대장 보강 켬, 지분거래 제외, IQR×3, 범주 결측 미상 유지.
- 기본회귀 적합 136건, 학습 MAPE 49.49%, CV-MAPE 25.22%.
- Macro 탐색 표본 168건, 예측형 1위 log-log, 탐색 CV-MAPE 22.67%, 확인 CV-MAPE 20.63%.
- Macro 1위 탐색 검증: 2021~2025년 126건 / 마지막 연도 확인: 2026년 11건.
- 상도동 한 곳 추가 시 Twin1 적합 266건, 탐색 CV 34.2%, 확인 CV 30.1%, 화면 결론은 현재 지역 기준 유지.
- Twin2 재탐색 적합 256건, 탐색 CV 36.8%.
- 상위지역 서초구: 조회 873건, 숫자 결측 제외 263건, 적합 610건.
- 다크 테마·글자 100%에서 확인했다. 밝은 테마·작은 창·글자 확대는 구현 후 별도 검증 대상이다.

### 2.2 확인 수준 구분

- **확인된 오류:** 계수 표·해설 간 100배 차이, 로그 종속변수의 범주 효과를 만원으로 표시, 절편을 기여 변수로 소개, 상위지역 비교표의 공시지가 누락, 예시 입력창의 표본 표기 불일치.
- **화면에서 확인한 혼동:** 검증 연도·건수가 다른 후보에 동일한 성능 유사 라벨, 추천 기준선과 선택 후보의 동시 표시, 기준 범주 변경을 찾기 어려움.
- **추가 확인 필요:** 잔차의 ‘전체 대비’가 어떤 집단을 기준으로 계산되는지, 표본 중첩 안내가 실제 행 집합과 일치하는지, Twin 간 검증 대상이 일치하는지. 현재 문구만으로 통계 엔진 오류라고 단정하지 않는다.
- 값을 입력해 산출한 예측값·구간의 정확성 전체를 검증한 것은 아니다. 입력 UI와 모형·표본 표기를 확인했다.

## 3. 공통 화면 구조와 문체

### 3.1 정보 우선순위

각 영역을 **무엇을 분석했는가 → 표본·검증 조건 → 주요 결과 → 해석 제한 → 상세** 순서로 읽게 한다. 계수 식별 문제가 있으면 주요 결과보다 먼저 알린다.

분석 조건은 결과와 함께 보존한다. 화면의 현재 필터와 결과 생성 조건이 달라지면 `조건이 변경되었습니다. 다시 분석하면 결과에 반영됩니다.`라고 표시한다. 마지막 분석 시각도 함께 제공한다.

### 3.2 문체 기준

1. 설명은 `~입니다 / ~합니다`, 안내는 `~할 수 있습니다 / ~을 확인하세요`로 통일한다. 버튼은 `계수 상세 보기`, `결과 접기`처럼 동작을 짧게 쓴다.
2. ‘식이 틀리나’, ‘값’, ‘이 열’, ‘행’, ‘접두’, ‘pool’ 대신 사용자가 이해할 대상·동작을 쓴다. 통계 용어가 필요하면 쉬운 이름을 앞에 두고 원어를 병기한다.
3. 관찰된 관계, 검증 결과, 해석 한계를 구분한다. 부호 일치가 모형 안정성을 입증하거나 AIC 1위가 정답인 것처럼 쓰지 않는다.
4. 확인된 탐색 범위 안의 결과임을 밝힌다. ‘가장 잘 예측하는 식’, ‘최적식’, ‘광평수 외삽에 유리’ 같은 일반화는 검증 근거 없이 사용하지 않는다.
5. 음수와 하락을 중복 표현하지 않는다. `약 -46.5% 낮음` 대신 `약 46.5% 낮음`으로 쓴다. 숫자 열에서는 부호를 유지한다.
6. 한 문장에는 핵심 한 가지를 담는다. 핵심 결론은 본문에, 계산 정의·예외·검정 가정은 해당 지표의 `?`에 둔다. `?`만으로 기본 의미와 산출방식을 이해할 수 있게 한다.
7. 같은 제한 문구를 카드마다 반복하지 않는다. 공통 안내는 영역당 한 번, 후보별 제한은 해당 후보 가까이에 둔다.
8. `**변수명**` 같은 마크다운 원문을 노출하지 않는다. 안전한 구조화 텍스트나 렌더링 컴포넌트로 표현한다.
9. `등분산 유지`, `나머지와 다른 집단이 없습니다` 같은 확정형 표현을 검정이 제공하는 근거 수준에 맞춰 쓴다.
10. 가격·매수·투자 판단 대신 통계적 관계와 참고 추정이라는 제품 정체성을 유지한다.

### 3.3 용어 표준

- 기본회귀 제목: **기본 회귀 분석**. 종속변수와 단위는 부제에 표시한다.
- Macro 제목: **Macro 모형 탐색** 유지.
- 상위지역 제목: **상위지역 재적합** 유지. ‘상위지역 재탐색’과 혼용하지 않는다.
- 적합 n: **적합 표본 n건**.
- 학습 MAPE: **학습 오차(MAPE)**.
- 탐색 CV: **탐색 검증 오차(CV-MAPE)**.
- 확인 CV: **마지막 연도 확인 오차**. 해당 연도·검증 건수도 표시한다.
- Local: **현재 지역 기준**. 필요한 상세에서만 `Local`을 병기한다.
- Twin1: **지역 확장 · 같은 변수로 재적합**.
- Twin2: **지역 확장 · 변수 조합 재탐색**.
- complete-case / 행: **선택 변수에 필요한 값이 있는 거래 / 분석 거래**.
- 더미 열 수: **범주 계수 수**. 정확한 의미는 `?`에서 기준 범주 제외와 함께 설명한다.

복합·집합 공통 표시 계약:

- 학습 오차와 검증 오차는 실제 계산 기준에 따라 별도로 표시한다. CV 불가 시 학습값을 같은 ‘검증 오차’ 자리에 조용히 대체하지 않는다.
- 검증 오차에는 시계열 검증·무작위 5분할 등 실제 방법과 검증 거래 수를 붙인다. 방법이 다른 오차를 같은 성능으로 직접 비교하지 않는다.
- 추정 영역은 **조건별 통계적 추정**, 버튼은 **추정값 계산**, 구간은 **95% 평균 추정범위 / 95% 개별 거래 예측범위**를 기본으로 한다. 실제 산식이 이 의미와 일치하는지 먼저 확인한다.
- 모형·분석 조건이 바뀌면 이전 추정 결과를 무효화하거나 이전 조건의 결과임을 분리한다. 결과에는 계산 당시 모형·입력 스냅샷을 보존한다.
- 이 공통 계약은 표시와 설명의 일관성에 관한 것이다. 집합에 복합의 검증 방식·AIC 기준·Macro 비대체 동작을 자동 도입하지 않는다.

### 3.4 공통 가시성·조작 규격

- 본문·표는 기본 13~14px 수준을 목표로 하고, 표의 핵심 수치를 10~11px 보조 글씨로 내리지 않는다.
- 다크 테마의 회색 설명과 경고 색을 점검한다. 일반 텍스트 명암비 4.5:1 이상을 검증한다.
- 색 외에 `선택됨`, `확인 불가`, `해석 주의` 등의 텍스트·아이콘을 함께 사용한다.
- 수치는 오른쪽 정렬, 자리 폭 고정 숫자, 천 단위 구분을 적용한다. 작은 p값은 임계치 미만으로 표시하고 작은 계수는 유효숫자·지수 표기로 보존한다.
- 표의 가로·세로 스크롤 중첩을 줄이고 `크게 보기`를 제공한다. 표 제목·열 이름을 유지한다.
- 예측 입력은 여러 줄로 배치하고 단위를 각 필드 옆에 표시한다. 오른쪽 밖에 범주 선택을 숨기지 않는다.
- 최소화·전체화면·닫기·복원, Esc, 포커스 이동을 검증한다. 앱 헤더가 모달 도구를 가리지 않아야 한다.
- 공통 셸·탭·글자·버튼 형식 변경은 [5앱 형식 패리티](../.cursor/rules/five-app-format-parity.mdc)를 적용한다. 같은 위젯이 있는 토지·복합·집합·임대·지역프로필을 점검하고, 집합은 주거·비주거를 함께 확인한다. 도메인 산식까지 임의로 통일하지 않는다.

## 4. 기본회귀 개선

### B-01. 결과 요약과 식별 경고 [P0]

관찰: R²·Adj R²·학습 MAPE·CV-MAPE·유의 개수·F p가 비슷한 크기로 흩어져 있다. 식별 경고 아래에 회귀식과 유의 계수가 정상 결과처럼 이어진다.

개선:

- 적합 표본, 설명력, 학습 오차, 검증 오차를 묶어 표시한다. 학습 오차와 검증 오차에는 산출 대상 차이를 붙인다.
- 모형 식별 경고를 별도 상태로 표시하고 계수 상세·예측 영역에도 연결한다.
- 회귀식과 유의 개수는 식별 제한을 제거한 것처럼 강조하지 않는다. 예측 제공 여부는 기존 엔진 계약에 따라 판단하고, UI가 독자적으로 금지·허용 기준을 만들지 않는다.

권장 카피:

> 계수 해석에 주의가 필요합니다. 일부 변수가 겹쳐 계수가 하나로 정해지지 않습니다. 변수별 효과를 해석하기 전에 변수 구성을 확인하세요.

설계 열 수·독립 계수 수는 상세 근거로 제공한다. `유의 변수 7개`는 집계 단위를 확인해 `유의한 계수 7개(p<0.05, 절편 제외)`처럼 실제 기준을 함께 표시한다. 회귀식 표시 기준 p<0.10과 혼동하지 않게 한다.

### B-02. 회귀식·계수 상세 [P0/P1]

- 원계수 β와 해석을 `변수 / β / 효과 해석 / SE / t / p`로 분리한다.
- 연속변수·용도지역·구조·도로조건을 묶고 각 그룹의 기준 범주를 상단에 둔다. ‘기타·미상’을 단독 라벨로 반복하지 않는다.
- 기본 회귀식에서 생략한 항목 수를 명확히 표시한다. 전체 회귀식 보기·복사 기능을 제공한다.
- ‘유의 계수만 표시’는 모형에서 나머지 변수를 제외했다는 뜻이 아님을 설명한다.
- 로그 공시지가를 범주형 ‘기준 대비’로 설명하지 않는다. 종속변수·설명변수의 변환 조합별로 효과 해석을 분기한다.

카피:

> 다른 변수가 같을 때의 관계입니다. 변수 변화가 가격 변화를 직접 일으킨다는 뜻은 아닙니다.

> 회귀식에는 p<0.10인 계수만 표시했습니다. 나머지 변수도 적합과 예측 계산에 포함됩니다.

수학적 표시 계약:

- 선형 금액·일반 연속변수: 설명변수 1단위 증가에 대한 β만원 변화.
- 로그 금액·일반 연속변수: 설명변수 1단위 증가 시 `(exp(β)-1)×100`% 변화.
- 로그 금액·로그 면적: 면적 1% 증가 시 `(1.01^β-1)×100`% 변화. 근사 탄력성 β와 구분한다.
- 선형 금액·로그 공시지가: 공시지가 1% 증가 시 `β×ln(1.01)`만원 변화.
- 로그 금액·로그 공시지가: 공시지가 1% 증가 시 `(1.01^β-1)×100`% 변화.
- 로그 금액의 범주 계수: 기준 범주 대비 `(exp(β)-1)×100`% 차이. 만원 단위로 표시하지 않는다.
- 절편은 변수 효과·기여도 순위에서 제외한다. 모든 설명변수가 0인 조건과, 로그 설명변수의 원값이 1인 조건을 혼동하지 않는다. 실제 적용하기 어려운 출발 조건이면 이를 명시한다.

### B-03. 산점도와 잔차 진단 [P1]

- 상관관계·부분회귀도에 축 이름·단위·분석 표본을 명시한다. 탐색 표본과 적합 표본이 다르면 이유를 표시한다.
- 작은 산점도가 카드 경계를 넘지 않도록 반응형 배치를 적용한다.
- 잔차 그래프에 세로축 눈금, 0%선, 범위 밖 점의 범례·건수를 표시한다. 점의 실제 값은 상세로 확인할 수 있게 한다.
- 음수 예측이 있으면 건수와 해석 제한을 표시한다. 표시 범위에서 잘린 점을 정상 범위 안의 관측처럼 보이게 하지 않는다.
- ‘전체 대비’의 계산 기준을 백엔드와 확인한다. 나머지 표본과의 차이라면 `다른 거래 대비 중위 오차 차이(%p)`처럼 정확히 명명한다. 단순히 전체 중위 오차를 뺀 값이라고 설명하지 않는다.
- 금액대·집단별 표의 중위 절대오차, 산포, MAPE 정의를 각각 `?`로 제공한다. 산포 수치를 일반적인 예측 오차처럼 읽게 하지 않는다.
- 금액대별 표의 `중위 금액`은 실제 필드가 예측금액 중위값임을 확인한 뒤 **예측금액 중위값**으로, `중위 절대오차`는 **절대오차율 중위값(%)**으로 명명한다. 산포는 실제 산출 통계량을 확인해 **오차율 표준편차(%)** 또는 해당 정의에 맞는 이름으로 쓴다. 통계량을 확인하기 전에 표준편차라고 단정하지 않는다.
- 집단 비교에서 유의한 차이가 확인되지 않은 상태와 차이가 없음을 입증한 상태를 구분한다.
- 영향 거래에 거래 식별정보와 해당 거래로 이동하는 동작을 제공한다. 이름만 같은 행들을 구별할 수 있어야 한다.
- ‘금액대별 오차 / 집단별 오차 / 영향 거래’로 구역을 나누고 하단 접기를 제공한다.

카피 수정:

- `잔차 진단 — 이 식이 어디서 틀리나` → **잔차 진단 — 오차가 큰 조건 확인**.
- `이 거래를 뺐을 때 계수 변화` → **영향 거래 제외 시 계수 변화**.
- `등분산 유지` → **이 검정에서는 이분산을 뒷받침하는 근거가 뚜렷하지 않습니다(p={p}).**
- `나머지와 다르게 틀리는 집단이 없습니다` → **설정한 검정 기준에서 다른 거래와의 차이가 확인된 집단은 없습니다.**
- `전체 대비가 읽을 숫자입니다` → **집단 간 오차를 비교할 때는 ‘{정확한 비교 지표명}’을 확인하세요.**
- `작은 거래의 예상값은 넓게 보세요` → **예측금액이 낮은 구간에서 오차 산포가 크게 관찰됩니다. 해당 구간의 추정값은 예측범위와 함께 확인하세요.**

`+300%는 불가`라는 기존 안내는 음수 예측이 있을 때도 성립하는지 확인한다. 현재 정의가 `(실제−예측)/실제×100`이고 실제가 양수라도 예측이 음수면 100%를 넘을 수 있다. 모델·값의 조건 없이 상한을 단정하지 않는다.

## 5. Macro 모형 탐색 개선

### M-01. 현재 구조 유지와 추천·선택 상태 분리 [P1]

예측형·설명형·쌍둥이 확장 탭과 후보 비교표를 유지한다. 상단에는 `추천 기준선 #1`, 상세에는 `현재 확인 중인 후보 #2`를 구분한다. 선택 표시가 추천 확정으로 오인되지 않도록 한다.

탭은 스크롤 중에도 접근 가능하게 유지한다. 후보 선택 시 상세 제목으로 이동하는 동작을 제공하되 키보드 포커스를 잃지 않는다. ‘기본회귀를 변경하지 않음’ 안내는 창 상단 한 곳에 두고 반복을 줄인다.

### M-02. 검증 범위가 다른 후보의 비교 [P0]

관찰: 1~3위는 탐색 검증 2021~2025년 126건, 4위는 2021~2023년 85건이며 확인 결과가 없다. 4위에도 ‘성능 유사’가 표시된다.

- 후보별 적합 표본과 검증 거래·연도·유효 fold를 구분한다.
- 같은 적합 표본 수라는 이유만으로 검증 대상도 같다고 보지 않는다.
- 검증 범위가 다르면 `검증 범위 다름`을 표시한다. 동일 기준 비교가 불가능하면 ‘성능 유사’ 또는 정밀한 우열 라벨을 보류한다.
- 순위 산정·유사 후보 판정의 변경이 필요하면 엔진 계약과 함께 검토한다. 화면 문구만 바꾸고 비교 오류를 남기지 않는다.
- 마지막 연도 확인 결과를 보고 후보를 다시 고르도록 유도하지 않는다. 탐색에서 고른 후보를 별도 확인한다는 역할을 유지한다.
- 확인 불가 사유는 `계산 없음`이나 원인 여러 개를 나열한 공통 문장 대신 실제 상태로 나눈다: 연도 부족 / 학습 표본 부족 / 적합 실패 / 미실행.

카피:

- `차이(%p)` → **탐색 1위 대비 오차 차이(%p)**.
- `성능 유사` → **탐색 오차 유사**. 설명: `같은 검증 대상에서 탐색 오차 차이가 {기준}%p 이내입니다. 통계적 동등성을 의미하지 않습니다.`
- `— / 0건` → **확인 불가** + 해당 사유.
- `거래가격을 가장 잘 예측하는 식입니다` → **탐색한 후보 중 검증 오차가 가장 낮은 모형입니다.**
- `예측 최소` → **탐색 오차 최소 후보**.
- `확인 CV로 대표모형 확정을 가릅니다` → **탐색 검증으로 후보를 고른 뒤, 마지막 연도 거래로 적용 가능성을 확인합니다.**

### M-03. 계수 해설 정확성 [P0]

확인된 오류: 대지면적 효과 표는 약 +1.11%, 해설은 +111.2%. 절편 `const`가 가장 큰 기여 후보이며 마크다운 기호가 그대로 노출된다. 범주 효과도 만원으로 표시된다.

- §4 B-02의 표시 계약을 표·문장·회귀식 도움말에 공통 적용한다.
- 절편을 변수 기여도에서 제외한다. 단위가 다른 원계수의 절댓값만으로 ‘가장 큰 기여’를 선정하지 않는다. 별도 근거가 없으면 기여도 표현을 제거한다.
- 유의성·모형 식별·공선성 한계를 문장에서도 유지한다.

카피 예시:

- `대지면적 1% 증가 … +111.2% 상승` → **다른 변수가 같을 때 대지면적이 1% 큰 거래는 금액이 약 1.11% 높은 관계를 보입니다.** 숫자는 실제 계수에서 산출한다.
- `const 증가 … 가장 큰 기여` → 절편 효과 문장을 제거하고 절편의 수학적 의미만 상세 도움말에 둔다.
- `기준 대비 +1만원` → **기준 범주({범주명}) 대비 금액이 약 {비율}% 높은 관계를 보입니다.** 음수면 양의 크기와 ‘낮음’을 조합한다.

### M-04. 등급·설명형·다른 표본 결과 [P1]

- ‘양호 ★★★★’에는 판정 기준과 확인 거래 수를 붙인다. 11건 확인을 충분한 범용 검증처럼 보이게 하지 않는다. 표본 제한은 접지 않는다.
- 설명형 AIC에는 `?`를 제공하고 예측형 대비 추가·제외 변수와 복잡도 차이를 요약한다.
- AIC 차이를 보여줄 경우 비교 가능한 종속 척도·표본·우도 정의 안에서만 계산한다. 선형과 로그 AIC를 임의로 직접 비교하지 않는다.
- 공시지가가 있는 거래만 쓴 부가 결과는 `다른 표본 참고 결과`로 분리한다. 원래 예측형 순위의 상위 후보로 읽히게 하지 않는다.

카피:

> 설명 목적의 후보입니다. 비교 가능한 로그 모형 중 AIC가 가장 낮은 모형을 표시했습니다. 예측형과는 선정 기준이 다릅니다.

> 개별공시지가 값이 있는 {n}건을 사용한 참고 결과입니다. 위 후보와 분석 거래가 달라 오차만으로 순위를 비교할 수 없습니다.

### M-05. 쌍둥이 확장과 계산 입력 [P0/P1]

- 탭 안 번호를 1부터 다시 매기거나 번호를 없앤다. 현재 ②부터 시작하는 이전 세로 설계의 흔적을 정리한다.
- 지역 후보에 시군구·지역명, 유사성의 주요 근거, 사용 가능한 추가 거래 수를 표시한다. 코드만 사용자에게 노출하지 않는다.
- 확장 채택 여부·결론을 최상단에 둔다. 채택하지 않은 모형의 예시 계산은 보조 동작으로 낮춘다.
- 검토 사례에서는 `현재 지역 기준 유지`를 먼저 보여주고, 실제 비교 가능한 조건일 때 탐색·확인 오차 변화도 표시한다.
- Twin1 266건, Twin2 256건인데 ‘표본이 같음’이라고 쓰지 않는다. 같은 지역 범위를 썼다는 것과 적합 거래가 같다는 것을 구분하고 제외 사유를 표시한다.
- 입력창의 제목·모형 ID·변수·적합 n은 실제 계산 모형의 한 스냅샷을 참조한다. Twin2 256건 아래에 Local 168건이 남는 표기를 수정한다.
- `거래 175 · 적합 256` 대신 `현재 지역 조회 {n}건 / 확장 지역 포함 {n}건 / 적합 {n}건`으로 분모를 구분한다.
- 최종 비교표에 이미 보유한 기본회귀 CV와 각 모형의 학습 MAPE를 누락하지 않는다. 미제공·계산 불가·미실행은 다른 상태로 표시한다.
- 다른 표본·척도의 R², 다른 검증 대상의 CV를 단순 우열·개선율로 제시하지 않는다.
- 최초 계산·Twin 계산에 실제 단계, 경과 시간, 취소 동작을 제공한다. 취소가 클라이언트 수신만 중단하는지 서버 계산도 중단하는지는 실제 동작에 맞춰 안내한다.

카피:

- `Local 유지` → **현재 지역 기준 유지**.
- `접두 실험 상세 · 계수 안정` → **지역 추가 단계별 결과 · 계수 부호 비교**.
- `Local 식을 버리고` → **확장 지역 표본에서 변수 조합을 다시 탐색한 결과입니다. 기존 결과는 보존됩니다.**
- `Twin1과 표본은 같고` → **같은 지역 범위를 사용했습니다. 필요한 변수의 결측으로 적합 표본 수는 다를 수 있습니다.** 실제 행 집합도 같으면 그 사실을 별도로 표시한다.
- `이 순위로 값 계산해 보기` → **선택 후보로 통계적 추정값 계산**.
- `쌍둥이 지역 후보를 불러온 뒤 탐색을 시작합니다…` → **유사 지역 후보를 불러오는 중입니다.** 이후 `모형 후보를 비교하는 중입니다.`처럼 실제 단계별로 표시한다.

## 6. 상위지역 재적합 개선

### U-01. 기능명과 열기·접기 동작 [P1]

상위지역의 별도 적합 결과라는 설명을 유지한다. 현재 구현은 기본회귀 응답의 `comparisons`를 표시하고 `다시 보기`는 열린 상태를 그대로 유지한다.

- 최초 버튼은 **상위지역 결과 보기**, 열린 후에는 **결과 접기**로 제안한다.
- 새 계산을 수행하는 버튼을 추가할 경우에만 ‘다시 계산’이라고 부른다.
- 결과 생성 시점과 조건을 표시하고 기본회귀 조건이 바뀌면 상위지역 결과도 함께 갱신·무효화한다.

부제:

> 선택 지역과 그 상위지역에서 각각 적합한 회귀 결과를 살펴봅니다. 분석 거래와 범주 구성이 달라질 수 있습니다.

### U-02. 차이 요약과 전체 변수 비교 [P0/P1]

- `방배동 → 서초구`, 적합 표본 136→610, 변수·범주 구성 변화, 기준 범주 변화, 식별 상태를 먼저 요약한다.
- 초점 Adj R²만 초록 배경으로 강조하지 않는다. 지역과 표본을 중립적으로 표시한다.
- 비교표를 실제 계수·변환 메타데이터에서 생성한다. 공시지가와 향후 추가되는 연속변수를 하드코딩 누락하지 않는다.
- 범주 수뿐 아니라 기준 범주 및 추가·제외 범주를 표시한다. 검토 사례의 용도지역 기준은 제2종일반주거→제3종일반주거다.
- 더미 개수가 달라진 행도 강조한다. 현재처럼 양쪽 모두 존재한다는 이유로 변경 강조에서 빠지지 않게 한다.

카피:

> 용도지역의 기준 범주가 바뀌었습니다: {초점 기준} → {상위 기준}. 범주 계수는 각각의 기준 대비 값이므로 그대로 비교하지 않습니다.

### U-03. 부호 일치·식별 경고·표본 중첩 [P0]

- `3개 중 3개 방향 유지`는 모형 안정성 판정과 분리한다. 제목은 **공통 연속변수의 계수 부호**로 제안한다.
- 식별 문제가 있으면 녹색 ‘유지’ 대신 `부호 일치 · 해석 제한`으로 표시한다. 유의성 부족과 식별 불가를 같은 상태로 묶지 않는다.
- 중첩 표본 안내는 실제 거래 행의 포함 관계를 확인한 데이터에 근거한다. 변수별 결측 처리로 포함이 보장되지 않으면 ‘모두 포함’이라고 단정하지 않는다.
- 서로 다른 표본의 Adj R²·학습 MAPE는 각 모형의 참고 지표로 두며 성능 우열을 판정하지 않는다. 비교 불가를 모든 통계적 비교가 불가능하다는 절대 문장으로 확대하지 않는다.

카피:

> 비교한 {n}개 변수의 계수 부호가 같습니다. 부호 일치만으로 계수의 안정성이나 모형의 우수성을 판단할 수는 없습니다.

> 일부 계수가 하나로 정해지지 않아 변수별 효과 해석에 제한이 있습니다. 아래 부호 비교는 참고 정보입니다.

> 두 모형은 분석 거래와 변수 구성이 다릅니다. 각 표본의 적합도를 나타내는 지표이므로, 숫자의 크기만으로 어느 모형이 더 낫다고 판단하지 않습니다.

### U-04. 제외 표본·계수 표·입력창 [P1]

- 조회→제외→적합 표본을 비율과 함께 표시하고 주요 결측 사유는 접힌 상태에서도 요약한다. 검토 사례는 873건 중 263건 제외, 주요 사유는 공시지가 결측 237건이다.
- 결측 사유가 중복 집계인지 순차 제외인지 정의를 제공한다. 근거 없이 사유별 수치를 더하도록 유도하지 않는다.
- 계수 상세는 B-02의 공통 형식을 사용한다. `−0만원 / SE 0.00 / p 0.00000` 표시는 실제 정밀도를 보존하는 형식으로 바꾼다.
- 입력창 제목 `Macro 모형 적용 예시`를 **{상위지역명} 재적합 모형으로 계산**으로 바꾼다.
- 입력창은 단위가 있는 여러 줄 배치로 만들고 모형명·적합 표본·척도·기준 범주를 함께 표시한다.
- 상위지역 모형으로 계산한 값을 초점 지역의 전용 추정값처럼 소개하지 않는다.

입력창 안내:

> {상위지역명} 거래자료에서 적합한 모형의 통계적 추정값입니다. 선택 지역만의 관계를 나타내는 모형과 결과가 다를 수 있습니다.
