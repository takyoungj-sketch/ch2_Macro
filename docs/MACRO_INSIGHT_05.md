## 0. 한 줄

한 해 전국 부동산 거래액이 그해 명목 GDP·시중 돈(M2)·주식 거래대금 대비 얼마나 큰지, 여덟 유형 구성이 어떻게 바뀌었는지를 본다.

「부동산이 GDP의 ○○%」로 끝내지 않는다. **지금 본문이 이 질문의 끝이 아니다.**

---

## 1. 질문 (목록 버튼)

**부동산 거래액은 경제 규모와 비교하면 얼마나 클까?**

부제: GDP·M2·주식 거래대금과 비교하고, 부동산 시장의 유형별 구성을 살펴봅니다.

메타: 전국 · 연 · 여덟 유형 합

리드: 한 해 부동산 거래액은 그해 국내총생산이나 시중 돈(M2)보다 작지 않은 규모로 나타난 해도 있었습니다. 다만 이는 부동산이 경제에서 차지하는 비중이 아니라, 기존 자산이 그해 얼마나 거래됐는지를 다른 규모와 나란히 본 숫자입니다. 유형 구성은 해가 바뀌며 달라졌습니다.

하면 안 됨: 「부동산 GDP 비중」「유동성이 부동산으로 이동」「주식 대체 검증」「거시 인사이트」.

## 4. 글의 결

1번 [`MACRO_INSIGHT_01.md`](./MACRO_INSIGHT_01.md) §4와 같다. 추가로:

| 구분 | 규칙 |
|------|------|
| **기간** | **달력 연**만. 월 표·월 그래프와 섞지 않음 |
| **본실험** | 총액 4선(각각) + 비율 3개 + 유형 구성비 + 같은 해 r(수준·전년대비). 건수 구성은 1차 아님 |
| **M2** | 시중 돈 **잔액(분모)**. #1의 전년동월 변화와 문을 섞지 않음 |
| **금리** | 이 글에 **없음** |
| **합계** | 여덟 유형 단순 합. 모든 부동산 아님 |
| **거래액** | 가격지수 아님. 「몇 건 × 얼마」가 섞인 합 |
| **인과** | 「돈이 갔다」「주식이 대체했다」「GDP 기여」금지 |
| **결론** | 「결론」「확인됐다」「법칙」금지 |

헤드라인에 한 해의 비율 하나를 박지 않는다. 유형 구성 변화가 본체 중 하나다.

## 6. AI

`app=insight` · `panel=Insight05` · bundle `insight_macro_05`.
