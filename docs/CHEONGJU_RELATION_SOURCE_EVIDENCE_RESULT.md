# 청주 관계 검토 큐의 원본 근거 확인

2026-10-05. 로컬 원본 읽기 전용 검사. 제품 보강·운영 DB·기존 확정 결과는 변경하지 않았다.

## 검사 범위

층화 검토 큐 160건을 원본 표제부 3개, 총괄표제부 3개, 2024~2026 토지특성 ZIP 12개와 대조했다. 원본 18개의 SHA-256과 스캔 행수를 보존했다. 표제부는 대상 관리 PK를 전국 파일에서 찾았고, 총괄은 같은 PNU 관측을 찾았다. 토지자료는 캐시 대신 ZIP의 DBF 원값을 읽었다.

재현: `python pipeline/parcel_master/audit_cheongju_relation_source_evidence.py`. 집계: `docs/lab/cheongju_relation_source_evidence.json`. 개별 근거는 로컬 `data/research/cheongju_ledger/building_relation_source_evidence.json.gz`에만 보관한다. 거래 연결의 독립 정확도 인증과 원자료 관측 재확인은 구분한다.

## 결과

- 주소 PNU 변경 40건 중 39건은 원본 양쪽 판본에서도 같은 관리 PK의 주소 변경을 확인했다. 나머지 1건은 이전 판본의 대지구분 코드 때문에 엄격한 PNU를 만들 수 없었다.
- 토지 미연결 40건 중 38건은 원본 표제부 주소를 확인했고 해당 연도 원본 DBF에서도 필지를 찾지 못했다. 2건은 대지구분 코드 예외로 별도 검토가 필요하다.
- 최신 판본 관측 누락 38건은 해당 관리 PK가 최신 전국 원본 표제부에도 없었다. 이를 멸실·말소로 단정하지 않는다.
- 숫자 오버플로 검토 36건은 DBF A25 원문이 별표 표시인 것을 확인했다. 6건은 원본 가격 관측을 보존했으며 결측/비양수를 임의 가격으로 채우지 않았다.

160건의 분해가 일치했고 대상 PK의 원본 중복은 없었다. 원천 PNU 처리의 산/토지 구분, 미상 구분 차단, 없는 지번을 0으로 채우지 않음, 긴 지번을 잘라내지 않음에 대한 테스트 4개가 통과했다.

## 대지구분 코드 2 — 중요한 정규화 예외

미해결 3건 모두 원본 대지구분 코드가 `2`였다. 이는 이번 조사에서 0/1의 일반 대지·산 매핑으로 해석하지 못한 원코드다. 현재 `parcel_master.pnu.gbn_from_title()`은 1/산 외의 값을 토지 1로 처리하므로 기존 DB 추출의 PNU는 생성될 수 있다. 이를 근거로 코드 2의 실제 의미나 정식 필지를 확정하지 않는다.

후속 정규화는 원문 대지구분·본번·부번·특수지명·블록·로트와 생성 규칙을 보존하고, 원코드 해석이 확인되지 않은 경우 canonical PNU 관계를 미확정으로 분리해야 한다. 이번 표본에서 발견한 3건을 도시 전체의 예외 건수로 보고하지 않는다. 현재 SQLite v1은 기존 가공 추출 PNU를 쓰는 시험이므로 원천 기반 v2에서 이 차이를 검증해야 한다. 현재 제품 키를 자동 교체하지 않는다.

## 확보 가능한 관계 필드와 한계

표제부 공통 위치에서 다음 원문을 확인했다. 표제부 샘플 CSV는 첫 열 배치가 TXT와 다르므로 첫 부분의 열 번호를 그대로 혼용하지 않는다.

- TXT [23]/[24]: 주부속구분코드/명. 주건축물·부속건축물 관측을 구분할 수 있다.
- [16]: 외필지수. 추가 필지의 개수이지 PNU 목록이 아니다.
- [47]/[48]: 부속건축물수/면적. 부속 건물의 관리 PK 목록이 아니다.
- 특수지명·블록·로트: 정식 지번 외의 원문 주소 정보를 보존할 필드다.

검토 건에 연결된 현재 원본 표제부 관측에서는 주건축물 일반 101회, 부속건축물 일반 14회, 주건축물 집합 3회를 확인했다. 검토 행과 연결된 관측 횟수이며 도시 전체 구성 비율이나 고유 건물 수가 아니다.

총괄표제부가 같은 주소 PNU에서 관측된 검토 행은 54건이다. 같은 PNU는 동주소 참고 근거이고 표제부 관리 PK↔총괄 PK 부모 관계를 증명하지 않는다. 같은 필지의 모든 표제부를 자동으로 하나의 총괄 자산에 넣지 않는다.

확보된 건축대장 폴더는 3판본 표제부·총괄과 샘플 CSV다. 추가 필지 식별 목록이나 명시적 부모/자식 연결 파일은 이 폴더에서 확인하지 못했다. 다른 공급 경로에 자료가 없는 것으로 단정하지 않는다. 정확한 관계 확대는 원천 스키마·연결 자료를 추가 조사한 뒤 결정한다.

2024년 대상 표제부는 76열, 이후 대상 판본은 77열이었다. 동일 열 수를 가정하지 않고 확인된 공통 필드를 사용했다. 전체 필드 명세/변경 의미는 원천 스키마 사전 보완 대상으로 남긴다.
