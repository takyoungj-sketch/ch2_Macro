# 공통 대장 객체·거래 소속 계약 초안

2026-10-05. 청주 이름 키 검토에서 얻은 근거를 바탕으로 한 병행 실험 계약이다. 운영 DDL·자동 연결 정책을 확정하거나 제품에 적용한 문서가 아니다. [공통 입력 계약](LEDGER_CONSUMER_CONTRACT_DRAFT.md), [운영 정책](CH2_LEDGER_V2_OPERATING_POLICY.md)의 원천 보존·판본·복원 규칙을 따른다.

## 식별 단위

- **필지:** 판본과 PNU를 함께 보관한다. PNU 변경만으로 영구 동일 필지 여부를 정하지 않는다.
- **대장 건물:** 관리 PK와 원본 판본·행 버전을 보관한다. 표제부 주소는 관측 주소 관계이며 전체 부지 인증이 아니다.
- **관리 단지:** K-apt 코드·원본 기준일·대표주소를 보관한다. 코드가 물리적 단지와 항상 일대일이라는 가정을 두지 않는다.
- **제품 분석 객체:** 단지·건물·도로명 군집 등 분석 단위를 명시한다. 이름 키와 필지 키를 물리적 객체 ID로 그대로 승격하지 않는다.
- **거래 관측:** 기존 거래 식별자·기존 제품 키·유형·주소 원문·관측 기간을 보존한다. 후보 관계는 원본 관측과 분리한다.

새 객체 ID와 소속 관계는 독립된 근거를 갖춘 후 부여한다. 검토 중에는 null을 유지한다. 기존 키는 전환 대응표의 참조값으로 남긴다.

## 관계 기록의 필수 항목

관계마다 원본 식별자·파일 해시·판본·관측 시각·관계 종류·판정 규칙 버전·근거 참조를 둔다. 원본 기준일, 시스템 관측 시각, 관계 유효기간은 서로 다른 값이다. 유효기간을 모르면 null로 남기고 거래일 또는 파일 월을 임의로 복사하지 않는다.

관계 종류는 최소한 `title_address`, `management_representative_address`, `additional_parcel`, `transaction_object_membership`를 구분한다. 앞의 두 주소 관측 관계가 뒤의 두 실제 소속 관계를 자동 증명하지 않는다.

## 병행 판정 상태

- `observed_only`: 원본 주소·이름·코드가 관측됐으며 소속 미검증.
- `object_scope_review_hold`: 한 키의 객체 범위가 혼합될 수 있어 전체 보강의 승계 보류.
- `shared_parcel_management_review`: 같은 필지의 복수 관리코드 관계 미확정. 자동 분할·병합 모두 보류.
- `development_block_identity_unresolved`: 비정규 사업 블록과 실제 필지 관계 미확정.
- `source_coverage_review`: 선택 판본에 원본이 없거나 용도·주소 관계에 추가 확인이 필요함.
- `membership_verified`: 거래 또는 분석 객체의 소속이 명시적 독립 근거로 검증됨. 검증에 사용한 관계·범위·시점을 함께 기록해야 함.

이번 52개 큐에서 `membership_verified`로 승격한 사례는 없다. 서로 다른 단지의 근거가 발견된 것과 모든 거래의 소속을 확인한 것은 구분한다. 향후 명시적 관계 원천의 식별자·스키마와 검증 방법을 확보한 뒤 승격 규칙을 구체화한다.

## 주소 선택·보강 승계 조건

실제 관측된 `(법정동 코드, 지번)` 쌍을 하나의 단위로 보관한다. 열별 MAX로 새로운 조합을 만들지 않는다. 비정규 주소를 폐기하거나 임의 PNU로 변환하지 않는다.

복수 후보에서 어느 주소를 대표로 선택할지는 객체 소속 검증 뒤 별도 규칙으로 정한다. 거래수·최신일·가격 존재 여부만으로 소속을 검증하거나 전체 다필지 단지의 대표 대지를 결정하지 않는다. 동률·미확정 결과도 명시적 보류 상태로 남긴다.

가격·건물 속성의 승계에는 검증된 객체 소속, 해당 원본·판본, 대표 주소 선택 근거와 소비 목적이 필요하다. 현재 혼합 키의 보강값은 기준값으로 보존하며 새 객체·주소에 자동 복사하지 않는다.

집합 소비는 기존 단지별 평균가격·지역회귀와 최신 개별공시지가 사용 목적을 유지한다. 이 초안으로 개별 과거 거래에 공시지가를 소급 연결하지 않는다. 복합 거래 보강과 집합 단지 보강은 각각의 소비 계약을 따른다.

비주거는 도로명 군집을 분석 단위로 유지한다. 주거의 물리적 단지 분할 규칙을 군집에 적용하지 않는다. 공통 적용은 출처·판본·보류 상태·거래 보존 원칙이다.

## 선택기 검증과 전환 준비

병행 선택기는 기존 결과와 새 후보·보류 사유를 함께 출력하고 제품 테이블에 쓰지 않는다. 거래 누락·중복, 미관측 주소 생성, 원본 없는 객체 할당, 미검증 가격 승계를 검사한다. 같은 입력·규칙 버전의 결과가 같아야 한다.

청주 52개 검토 큐와 같은 법정동 복수 PNU 33개를 각각 검증한다. 두 집합의 중복 여부는 실제 기존 키 기준으로 확인하며 숫자를 단순 합산하지 않는다. 다음으로 통계·가격·회귀·조회 성능 차이를 측정하고, 기존 키 대응표·재계산 범위·복구 기준점을 준비한다.

운영 전환은 위 근거와 검증 결과를 검토한 후 별도 변경으로 수행한다. 커밋은 실험 결과 보존이며 운영 전환이나 배포를 의미하지 않는다.
