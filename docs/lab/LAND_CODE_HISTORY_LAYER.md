# 법정동 코드 이력층 V1

확정: 2026-10-16. 이 층은 토지 연결 규칙 V1의 앞단이다. 필지 연결, 명칭 정규화, 공시지가 규칙은 바꾸지 않는다.

하는 일은 과거 코드를 현재 코드로 바꿔 넣는 것이 아니다. 거래일의 법정동 코드 세대로 맞춘 뒤, 그 코드에 V1을 그대로 적용한다.

지역별 예외는 더 찾지 않는다. 고정 기준은 이번 shadow다. 이력 변환 뒤 true conflict는 0이고, 재발급 이후 연도의 연결은 변환 전과 같다.

측정: [`land_link_code_history_shadow_20261016.json`](land_link_code_history_shadow_20261016.json). 전국 제품 연결 shadow: [`land_link_product_shadow_20261016.json`](land_link_product_shadow_20261016.json).

## 적용 범위

시행일 이전이면 아래 대응으로 법정동 코드를 바꾼다. 시행일 이후에는 거래에 적힌 현행 코드를 유지한다. 이 표에 없거나 1:1이 아니면 변환하지 않는다.

| 구분 | 현행 | 이전 | 시행일 | 규칙 |
|---|---|---|---|---|
| 1:1 코드 치환 | 51 강원 | 42 | 2023-06-11 | 앞 두 자리만 교체한다. 필지 뒷자리는 그대로다. |
| 1:1 코드 치환 | 52 전북 | 45 | 2024-01-18 | 강원과 같다. |
| 이름 대응 보조 규칙 | 12 전남광주 | 29 또는 46 | 2026-07-01 | 직접 공식 1:1 이력표가 아니다. 시군구·읍면동·리 이름이 하나씩 대응할 때만 쓴다. |

세 대응을 합쳐 5,997쌍이며 서로 겹치지 않았다. 세 시도에서 보류는 0건이다. `region_code_history`의 기존 191행(면→읍)은 이 층에 넣지 않았다.

## 고정에 쓴 결과

| 시도 | exact, 변환 전 → 후 | 재발급 이후 연도 |
|---|---:|---|
| 전남광주 | 0% → 76.4% | 2026년 7월 이후는 현행 12번 코드 유지 |
| 강원 | 23.6% → 72.3% | 2024–2026은 변환 전과 동일 |
| 전북 | 15.6% → 67.4% | 2025–2026은 변환 전과 동일 |

true conflict는 변환 전후 모두 0이다. 강원 2023년 same-year 52.7%, 전북 2024년 88.1%는 그 해 공시지가가 두 코드 세대에 나뉜 결과다. 연결 실패가 아니므로 규칙을 추가하지 않는다.
