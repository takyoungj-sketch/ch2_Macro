### 구현 중 고친 것

1. **영향 범위 설계 오류 2개**(설계 §2.1 정정).
   - 4-C는 시점 판에서 못 찾으면 다른 판을 쓴다(`time_fallback`). 그래서 새 판은 대체 판으로 붙었거나 미매칭인 거래에도 영향을 준다.
   - 4-C 동률 해소가 slim 면적을 쓴다. 그래서 토지 새 기준일은 매칭에도 영향을 준다.
2. **토지 영향 판정이 너무 넓었다.** 처음에는 최신 관측 연도까지 비교해서 새 기준일마다 거의 모든 거래(109,242건)를 다시 계산했다. 결과는 같았지만 전체 구성보다 느렸다. 최신 연도는 공급·저장되지 않는 값이라 비교에서 뺐다. 재계산이 38,586건으로 줄었고 결과는 여전히 같다.
3. **저장 부풀림.** 삭제 후 재삽입으로 증분본이 직전보다 최대 +64MB 커졌다(빈 페이지 목록 0, 색인 페이지 분할). 이어붙이기 끝에 VACUUM을 넣었다(약 3초). 증분본이 직전 전체본보다 작아졌다.
4. **실패 시 부분 파일.** 이어붙이기 도중 실패하면 `.partial` 파일이 남았다. 이제 실패하면 지운다.

세 번 실행한 결과가 모두 불일치 0이다. 표의 수치는 마지막 실행(커밋하는 코드)이다.
