## 2. 핵심 모수

기본식 (모형 A):

\[
\log(\text{단가})=\alpha+\beta\log(\text{면적})+\gamma\,\text{연도}+\delta\,\text{도로}+\varepsilon
\]

| β | 단가 | 총액 탄성 \(1+\beta\) |
|---|------|------------------------|
| β &lt; 0 | 면적↑ → ㎡당 단가↓ | 1 미만 (규모 경제·소필지 할증) |
| β ≈ 0 | 면적과 단가 거의 무관 | ≈ 1 |
| β &gt; 0 | 면적↑ → ㎡당 단가↑ | 1 초과 (광평 희소·합필) |

단가 = 만원/㎡ (`unit_price_per_sqm`). 총액 OLS로 단가 효과를 읽지 않는다.  
이름은 **면적 탄성 β**. 「광평수 할인율」·\(D=-\beta\) 금지 (β&gt;0이면 할인이 아님).

가설 스케치 (관측 전):

| 가설 | 예측 | 어디서 볼 수 있는가 |
|------|------|---------------------|
| 규모 경제 · 소필지 할증 | β &lt; 0 | 전·답 전반, 도시 대지에서도 흔함 |
| 광평 희소 · 합필 | β &gt; 0 | 개발 가능한 도시 대지, 대형 꼬리 |
| U자 | 소·대 단가↑, 중간↓ | 도시 대지 |
| 입지 착시 | A≠0, 동 FE 후 ≈0 | 큰 땅이 외곽 동에만 남은 시군구 |

## 3. 분석 단위

**칸** = 시군구 × 지목 × 롤링 5년.

- 지목은 **대 / 전 / 답**을 한 식에 섞지 않는다. 군에서 임야는 별칸(선택).
- 지목군 `dev`·`agri`로 대체하지 않는다. `dev`는 대+공장용지 등이 섞인다.
- 용도지역: n이 되면 주거계 / 농림 / 기타로 가르거나 A에 더미. 농림 대와 주거 대를 한 표본으로 두지 않는 것이 기본.
- 창: 제품과 같이 5년. as_of는 원장 최신.
- 지역 코드: canonical (D-028).

하지 않음: 전국 풀+지역 절편만으로 β가 같다고 가정하기. 대+전 한 식. 총액만 보고 단가 효과로 읽기.

## 4. 단계

```
원장 (지분 제외, 오류 면적만 제거)
  → 시군구 × 지목 집계 (n, 면적 분위, 꼬리 건수)
  → 유형별 적격 게이트 (단가·β로 고르지 않음)
  → 1차: 유형 안 할당 선정 → A/B/C (±D)
  → 2차: 같은 식을 적격칸 전부에 반복
```

| 차 | 목적 | 지역 |
|----|------|------|
| **1차** | 효과가 있는가, 어떤 유형에서 보이는가 | 유형당 3~5칸. 전수 아님 |
| **2차** | 1차 패턴이 같은 유형에서 되풀이되는가 | 게이트 통과 칸 |

1차 전에 적격 표가 있어야 한다. 회귀가 먼저가 아니다.

### 5.1 집계 열 (칸마다)

전체 n · 면적 P10/P50/P75/P90 · P90/P50 ·  
300·500·1,000·3,000·5,000㎡ 이상 건수.

종속(단가 수준, β)은 선정에 쓰지 않는다. 관측 가능성(거래량·면적 분포)만 쓴다.

### 5.2 유형 (층)

| 코드 | 유형 | 1차에서 볼 것 |
|------|------|----------------|
| `metro_gu` | 서울·광역시 자치구 | 대지. 소·중형 vs 그 시장에서의 상대적 광평 |
| `cap_city` | 수도권 시 (성남·화성·평택·남양주 등) | 대지와 전·답 둘 다 가능하면 둘 다 |
| `prov_city` | 지방 시 (청주·전주·천안 등) | 시가지 대지 + 외곽 전답 |

광평의 **절대 ㎡**는 유형마다 다르다. 대도시 대지에 1,000㎡≥20을 전국 공통으로 걸면 희소 가설 칸이 탈락한다.

| 유형 | 지목 | A 최소 | 넓이 조건 (모두) |
|------|------|--------|------------------|
| `metro_gu` | 대 | n≥150 | P90/P50≥2 **그리고** (P90≥300㎡ 또는 300㎡+ ≥30건) |
| `cap_city` · `prov_city` · `urban_rural` | 대 | n≥100 | P90/P50≥2.5 **그리고** 500㎡+ ≥20건 |
| 위 세 유형 | 전 또는 답 | n≥100 | P90/P50≥3 **그리고** 1,000㎡+ ≥20건 |
| `gun` | 전 또는 답 | n≥80 | P90/P50≥3 **그리고** 1,000㎡+ ≥20건 |
| `gun` | 대 | n≥80 | 500㎡+ ≥15건. 미달이면 칸 비움 (합치지 않음) |

1차 할당: 유형당 통과 칸 3~5. 같은 유형 안에서는 P90/P50·꼬리 건수가 큰 쪽을 우선.

미달 칸은 비운다. 이웃 시군구·지목과 합치지 않는다.

## 6. 표본 처리

| 항목 | 규칙 |
|------|------|
| 지분 | 제외 (`partial_ownership`) |
| 면적 오류 | 0·비양수·비현실 상한만 제거 |
| **면적 IQR** | **하지 않음.** 광평 꼬리가 연구 대상 |
| 단가 Raw | IQR 없이 A/B/C |
| 단가 Robust | 단가 IQR 또는 winsor(1/99) 또는 Cook 고영향 제외 후 **같은 식** |
| 보고 | Raw β와 Robust β를 나란히. 부호가 같으면 고가 1건 의존이 아님 |
| 연도 | 창 내 연도 추세(평균 중심) |
| 도로 | 접면 더미. 범주 1개면 제외하고 기록 |
| 거래유형 | 기본은 지분 제외 후 전부. Robust에서 중개만 따로 볼 수 있음 |

## 7. 모형

같은 칸·같은 Raw 표본에 적용. 제품 `land_regression.py`와 종속·면적 log는 맞추되, 이 랩이 제품 기본 체크를 바꾸지 않는다.

| id | 식 | 역할 |
|----|-----|------|
| **A** | log 단가 ~ log 면적 + 연도 + 도로 | 기본. 시장에서 보이는 기울기 (동 구성 포함) |
| **B** | A + 법정동 FE | 같은 동 안 면적 기울기. **식별 점검**이지 A의 대체 본결과가 아님 |
| **C** | A + \((\log\text{면적})^2\) **그리고** 면적 삼분위 단가 중위 | 비선형. 제곱만 쓰지 않음 (대형 몇 건이 곡선을 휨) |
| **D** | 권역×지목 풀에서 \(\log A \times\) 권역 | 지역 차가 오차 범위인지. 시군구×면적 상호작용 전수 아님 |

A와 B가 같으면 입지 착시가 아니라는 증거가 된다. **갈리면 A를 버리지 않고 둘 다 적는다.**  
A = 거래시장 구성(큰 땅이 어느 동인가) 포함, B = 동 내부 규모 효과.

C turning point: \(x^\ast=-\beta_1/(2\beta_2)\), 면적\(^\ast=\exp(x^\ast)\).  
표시 조건: β₂ 유의 **그리고** 면적\*가 그 칸 면적 P10–P90 안. 밖에 있으면 「이 표본에서 U자 아님」.

D는 1차에서 칸이 모인 뒤, **같은 지목**만 권역 풀로 검정한다. 대+전 금지.
