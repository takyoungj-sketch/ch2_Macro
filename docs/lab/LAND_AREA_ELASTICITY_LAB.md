## 2. 핵심 모수

기본식 (모형 A):

\[
\log(\text{단가})=\alpha+\beta\log(\text{면적})+\gamma\,\text{연도}+\delta\,\text{도로}+\varepsilon
\]

| β | 단가 | 총액 탄성 \(1+\beta\) |
|---|------|------------------------|
| β &lt; 0 | 면적↑ → ㎡당 단가↓ | 1 미만 (규모 경제·소필지 할증) |
| β ≈ 0 | 면적과 단가 거의 무관 | ≈ 1 |
| β &gt; 0 | 면적↑ → ㎡당 단가↑ | 1 초과 (광평 희소·합필) |

단가 = 만원/㎡ (`unit_price_per_sqm`). 총액 OLS로 단가 효과를 읽지 않는다.  
이름은 **면적 탄성 β**. 「광평수 할인율」·\(D=-\beta\) 금지 (β&gt;0이면 할인이 아님).

가설 스케치 (관측 전):

| 가설 | 예측 | 어디서 볼 수 있는가 |
|------|------|---------------------|
| 규모 경제 · 소필지 할증 | β &lt; 0 | 전·답 전반, 도시 대지에서도 흔함 |
| 광평 희소 · 합필 | β &gt; 0 | 개발 가능한 도시 대지, 대형 꼬리 |
| U자 | 소·대 단가↑, 중간↓ | 도시 대지 |
| 입지 착시 | A≠0, 동 FE 후 ≈0 | 큰 땅이 외곽 동에만 남은 시군구 |

## 3. 분석 단위

**칸** = 시군구 × 지목 × 롤링 5년.

- 지목은 **대 / 전 / 답**을 한 식에 섞지 않는다. 군에서 임야는 별칸(선택).

- 창: 제품과 같이 5년. as_of는 원장 최신.
- 지역 코드: canonical (D-028).

하지 않음: 전국 풀+지역 절편만으로 β가 같다고 가정하기. 대+전 한 식. 총액만 보고 단가 효과로 읽기.

## 4. 단계

```
원장 (지분 제외, 오류 면적만 제거)
  → 시군구 × 지목 집계 (n, 면적 분위, 꼬리 건수)
  → 유형별 적격 게이트 (단가·β·Δ로 고르지 않음)  → 369칸 = 2차 모집단
  → 1차: 유형 안 할당 선정 → A/B/C          (기록됨)
  → 2차: 비교가능칸만 통과 → 초소형·몸통·광평 단가 비교
  → 3차: 차이 방향 × 유형·지목 구성 · 교차표 (랩 마감)
```

| 차 | 목적 | 어디 |
|----|------|------|
| **1차** | 면적효과가 칸마다 다른가 (회귀 β) | 유형당 3~5칸. 기록됨 |
| **2차** | 같은 칸에서 광평(본)·초소형(보조) 단가가 몸통과 다른가 | 369 중 비교가능 358. **OLS 반복 아님. 기록됨** |
| **3차** | 그 차이가 어느 체급·지목·구성에 모이는가 | 358칸 구성 + 같은 동 + 유형×지목 교차표. **기록·랩 마감** |

1차 전에 적격 표가 있어야 한다. 2차는 적격 표를 모집단으로 쓰고, **비교 가능한 칸만** 통과시킨다. 단가가 낮/높은 칸을 고르지 않는다.

## 6. 표본 처리

| 항목 | 규칙 |
|------|------|
| 지분 | 제외 (`partial_ownership`) |
| 면적 오류 | 0·비양수·비현실 상한만 제거 |

## 7. 모형

같은 칸·같은 Raw 표본에 적용. 제품 `land_regression.py`와 종속·면적 log는 맞추되, 이 랩이 제품 기본 체크를 바꾸지 않는다.

| id | 식 | 역할 |
|----|-----|------|
| **A** | log 단가 ~ log 면적 + 연도 + 도로 | 기본. 시장에서 보이는 기울기 (동 구성 포함) |
| **B** | A + 법정동 FE | 같은 동 안 면적 기울기. **식별 점검**이지 A의 대체 본결과가 아님 |
| **C** | A + \((\log\text{면적})^2\) **그리고** 면적 삼분위 단가 중위 | 비선형. 제곱만 쓰지 않음 (대형 몇 건이 곡선을 휨) |
| **D** | 권역×지목 풀에서 \(\log A \times\) 권역 | 지역 차가 오차 범위인지. 시군구×면적 상호작용 전수 아님 |

A와 B가 같으면 입지 착시가 아니라는 증거가 된다. **갈리면 A를 버리지 않고 둘 다 적는다.**  
A = 거래시장 구성(큰 땅이 어느 동인가) 포함, B = 동 내부 규모 효과.

C turning point: \(x^\ast=-\beta_1/(2\beta_2)\), 면적\(^\ast=\exp(x^\ast)\).  
표시 조건: β₂ 유의 **그리고** 면적\*가 그 칸 면적 P10–P90 안. 밖에 있으면 「이 표본에서 U자 아님」.

D는 1차에서 칸이 모인 뒤, **같은 지목**만 권역 풀로 검정한다. 대+전 금지.

## 11. 2차 — 비교가능칸 단가 비교 (기록, 2026-09-21)

1차를 버리지 않는다. 1차는 「칸마다 β가 다른가」이고, 2차는 「같은 칸에서 큰 필지(·극소 필지)의 **실제 단가**가 몸통과 다른가」이다.  
적격 369칸에 A/B/C를 반복하지 않는다. 369는 **비교 가능한 칸을 찾기 위한 모집단**이다.

### 11.1 처음 질문과 판정 중심

처음 질문은 「광평수 거래의 단가 평균이 낮은가」다. 단가 분포는 비대칭일 가능성이 크므로 **중위는 반드시** 보고, 평균은 같이 계산하되 판정의 중심은 중위다. 고가 1건이 평균을 움직인다.

같은 칸에서:

\[
\Delta_{\mathrm{mean}}=\frac{\bar P_{\text{광평}}}{\bar P_{\text{몸통}}}-1,\qquad
\Delta_{\mathrm{median}}=\frac{P50_{\text{광평}}}{P50_{\text{몸통}}}-1
\]

초소형도 같은 식으로 \(\Delta_{\mathrm{mean}}^{\text{소}}\), \(\Delta_{\mathrm{median}}^{\text{소}}\) (보조).

| 역할 | 지표 |
|------|------|
| **판정 중심** | \(\Delta_{\mathrm{median}}\) + 부트스트랩 95% CI |
| **보조** | \(\Delta_{\mathrm{mean}}\) (치우침·고가 1건 점검) |

이름: **차이율 Δ**. 「광평수 할인율」·「할증율」로 부르지 않는다. β&gt;0인 칸과 충돌하고, 관측 비율이지 인과 할인이 아니다. 화면 문구는 「몸통보다 낮게/높게 관측」.

### 11.2 구간 (칸 안 상대 + 절대 하한)

| 구간 | 정의 | 2차에서의 역할 |
|------|------|----------------|
| 초소형 | 면적 ≤ 그 칸 P25 **그리고** 하한 이상 | **보조.** 1차 극소필지 꺾임(용산 13.8㎡) 확인 |
| 몸통 | P25 &lt; 면적 ≤ P75 | 기준 |
| 완충 | P75 &lt; 면적 &lt; P90 | 어느 쪽에도 안 넣음 |
| 광평 | 면적 ≥ 그 칸 P90 | **본실험.** 상대적 대형 vs 몸통 |

하한: 대지 ≥10㎡, 전·답 ≥30㎡. 미달 행은 초소형에 넣지 않고 `n_below_floor`로만 센다. P10=3㎡(용산 대지)를 초소형 표본으로 쓰지 않는다.  
절대 ㎡ 컷(전국 1,000㎡)으로 광평을 정의하지 않는다. 서울 대지 P90은 200–330㎡대다.

초소형과 광평을 하나의 Δ로 합치지 않는다. 핵심 판정은 **광평 vs 몸통**. 초소형은 열이 하나 더 있을 뿐이다.

### 11.3 선정 — 비교 가능 여부만, 결과 보기 전

**좋은 기준:** 전체 n, 몸통 n, 광평 n, 초소형 n, P90/P50, 면적 분포.  
**나쁜 기준:** 광평 단가가 낮/높은 곳, |Δ|가 큰 곳, β 부호, 시군구 평균 단가.

```
적격 369칸 (유형 게이트 통과. 단가·β로 고르지 않음)
       ↓
몸통 n ≥ 30  그리고  광평 n ≥ 20     → 본실험 칸
       ↓
그중 초소형 n ≥ 20                    → 보조열을 채움 (미달이면 광평열만)
       ↓
Δ_mean · Δ_median + CI
```

369 전부를 비교할 필요는 없다. 표본조건을 충족한 칸만 분석했다고 쓴다. 「광평이 많은 지역을 임의로 골랐다」가 아니다.  
본실험에 초소형 n을 필수로 걸지 않는다. 꼬리가 한쪽만 있는 칸을 억지로 세 구간 채우지 않는다.

### 11.4 유의성

칸 안에서 광평·몸통 단가를 각각 재추출해 \(\Delta_{\mathrm{median}}\)의 백분위 95% CI.

예: 몸통 중위 1,000만, 광평 중위 800만 → \(\Delta_{\mathrm{median}}=-20\%\).

| CI | 처리 |
|----|------|
| −27% ~ −12% (0을 안 포함, 음수) | 광평 중위가 몸통보다 **낮게 관측**. 방향 칸 |
| −42% ~ +5% (0 포함) | 낮게 보이지만 **뚜렷하지 않음**. 중립 |
| 양수 쪽만 | **높게 관측**. 방향 칸 |

「낮다/높다」를 점추정만으로 찍지 않는다. 평균 Δ는 표에 나란히 두되, 평균만 유의하고 중위 CI가 0을 포함하면 본판정은 중립이다.

입지 점검(선택, 1차 B와 같은 역할): 같은 동에 광평과 몸통이 **같이** 있는 동만 다시 Δ. 본결과를 대체하지 않는다. 동 가드 미달이면 skip.

보고 행: `addr1, addr2, land_category, 유형, n, n_tiny, n_body, n_large, n_below_floor,`  
`P10/P50/P90, Δ_mean_large, Δ_median_large, CI_lo, CI_hi, 방향_광평,`  
`Δ_mean_tiny, Δ_median_tiny, CI_tiny, 방향_초소형 또는 skip`.
