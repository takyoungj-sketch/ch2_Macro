## 2. 1차 설계 (고정)

현재 지역회귀 정의를 따른다.

- 아파트 · 창 5년 · 단지 1행 · log OLS · 가중 equal
- 변수: 세대수 · 최고층 · 연식 · 주차 (공시지가·시공사 없음)
- 잔차율 = (실제 단가 − 예측) / 실제 단가. 과소예측 = 실제 > ŷ0
- 대전: 시 전체 1회 적합
- 전국: **시도마다 1회** 적합 후 잔차 스택. 전국 한 식 없음
