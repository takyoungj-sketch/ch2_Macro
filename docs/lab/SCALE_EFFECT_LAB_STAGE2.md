# 규모효과 회귀실험 2단계

> **작성:** 2026-10-25
> **상태:** 랩 기록. 1단계 산출물은 유지한다. 제품 회귀 식과 모형추천은 바꾸지 않았다.
> **화면:** http://localhost:5179/lab/?tool=scale-effect-2
> **스냅샷:** [`scale_effect_stage2.json`](./scale_effect_stage2.json)
> **재실행:** `backend`에서 `python -m app.scale_effect_lab.stage2`

1단계가 고른 평택동·한남동·고잔동·주안동만 같은 거래와 같은 통제로 다시 읽는다. 목적은 최우수 모형을 고르는 것이 아니라, 예측이 좋아진 것과 설명 구조가 바뀐 것을 가르는 것이다.

2차항은 칸 전체 로그면적 평균으로 중심화한다. 계수가 양수이면 전환면적은 단가의 극솟값이고, 음수이면 극댓값이다. 주변 거래는 전환면적 ±20%이다. 전환면적의 안정성은 같은 중심을 두고 학습 겹만 바꿔 다시 맞춘 값이다. 정규화 강도는 학습 겹 안의 3겹 평균제곱오차로만 고른다.

단가 식과 총액 식은 같은 행이다. 총액 예측은 관측 면적으로 ㎡당 단가 MAPE에 맞춘다. 총액 log-log 기울기는 단가 기울기에 1을 더한 값과 같다.
