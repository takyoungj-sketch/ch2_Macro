# 건축물대장 원장 v1 설계 (계획 3단계)

계획: [`docs/LEDGER_NEXT_PHASE_PLAN.md`](../LEDGER_NEXT_PHASE_PLAN.md) 3단계 · 2026-10-17

## 원칙

- 원문 보존: 표제부·총괄표제부 한 줄을 **바이트 그대로**(`raw BLOB`) 저장한다. 열 해석은 소비층에서 한다.
- 같은 값은 접는다: `(관리번호, 원문 해시)`가 같으면 버전 한 행. 판(snapshot)마다 관측 한 행.
- 필지번호는 청주 v2.1 규칙을 전국으로 일반화해 만든다. 대지구분 코드가 0/1이 아니면 **보류**(`unknown_land_type`)하고 변환하지 않는다.
- 지역코드는 판에 적힌 그대로 둔다. 코드 이력 매핑은 이 원장에서 하지 않는다.
- 전유부 원본은 없다. 표제부(동)·총괄표제부(단지)만 다룬다.

## 구조 (`C:\CH2\parcel_master\building_ledger_v1.sqlite`)

|---|---|---|

판 하나 = 트랜잭션 하나(중단 시 그 판만 롤백, 재실행하면 완료된 판은 건너뜀).
