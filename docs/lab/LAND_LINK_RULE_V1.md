# 토지 연결 규칙 V1

확정: 2026-10-16. 청주 4개 구, 계약 2019–2023. 이 버전은 전국 적용에서 바꾸지 않는다. 전국에서 새 예외가 대량으로 나올 때만 V2를 만든다.

측정: [`cheongju_land_label_rule_2019_20261016.json`](cheongju_land_label_rule_2019_20261016.json), [`cheongju_land_price_final_2019_20261016.json`](cheongju_land_price_final_2019_20261016.json).

## 상태

거래 하나에 아래 중 하나만 붙인다.

| 상태 | 의미 |
|---|---|
| exact | 계약일 이전 정상 판이 하나이고 거래의 지목·면적·용도지역과 같다 |
| label_normalized | 코드·면적·공시지가는 같고 명칭만 달라 충돌로 빠져 있던 판을 한 관측으로 되살린 뒤, 그 조건이 성립한다 |
| clean_precontract_traits_differ | 계약 전 정상 판은 있으나 거래 특성과 다르다 |
| label_normalized_traits_differ | 명칭 차이를 걷어 낸 판은 있으나 거래 특성과 다르다 |
| multiple_or_other | 후보가 둘 이상이거나 지번이 한 필지로 모이지 않는다 |
| post_contract_only | 그 필지 자료가 계약일 이후에만 있다 |
| no_precontract_observation | 계약 전 관측이 정상 판에도 충돌 행에도 없다 |

후보가 둘 이상이면 고르지 않는다. 하나가 나와도 미검증이다. 계약 전 관측이 없는 거래와 계약 뒤에만 자료가 있는 거래는 메우지 않는다.

## 필지

계약일 이전 판만 쓴다. 키는 법정동, 지목, 면적(소수 한 자리), 산 여부, 가려진 본번, 용도지역 코드다. 그 날짜 이전 판 중 가장 늦은 판을 쓴다. 거래 뒤에 바뀐 특성으로 필지를 정하지 않는다.

## 명칭과 충돌

분석 값은 코드, 면적, 공시지가다. 명칭은 키도 아니고 충돌 판정도 아니다.

코드·면적·공시지가가 같으면 한 관측이다. 원문 명칭과 출처 ZIP은 그대로 둔다. 화면에 보이는 이름은 코드사전에서 만든다. 나중 ZIP의 문자열로 원장을 덮지 않는다.

같은 코드에 빈칸이 아닌 이름이 둘이면 별칭으로만 남긴다. 청주에서 확인한 경우는 형상 `05`(사전명 부정형, 별칭 삼각형)와 `06`(사전명 자루형, 별칭 역삼각형)이다.

코드 또는 면적·공시지가가 다를 때만 실제 충돌이다. 숫자 표기만 다른 값은 같은 값이다.

## 공시지가

필지가 하나로 정해진 뒤에만 붙인다.

1. 계약연도와 같은 기준연도
2. 없을 때만 직전 연도. 이 행은 직전 연도 fallback으로 표시한다
3. 그것도 없으면 결측. 2년 이상 지난 값은 쓰지 않는다

같은 기준연도의 공시지가가 서로 다르면 고르지 않는다. 공시지가, 거래가격, 기존 제품값으로 필지나 판을 고르지 않는다. 그 연도의 가격이 들어 있는 판이면, 판의 날짜가 계약일 이후여도 그 기준연도 값을 읽는다.
