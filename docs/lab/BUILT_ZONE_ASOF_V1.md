## 상태 구분

토지특성은 기준일(기준연도 1월 1일, 일부 7월 1일)마다 값이 있다. 계약 (연, 월)에 대해:

| 상태 | 뜻 | 보존하는 연도 |
|---|---|---|
| **관측(계약연도 기준)** | 계약연도 기준일 중 계약월 이전 것이 있다 | 그 기준일(연·월) |
| **추정** | 계약연도 값이 없고, 앞(전년)과 뒤(같은 해 하반기 또는 다음 해) 기준일 값이 같다 | 앞·뒤 기준연도 |
| **인접(이전)** | 전년 값만 있다. 계약 시점까지 바뀌었을 수 있다 | 전년 |
| **인접(이후)** | 계약 뒤 기준일 값만 있다. 계약 후 관측이다 | 다음 기준연도 |
| **확인 불가** | 1년 안에 기준일이 없음, 앞뒤 값이 다름, 한 기준일에 값이 둘, 필지 없음, 필지 코드가 계약보다 늦게 생김 | — |

기준연도는 토지특성 조사 기준일이지 **용도지역이 실제로 바뀐 날이 아니다.** "관측"은 계약연도 기준일 값이 있다는 뜻이고, 그해 중간에 바뀐 것까지 보장하지 않는다.

코드 연결: 시도 12는 4-A 대응표, 전북 52←45·강원 51←42는 토지 코드 이력 층 V1의 앞자리 교체 규칙을 썼다. 승인된 대응이 없는 시군구 개편(부천·화성 일반구, 인천 2026-07 개편, 군위 편입)은 연결하지 않고 확인 불가로 남겼다.

### 같은 해 변경 위험 (품질 정보)

기준일 값이 계약일까지 유지됐는지는 알 수 없다. 대신 **쓴 기준일 다음 기준일**의 값과 비교해 위험을 표시한다.

| 계약연도 기준 관측 495,605건 | 건수 | 비율 | 뜻 |
|---|---:|---:|---|
| 다음 기준일도 같은 값 | 458,429 | 92.5% | 그 사이 변경 흔적 없음(그 사이 바뀌었다 되돌아간 경우는 못 봄) |
| **다음 기준일 값이 다름** | **1,610** | **0.3%** | 기준일과 다음 기준일 사이에 바뀜. 계약일이 변경 뒤면 실제와 다르다 |
| 다음 기준일 없음 | 35,566 | 7.2% | 대부분 2026년 계약. 아직 확인 불가 |

행 파일에는 계약 연·월, 쓴 기준일(`base_date`), 추정일 때 뒤 기준일(`base_date_after`), 위 표시(`stability`), 최신 기준연도·값을 둔다. 확인 불가와 "다음 기준일 값이 다름" 행은 기준일별 원본 이력(`base_history`)도 보존한다.

## 3. 원천 대조 (상가·공장)

상가·공장은 거래 원천에 용도지역이 있다. 다만 원천 값이 토지특성에서 왔을 수 있어 정답률이 아니라 정합이다.

| slim 값 | 원천과 같음 |
|---|---:|
| 계약연도 기준(전체) | **98.7%** (129,835 / 131,553) |
| — 관측 | 98.7% (128,732 / 130,378) |
| — 인접(이후) | 93.1% (925 / 994) |
| 최신 | 97.7% (128,513 / 131,553) |

계약연도 기준 값이 최신값보다 원천과 1.0%p 더 맞는다. 계약 후 관측(인접 이후)은 93.1%로 떨어져, 이후 관측을 계약 당시 값처럼 쓰면 안 된다는 원칙이 숫자로 확인된다.

AL_D155(현재 보강 표시값, 최신판 대표 라벨)와는 대표 라벨이 같은 비율 83.7%, 계약연도 기준 값이 AL_D155 라벨 중 하나에 들어가는 비율 97.4%다. 대표 라벨 차이 대부분은 한 필지의 복수 용도지역 중 무엇을 대표로 골랐는지의 차이다(기존 진단과 같음).

## 4. 적용 후보 규칙 (미적용)

D-050(제품 용도지역은 대표 1개)·D-051(원장 `zone_type` 미덮기, 표시=필터)에 걸리므로 결정 전에는 바꾸지 않는다. 2026-10-18 검토 의견 반영.

1. **기존 필드는 그대로 둔다.** 거래 원천 `zone_type`과 지금 보강 표시값(AL_D155 최신판 대표 라벨)의 의미와 값을 바꾸지 않는다.
2. **새 값은 별도 필드로 공급한다.**
   - 계약연도 기준 관측: 값, 상태(관측·추정·인접 이전), 기준일, 같은 해 변경 위험 표시
   - 최신 관측: 값, 기준연도
   - 인접(이후)·확인 불가는 계약연도 기준 값을 비운다. 계약 후 관측을 계약 당시 값으로 쓰지 않는다.
3. **표시 문구는 기준일을 드러낸다.** "용도지역(2023년 기준)". "거래 당시 용도지역"이라고 쓰지 않는다. "다음 기준일 값이 다름" 행은 변경 가능성 안내를 붙인다.
4. **기본 표시값·회귀 입력 변경은 비교 검증 뒤 결정한다.** 같은 표본에서 기존(최신값) 모형과 계약연도 기준 모형을 홀드아웃 비교하고, 목록·필터 결과 차이를 센 다음 정한다.
5. 확인 불가는 추정해서 채우지 않는다. 원인(코드가 계약 뒤 생김, 필지 없음, 기준일 없음, 값 둘)과 원본 이력만 보존한다. 승인 대응이 없는 시군구 개편 지역(약 7천 건)은 4-A처럼 근거를 갖춘 대응표가 생긴 뒤 다시 잰다.

적용하려면 enrichment 표에 열 추가와 기존 행 값 채움이 필요하다. 기존 결과를 바꾸는 일이므로 별도 승인 대상이다.
