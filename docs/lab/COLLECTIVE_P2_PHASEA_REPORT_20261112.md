2. **동 단위** = leaf 이름(addr4가 리가 아니면 addr4, 아니면 addr3, 읍↔면 같은 단위). 같은 키 안에서 leaf 이름은 하나인데 코드 앞 8자리만 다른 키 **696개는 전부 화성시**(옛 41590 코드 ↔ 행정구 신설 후 코드)다 → 같은 동이므로 분할 대상이 아니다.
3. 동 단위 쌍 판정

   - (c) 그 밖
   - 키: 쌍 하나라도 (a) → (a), 모두 (b) → (b), 나머지 (c).
4. **거리 기준 대체:** 지오코드(`collective_building_geocodes`)는 키 단위 5,341건뿐이고 동 단위 좌표가 없다. 지번은 법정동마다 따로 매겨져 동 사이 비교가 의미 없다. 그래서 토지 DB `region_neighbors`(읍면동 인접 그래프)를 썼다. 그래프에 없는 코드는 근거 없음으로 둔다.
