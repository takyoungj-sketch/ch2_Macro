## 1. 질문 (랩, 두 결)

같은 그래프에 M2와 금리를 겹치지 않는다.

| # | 질문 | 기본 축 |
|---|------|---------|
| L | 유동성이 늘어난 해에 전국 거래도 늘었는가 | M2 YoY ↔ 거래 **건수** YoY (금액은 다음) |
| R | 금리가 오른 해에 전국 거래는 줄었는가 | CD 91일 **%p** ↔ 거래 **건수** YoY |

대표금리 = **CD(91일)** (기본 화면).  
확인용 = **국고채(3년)** · **한국은행 기준금리** (`data/*기준금리*.csv`).  
COFIX는 주담대 질문용, 1차에 넣지 않는다.

## 3. 1차 분석 (연 관측 ~16)

수준 Pearson은 참고만. 본실험은 변화량.

| 단계 | 내용 |
|------|------|
| 그래프 | 두 축 시계열 (예: CD 수준 vs 전국 총 건수). 「추세 주의」 |
| 본실험 | 금리 `d_pp`(전년 %p), M2·거래 `yoy_pct` |
| 시차 | **1년**만. 월 시차는 2차 |
| 유형 | 8대 + 합계. 건수 1순위, 금액 2순위, 단가 3순위(전국 P50 시계열 이후) |

8유형 병합은 프로필 `yearly_mix`와 같다 (D-027): 상가 = 일반상가+집합상가, 공장 = 일반+집합공장.

전국 합은 **시도 grain을 더하지 않고** 원장·연도 마트를 **한 겹**으로 합친다. 시군구+시도를 동시에 더하면 중복이다.
