- 값은 확정·후보 동일일 때만 있다. 다른 상태에 값이 들어간 행 0(CHECK).
- 후보 동일 값의 사용 승인 0건. 표본 판정 뒤 변수별로 켠다.
- 계약연도 용도지역 "확정" 498,529 중 계약연도 관측은 495,605이다. 나머지는 인접연도(이후 2,541 · 이전 379)와 앞뒤 일치 추정 4이며, `timing`으로 구분하고 사용 승인은 끈다. 다음 기준일 값이 다른 1,610건은 `change_risk = next_base_differs`, 다음 기준일이 없는 35,940건은 `undetermined`.
- "판단 불가" 7,170건은 승인 대응이 없는 코드 개편 지역이다. 추정해 채우지 않았다.
- 대지면적은 제품용 지목 규칙(4-F 정책 6)이 정해지기 전이라 모두 사용 승인 꺼짐.
- 계약 뒤 판으로 읽은 연결 409,837건은 건물 변수의 `timing = post_contract_register`.
- 보류 표시(`hold_flags`): 집합건축물에 연결 402, 판마다 대장구분 다름 98, 확정 건물의 사용승인이 계약연도보다 늦음 421.

**집합 단지 집계값:** 이 공급표는 복합이라 단지 값이 없다. 계약 DDL에서는 `value_level = complex_aggregate`(D·F 등급 합산값)가 후보 동일 상태가 될 수 없게 막아, 단지 합산값이 개별 건물의 확정 속성으로 나가지 않게 했다. 집합 공급표를 만들 때 적용한다.
