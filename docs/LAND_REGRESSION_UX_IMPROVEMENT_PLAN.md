## 1. 범위와 지분거래 전제

토지 회귀는 선택한 지역·용도지역·지목·기간·거래 조건 안에서 개별 거래의 **단가(만원/㎡)**와 변수의 관계를 설명한다. 집합의 거래금액 회귀, 주거 지역회귀의 단지 중앙단가 모형과 종속변수·분석 단위가 다르다. 결과 상태·표·문체는 통일하되 실제 표본과 산식의 차이는 보존한다.

사용자 확인 사항:

- 지분거래는 대장 보강이 불가능해 개별공시지가를 연결할 수 없다. 일반적인 미수집 결측과 구분해야 한다.
- 지분거래가 많은 두 지역에서 공시지가 모형의 표본이 크게 줄어드는 것은 이 구조적 제약과 관련된다. 전부를 단순 결측이나 추가 보강 대상으로 설명하지 않는다.
- 지분거래에 공시지가를 평균·인접 필지·행정동 대표값 등으로 임의 대입하지 않는다. 재보강을 반복하거나 다른 필지의 값을 대신 연결하지 않는다.
- 공시지가를 켠 적합·예측에서는 지분거래를 제외한다. 그 상태에서 공시지가 없는 후보를 탐색하더라도 지분거래를 다시 투입하지 않는다.
- 공시지가를 끈 일반 회귀의 지분 포함 여부는 기존 사용자 필터를 따른다. 모든 화면의 전역 지분거래 기본값을 이번에 바꾼 것은 아니다.

권장 후속 분석 흐름은 먼저 지분거래를 제외한 표본을 확인하고, 그 안에서 공시지가 연결 여부·동별 표본·검증 가능성을 판단하는 것이다. 작은 공시지가 연결 표본을 전체 토지시장의 대표 표본처럼 설명하지 않는다.

이번에는 L-01~L-05 정합성 수정을 선행 적용했다. 나머지 UI·통계·문체 개선은 다른 유형의 문서와 함께 구현한다. 기존 Macro 탐색을 모형추천2로 대체하지 않는다.

## 2. 직접 확인한 결과

### 2.1 신림동 단독

5년 창, 용도 2주 × 지목 대, 면적·도로조건·거래유형·연도추세, 로그 단가·로그 면적, IQR 끔, 범주 결측 유지로 실행했다.

- 적합 165건, R² 0.53577, Adj R² 0.51196.
- 면적 247㎡·계약연도 2024·기준 도로조건·직거래의 기존 추정값은 149.21만원/㎡였다. 평균 추정범위 104.27~213.52, 개별 거래 예측범위 36.59~608.45만원/㎡로 표시됐다.
- 면적을 100㎡로 바꿔도 기존 추정값이 남는 것을 재현했다.
- 추천은 선택된 변수·척도 안에서 AIC 순으로 후보를 제시했다. MAPE는 원단가 학습 오차이며 별도 검증 오차가 아니었다.

### 2.2 신림동 + 봉천동, 법정동 FE + 공시지가

- 수정 전 원천 469건 중 ‘공시지가 결측 444건 제외’, 적합 25건으로 표시됐다.
- 로그 R² 0.95020, Adj R² 0.92032. 절편 포함 계수 10개로 계수당 거래는 약 2.5건이다.
- 기준 법정동은 신림동. 봉천동은 기준 대비 약 −8.2%, p=0.66314였다. 두 지역의 차이가 확정적으로 식별됐다는 의미가 아니다.
- 공시지가 로그 계수는 약 0.8978, p=0.05091이었다. 10% 기준에서는 강조되지만 5% 기준에서는 유의하지 않다.
- 공시지가 설명은 ‘1% 높을 때 단가 +145.4%’로 잘못 표시됐다. 올바른 1% 변화 해석은 약 +0.90%다.
- 현재 모형 25건과 달리 추천은 공시지가를 빼고 469건을 사용했지만 그 차이를 설명하지 않았다.

### 2.3 수정 후 확인한 표본

2021-10-01~2026-09-30의 두 지역·동일 용도/지목 조건을 실제 API로 검증했다.

1. 분석 후보 469건.
2. 대장 보강 불가 지분거래 347건 제외.
3. 나머지 122건 중 공시지가 미연결 97건 제외.
4. 공시지가 포함 모형은 25건 적합.

공시지가를 제외한 후보 탐색은 122건을 사용하고, 지분거래 347건을 다시 넣지 않는다. 현재 공시지가 모형 25건과는 여전히 표본·변수가 다르므로 직접 지표 비교를 금지하는 안내를 표시한다.

이 수치들은 검토 사례다. 데이터 갱신 후 달라질 수 있으며 제품 상수가 아니다. 다른 지역·모든 변수 조합·글자 확대·밝은 테마 전체를 검증한 것은 아니다.

## 3. 이번에 적용한 수정

### L-01. 로그 변수의 1% 변화 해석 [P0 · 적용]

- 공시지가 로그 계수의 1% 변화는 `(1.01^β−1)×100`으로 계산한다. `exp(β)−1`을 1% 변화처럼 설명하던 오류를 수정했다.
- 선형 단가 + 로그 공시지가는 `β×log(1.01)`의 단가 차이로 설명한다.
- 로그 단가 + 원면적은 1㎡ 증가에 따른 비율 차이로 표시한다. 금액 차이로 표시하던 경로를 수정했다.
- 로그 상수의 역변환 값을 반올림해 ‘0만원/㎡ 출발 수준’처럼 설명하지 않는다. 기준 조건의 로그 상수로 표현한다.

### L-02. 공시지가 표본의 구조적 제외와 추천 비교 [P0 · 적용]

- 원거래의 canonical 지분 여부를 회귀 입력에 전달한다. 표시 문자열로 지분 여부를 추측하지 않는다.
- 공시지가 모형은 보강 불가 지분거래와 그 외 공시지가 미연결을 순서대로 제외하고 각각의 수를 알린다. 어떠한 공시지가 대체값도 생성하지 않는다.
- 공시지가 모형에 지분거래 추정을 요청하면 HTTP 400으로 거부한다.
- 추천 API는 공시지가 제외 여부를 응답의 `excluded_blocks`와 경고로 명시한다. 프런트에서 조용히 체크를 끄고 요청하던 처리를 제거했다.
- 공시지가를 켠 상태에서 시작한 추천에도 지분거래 제외 정책을 유지한다.
- 추천 제목은 ‘후보 간 공통 표본’으로 한정하고, 현재 모형과 표본·조건이 다르면 직접 비교 불가를 표시한다. 추천 MAPE는 ‘학습 MAPE’로 표시한다.

이 수정은 현재 모형과 추천을 같은 표본에서 비교하는 기능까지 구현한 것이 아니다. 해당 기능은 L-08의 후속 과제다.

### L-03. 로그 추정·평균 범위의 기준 [P0 · 적용]

- 기존 점 추정은 `exp(로그 예측값)`이었으나 추천 학습 오차에는 잔차 역변환 보정이 적용됐다.
- 점 추정과 평균 추정범위에 같은 Duan smearing 보정을 적용해 원단가 평균 기준으로 맞췄다.
- 개별 거래 예측범위는 로그 관측 예측구간을 원단가로 역변환한다. 평균 보정계수를 개별 거래 구간에 다시 곱하지 않는다.
- 평균 추정범위는 보정계수를 고정한 근사이며, 이 한계를 화면에 표시한다. 보정계수 추정의 불확실성까지 반영한 범위는 아니다.
- 응답에 `log_smearing_factor`를 제공한다. 선형 모형은 1이다.

같은 입력의 추정값은 수정 전과 달라질 수 있다. 이는 평균 척도 정합성 수정이며 성능 개선을 뜻하지 않는다. 예측구간 자체가 실제 시장가격을 보장하는 것도 아니다.

### L-04. 요청·입력·이전 결과 상태 [P0 · 적용]

- 지역·기간·필터·변수·척도·결측 처리·IQR을 포함한 요청 전체로 현재 설정과 적합 결과를 비교한다.
- 설정이 달라지거나 적합/추천 요청 중이면 추정 계산을 막고 이전 추정값을 표시하지 않는다.
- 추정 결과에는 요청·계수·입력의 식별 정보를 대응시킨다. 면적·연도·도로·거래유형·법정동·공시지가 입력을 바꾸면 이전 값이 현재 결과처럼 남지 않는다.
- 늦게 도착한 응답도 현재 입력·모형과 일치할 때만 표시하고, AI에는 현재 표시 가능한 결과만 전달한다.
- 추천도 실행 당시 조건과 현재 조건이 같을 때 표시한다. 이전 지역·필터의 추천이 남는 상태를 줄인다.

### L-05. 반복 실행 [P0 · 적용]

회귀 입력을 거래 ID로 안정 정렬한다. 동일 데이터와 요청의 추천·계수·산점도 표본 추출이 DB 반환 순서에 의존하지 않도록 한다. 실제 API 반복 적합 응답이 일치하는지 확인했다.

## 4. 후속 개선안

### L-06. 분석 범위와 표본 흐름 [P1]

- 회귀 탭의 제목을 ‘롤링 구간별 평균 변동’ 대신 ‘토지 회귀분석’으로 맞춘다.
- 지역·용도지역 전체 명칭·지목·기간·필터·표본을 상단에 명시한다. ‘신림동 전체’와 ‘선택한 용도×지목 셀’을 혼동하지 않게 한다.
- 지역 추가 → 지분 제외 → 필지/대장 연결 → 공시지가 연결 → 기타 결측·IQR → 최종 적합의 수를 보여준다. 각 제외 수의 분모와 중복 집계를 명시한다.
- 공시지가 제외 사유에 ‘구조상 대상 아님’과 ‘그 밖의 미연결’을 구분한다. 지분거래에 ‘대장 재보강’ 행동을 제안하지 않는다.
- 동별 원천·지분·연결·적합 건수를 제공한다. FE를 켰어도 한 동의 적합 표본이 극소수면 이를 명시한다.
- 일반 회귀에서 지분거래 제외를 권장하는 시작 흐름을 검토하되, 기존 목록·기본통계의 지분 정책과 혼동하지 않는다. 전역 기본값 변경은 별도 합의·검증 범위다.

### L-07. 지표·계수·추정 입력 [P1]

- 로그 R²·Adj R²의 척도를 표시하고, 학습 오차·검증 오차·검증 불가를 다른 유형과 같은 방식으로 구분한다. 현재 토지 기본 결과에는 CV 지표가 없다.
- 소표본 경고는 미달 기준별 실제 값과 계수 수를 보여준다. R²가 높더라도 표본이 크게 줄었다는 사실을 먼저 읽게 한다.
- 도로·거래유형의 접두어를 지워 ‘-’만 남기지 않는다. 원본 코드의 의미를 확인해 변수 소속과 기준 범주를 표시한다.
- 법정동 FE는 기준 동·동별 표본·신뢰구간을 함께 표시한다. 불유의한 계수를 확정적인 지역 차이로 번역하지 않는다.
- 연도 추세는 다른 변수를 통제한 해당 표본의 관계다. 지역 전체 시세 상승/하락률이나 미래 전망으로 단정하지 않는다.
- 공시지가의 원/㎡ 단위·기준연도·자료 기준일·학습 범위를 표시한다. 과거 거래연도와 공시지가 기준연도의 관계를 확인할 수 있어야 한다.
- 입력 기본값이 범위 중간값임을 명시하거나 더 적절한 대표값을 검토한다. 현재 기본 면적 1,173㎡는 최솟값·최댓값의 중간값이며 대표 거래 면적을 뜻하지 않는다.
- 평균 추정범위와 개별 거래 예측범위는 공통 용어를 쓰되 단가는 만원/㎡, 거래금액은 만원으로 구분한다.

### L-08. 같은 평가 대상에서 변수·지역·후보 비교 [P0 후속 설계]

- 공시지가 유무의 효과는 동일한 공시지가 연결·비지분 표본에서 비교한다. 전체 비지분 표본의 별도 모형도 병행 표시할 수 있지만 표본을 구분한다.
- 신림동 단독과 봉천동 추가의 성능은 동일한 신림동 검증 거래에서 비교하는 설계를 검토한다. 단순 R² 상승을 확장 효과로 판정하지 않는다.
- 무작위 분할과 시간 기준 검증의 목적을 구분하고, 표본 부족·동별 부족 시 평가 불가를 표시한다.
- 후보 선정에 사용한 오차와 독립 최종 검증을 구분한다. 현재 추천의 학습 MAPE를 예측 성능으로 해석하지 않는다.
- 작은 25건 모형에는 과도한 변수 탐색을 권하지 않는다. 변수 축소·기준 표본 유지·지역별 구성 확인을 먼저 제공한다.

### L-09. 진단·가독성·문체 [P1]

- 공시지가를 켜면 해당 변수의 부분회귀도도 제공한다. 현재 부분회귀도에는 면적·연도만 있다.
- 부분회귀도는 모형 전체 잔차 진단의 대체가 아니다. 복합·집합과 같은 잔차 진단 진입점과 표본 표시를 적용한다.
- ‘순수 관계’는 ‘모형에 포함한 다른 변수의 영향을 통제한 관계’로 표현한다.
- 후보 변수명을 한글로 표시하고 현재 모형과 달라지는 설정을 요약한다. 적용/재실행 동작과 추천의 탐색 범위를 명시한다.
- 추천·산점도 영역의 밝은 배경과 낮은 글자 대비, 계수 표의 중첩 스크롤, 반복되는 용도지역 주의문을 정리한다.
- p값은 `<0.001` 등으로 표시하고 유의수준 10%를 명시한다. 5% 기준과 혼동시키지 않는다.
- 모달 제목·닫기·배율·표·버튼·도움말 형식은 5앱 패리티 작업과 함께 적용한다.

문구 초안:

- `개별공시지가 결측 444건 제외` → `지분거래 347건은 공시지가 분석 대상에서 제외합니다. 나머지 거래 중 공시지가가 연결되지 않은 97건을 추가 제외했습니다.` 숫자는 실제 응답을 사용한다.
- `법정동 FE` → `법정동별 수준 차이 반영`. 도움말에는 고정효과·기준 동·식별 한계를 설명한다.
- `다른 변수 고정 · 통계적 추정` → `조건별 토지 단가 추정`.
- `토지 모형 추천 · 공통 표본` → `후보 간 공통 표본`과 `현재 모형과 비교 가능 여부`를 각각 표시한다.
- `표본이 적어 참고용` → `적합 거래 25건 · 계수 10개로 계수가 불안정할 수 있습니다.` 구체적인 미달 사유를 사용한다.
