## 1. 왜 만드는가

| 문제 | 이 페이지가 하는 일 |
|------|---------------------|
| Macro에 IQR, Adj-R², CV-MAPE, 분위수 회귀, Twin 등 용어가 반복 등장 | UI마다 긴 설명을 넣지 않고 `?` → 학습 페이지로 연결 |
| 감정평가사·실무자는 통계 용어에 익숙하지 않을 수 있음 | 수식 없이 직관 → 선택적 「조금 더 알아보기」 |
| CH2는 AVM이 아니라 **탐색·판단 도구** | 매 장마다 **주의** 박스로 상관≠인과·표본편향·외삽을 반복 |

**CH2 Data 세 축 (양방향)**

```
Learn (개념)     ch2data.com/learn/stats/
    ↔  Insight (실험)   macro.ch2data.com/insight/
    ↔  Macro (도구)     macro.ch2data.com/land|built|collective|…
```

| 축 | 질문 | 예 |
|----|------|-----|
| **Learn** | 평균·IQR·회귀·CV-MAPE가 **무엇**인가? | `/learn/stats/cross-validation/#cv-mape` |
| **Insight** | 부동산 데이터에 **이런 질문**을 던졌더니? | 광평수 토지 가격 실험 → t-test·회귀·CV-MAPE는 Learn 링크 |
| **Macro** | **도구**에서 숫자를 어디서 보는가? | `CV-MAPE 13.2% ?` → Learn → 「Macro에서 확인하기 →」 |

허브 = **교과서**, Macro = **실습실**. Insight = **실험 기록**. 역할을 섞지 않는다.

### 1.1 사이트 트리 (허브)

```
ch2data.com/learn/stats/
├─ I. 자료를 보다
├─ II. 표본에서 결론으로
├─ III. 관계
├─ IV. 새 자료에서도 맞는지
└─ V. 기초 머신러닝
```

장 목록·slug·작성 상태는 §16.

### 1.2 허브 노출 단계

| 단계 | 노출 |
|------|------|
| **지금** | Macro `?` 딥링크 · Macro 게이트웨이 **작은 링크**만. 허브 메인 대형 카드 **없음** |
| **1차 12장 후** | 허브에 정식 카드: 「통계학 & 데이터 분석」 + 한 줄 설명 + 학습하기 → |
| **검색** | Learn은 허브 공개 정적 페이지 → 「IQR이란?」「조정 R²란?」 등 **비가입자** 유입 가능 |

### 1.3 Macro ↔ Learn 양방향 (SSOT)

**Macro → Learn**

- UI: `CV-MAPE 13.2%` 옆 `?`  
- URL: `https://ch2data.com/learn/stats/cross-validation/#cv-mape`  
- 새 탭 권장 (`target="_blank" rel="noopener"`)

**Learn → Macro**

- ④ CH2 Macro에서는? 본문 후 **「CH2 Macro에서 확인하기 →」**  
- 예: 모형추천 → `https://macro.ch2data.com/collective/` (집합 · 모형추천 탭)  
- 장·anchor마다 `macro_href` 를 계획서·HTML frontmatter에 기록 (딥링크 확장 여지)

**Insight → Learn**

- 실험 본문에서 t-test·회귀·CV-MAPE 등 용어 → 해당 Learn slug 링크  
- Learn에서 Insight 역링크는 **관련 실험이 있을 때만** (예: 상관 → Insight #1)

| 항목 | 기준 |

| **제목** | 섹션 h2는 **크고 굵은 파란색** (`#1d4ed8`, font-weight 800). 문단·섹션 구분이 한눈에 보이게 |
| **시각화** | 분포·비교·추세가 핵심인 장은 **SVG 그래프**로 설명. ASCII 도식은 보조 |
| **분량** | 일률적이지 않음. 평균·중앙값 등은 짧게, 회귀·교차검증·AIC 등은 **현재 분량의 1.5~2배** 허용 |
| **선택** | 「조금 더 알아보기」에 **중급층**: K-fold 도식, 수식, 지표 비교, MAPE 한계 등 |
| **금지** | 본문 첫 문단에 증명, 딥러닝·신경망 정규과정, 이번 단계에서 Macro 캡처를 새로 붙이기 |
| **철학** | Macro는 평가액을 **내려주는 AVM**이 아니라, 데이터로 **탐색·판단**할 수 있게 하는 통계 도구 |

### 2.1 페이지 성공 기준 (독자가 마지막에 말할 수 있는 문장)

| 장 (예) | 이해했다면 이렇게 말할 수 있다 |
|---------|-------------------------------|
| 평균·중앙값 | 「Macro가 평균뿐 아니라 중앙값도 보여주는구나.」 |
| R²·모형추천 | 「R²가 높은데도 다른 회귀식이 추천될 수 있구나.」 |
| CV-MAPE | 「CV-MAPE는 이미 본 자료를 잘 설명했느냐가 아니라, 안 본 자료에서도 잘 맞았느냐를 보는 거구나.」 |

### 2.2 장당 최소 요소 (1차 12장)

각 페이지: **① 핵심개념 1개 + ② 부동산 숫자 예제 1개 + ③ Macro 실제 적용 1개 + ④ 오해하기 쉬운 점 1개** (주의 박스).  
2026-10-04 이후 다시 쓰는 장의 최소 요소는 §16.2다.

### 2.3 작성 단계 (1차 효율)

| 단계 | 내용 | 상태 |
|------|------|------|
| **A. 초안** | 12장 HTML — ①~④·주의·Macro CTA·이전/다음. 존댓말·풍부한 설명의 **골격** | **완료** |
| **B. 확장** | 12장 문장·예제·⑤ 화면 모형 (`learn-macro-mock`) | **완료** |
| **C. 그래프** | 장별 SVG 추가. 02~11 + IQR·표본·log·model-fit | **완료** |
| **D. Macro `?`** | glossary 팝업 → Learn URL (`statsLearnLinks.ts`) | **1차 연결 완료** |

**원칙:** 12장 **초안을 먼저** 올려 로드맵·링크·톤을 고정하고, 그래프·Macro 캡처는 2차 패스에서 채운다. 그래프가 없어도 ASCII·숫자 예제로 읽을 수 있어야 한다.

### 2.4 그래프 가이드

| 장 | 그래프 (1차 우선) | 형식 |
|----|-------------------|------|
| 평균·중앙값 | 왜곡 분포에서 평균 vs 중앙값 | SVG 막대·수직선 |
| 분위수 | Q1·중앙값·Q3 박스 | SVG box plot |
| 분산·표준편차 | 같은 평균·다른 퍼짐 | SVG 두 곡선 |

| 회귀분석 | 산점도 + 회귀선 | SVG |
| 교차검증 | 학습/검증 분할 | SVG 막대 + ASCII |
| IQR·이상치 | Tukey fence | SVG (2차) |

파일: `learn-stats.css`의 `.learn-chart`, HTML 인라인 SVG. 외부 차트 라이브러리는 1차에서 쓰지 않는다.

참고 흐름: NIST Handbook (EDA → 비교 → 모델링), scikit-learn User Guide (선형모형 → 모델 선택 → 교차검증 → 평가). CH2는 그 깊이까지 가지 않고 **해석 가능한 회귀·평가**에 집중한다.

## 5. 1차 공개 — 학습 흐름 (12장, 2026-10-01 기록)

아래 표는 **당시 Macro 사용 경로**로 공개한 12장이다. 2026-10-04 이후 읽는 순서는 **§16**이다. 페이지 번호는 2026-10-05부터 목차 순서 01~23이다.

| 순서 | slug (안) | 제목 | Macro 연결 (핵심) |
|------|-----------|------|-------------------|
| 1 | `data-and-variables` | 데이터와 변수 | 거래가격·면적·용도지역·지목 |

| 5 | `iqr-outliers` | 이상치와 IQR | IQR 1.5 / 2 / 3 |

## 7. 페이지 템플릿 (2026-10-01, 공개된 12장이 아직 쓰는 틀)

새로 쓰거나 다시 쓰는 장의 틀은 **§16.2**다. 아래는 이미 올라간 12장의 구성이다. 1단계에서는 이 블록(④⑤, 확인하기)을 **고치거나 지우지 않는다.**

각 장은 **동일한 틀**을 따른다.

```
┌─────────────────────────────────────────┐
│ 03. 분위수                    [로드맵] │
├─────────────────────────────────────────┤
│ ① 한 줄 정의 (Macro 맥락에서 왜 읽는지)   │
│ ② 쉽게 이해하기 (부동산 사례 → 개념)     │
│ ③ {주제별 질문 제목}                     │
│ ④ CH2 Macro에서는?                      │
│ ⑤ Macro 화면 (캡처 또는 링크, 가능 시)   │
│ ⚠ 주의 (통계적 함정 1개, 매 장 필수)     │
│ ▶ 조금 더 알아보기 (중급: 식·도식·비교)  │
│ ← 이전 장    CH2 Macro에서 보기 →   다음 →│
└─────────────────────────────────────────┘
```

### 7.1 섹션 규칙

| 섹션 | 규칙 |
|------|------|
| **① 정의** | Macro 화면과 연결되는 **진입 문장**. 교과서 정의만 던지지 않음 |
| **② 예제** | **부동산 사례 먼저 → 개념 이름**. 토지·아파트 **구체 숫자**. 어려운 주제는 100건 분할·간단 ASCII 도식 1개 |
| **③ 질문** | 고정 문구 「그래서 언제 무엇을 쓰나」 **사용 안 함**. 장마다 질문형 제목 (§7.3) |
| **④ Macro** | **실제 있는 기능만**. 화면 이름·탭·필터를 정확히 (코드·UI 확인) |
| **⑤ 화면** | 정적 캡처 + 가능하면 **딥링크**. UI 변경 시 캡처만 갱신 |
| **⚠ 주의** | **통계적 함정 1개**. 법적 면책문 톤 금지. §8 예시 |
| **조금 더 알아보기** | `<details>`. K-fold 도식, 수식, 지표 비교(R² vs CV-MAPE), MAPE 한계 등 **중급층** |

### 7.2 진입 스토리 (권장)

②에서 **부동산 거래 한 건·한 시장**부터 시작하고, 그다음에 변수·평균·교차검증 같은 이름을 붙인다.

> 부동산 거래자료 한 건에는 거래가격, 면적, 용도지역, 지목 등 여러 정보가 들어 있다. 이처럼 분석의 대상이 되는 개별 항목을 **변수**라고 한다.

「교과서 정의부터」가 아니라 **「이 숫자가 뭘 의미하지?」**부터.

### 7.3 ③ 섹션 제목 예시 (장마다 다르게)

| 장 | ③ 제목 (예) |
|----|-------------|
| 평균·중앙값 | 왜 평균만 보면 안 될까? |
| 이상치·IQR | 왜 이상치를 확인할까? |
| 상관관계 | 상관계수가 높으면 관계가 강한 걸까? |
| R²·모형 성능 | 왜 R²가 가장 높은 모형을 고르지 않을까? |
| 교차검증 | 왜 R²가 가장 높은 모형을 고르지 않을까? (설명력 vs 예측력) |
| 데이터·변수 | 왜 변수 종류를 구분할까? |

CV-MAPE 등 **정확한 정의가 필요한 지표**는 엄밀한 문장 먼저, 바로 아래에 「쉽게 말하면」 한 문장으로 풀어 쓴다.

## 8. ⚠ 주의 박스 — 예시 (1차)

매 장 하단(또는 ④ 직후)에 고정 컴포넌트 `.stats-caution`으로 렌더한다.

| 장 | 주의 (통계적 함정 1개) |
|----|----------------------|
| 평균·중앙값 | 평균은 **극단값(고가·저가 거래)** 의 영향을 크게 받는다. |
| 상관관계 | 상관관계가 **인과관계**를 의미하지 않는다. |
| R² | R²가 높다고 **예측력**이 반드시 좋은 것은 아니다. |
| MAPE·CV-MAPE | 실제값이 매우 작으면 백분율 오차가 **왜곡**될 수 있다. (본문 주의 또는 조금 더) |
| 회귀분석 | 관측 범위를 벗어난 **외삽**은 주의해야 한다. |
| 교차검증 | CV-MAPE는 과거 패턴 추정이다. **낮은 CV-MAPE가 감정평가액을 보장하지 않는다.** |
| IQR | 이상치 제거는 **분석 목적**에 따른 선택이다. 제거 = 잘못된 거래가 아니다. |
| 표본·데이터 | 실거래는 **전체 시장이 아닌 표본**이다. 건수가 적으면 통계가 흔들린다. |
| 12장 종합 | CH2 결과는 **감정평가 결론을 대체하지 않는다**. |
| Twin (2차) | 쌍둥이 지역은 **유사**한 지역 탐색이다. **동일** 시장이 아니다. |

주의 문안은 [CH2_EXPLAIN_CONSTITUTION.md](./CH2_EXPLAIN_CONSTITUTION.md)의 Limitations First와 맞춘다.

## 9. Macro UI 연동 (`?`)

### 9.1 원칙

- Macro 화면의 긴 설명문을 **줄이고**, 지표 옆 **`?`** 만 남긴다.  
  예: `CV-MAPE 12.4% ?` → `/learn/stats/cross-validation#cv-mape`
- 학습 페이지가 **SSOT**. Macro `?`는 요약 1문장 + 링크만 (중복 유지 최소화).
- Insight 본문과 **문장 복제 금지**. 역할이 다름.

## 16. 정규 과정 (2026-10-04~)

## 17. 32장 교육과정 개편 작업계획 (2026-10-07)

### 17.1 합의된 목적과 범위

CH2 Macro의 부가서비스인 이 페이지는 **데스크톱에서 읽는 통계학·기초 머신러닝 교재이자 개념 참고서**다. 사용자는 전체 과정을 순서대로 학습하거나 필요한 개념만 찾아 읽은 뒤 Macro의 통계 기능을 활용한다. 과정 편제는 일반적인 통계학·기초 머신러닝의 개념 의존관계를 따르고, Macro의 메뉴 순서에 종속시키지 않는다.

- 기존의 짧은 설명을 교과서 수준의 정의·원리·예제·해석·한계로 보강한다.
- 정확성을 유지하면서 자연스러운 한국어 설명으로 다듬는다.
- 이해에 필요한 그래프를 늘리고 본문과 연결한다. 단순히 글·그림의 개수를 늘리는 것을 목표로 삼지 않는다.
- **장별로 하나씩 검토 → 집필 → 계산·그림 검증 → 로컬 확인 → 작업 기록** 순서로 진행한다.
- 현재 단계는 1단계 기반 정비와 01~32장 본문 개편 및 장별 검증을 마쳤다. 브라우저 자체 확대를 포함한 최종 통합 검증은 남아 있다. 세부 결과는 §17.9에 기록한다.
- 모바일 개편은 이번 작업의 주요 범위가 아니다. Macro 본체의 통계 산식·API·5앱 UI 변경도 이 계획에 포함하지 않는다.
- 랜덤포레스트·부스팅·주성분분석은 후속 심화 후보이며, 딥러닝은 이번 과정 밖이다.

### 17.2 교육과정 설계 원칙

1. **기술통계 → 확률·표본분포 → 추정·검정 → 회귀 → 예측 평가 → 기초 머신러닝**의 순서를 따른다.
2. 모집단과 표본·편향은 초반에, 표준오차와 표본분포는 신뢰구간 앞에 배치한다.
3. 잔차는 단순회귀에서 소개하고 바로 다음 장에서 진단까지 확장한다. 다중회귀는 독립 장으로 다룬다.
4. 자료에 대한 적합도와 새로운 자료에 대한 예측 성능을 구분한다. R²·조정 R²는 21장, 예측오차는 25장, CV-MAPE는 26장에 배치한다.
5. 지도·비지도학습의 개요와 자료 분할을 과적합·교차검증·규제보다 먼저 설명한다.
6. 회귀와 분류의 차이 및 로지스틱 회귀를 포함해 기초 머신러닝의 균형을 맞춘다.
7. 특정 장만 읽어도 핵심 의미를 이해하도록 필요한 선수 개념은 짧게 요약하고 관련 장을 연결한다.

편제 참고 자료:

- [OpenIntro Statistics, 4판 목차](https://www.openintro.org/go/?id=os4_for_screen_reader): 기술통계, 확률·분포, 추론, 회귀의 개념 연결 참고.
- [An Introduction to Statistical Learning](https://www.statlearning.com/): 회귀·분류, 재표본추출, 규제, 나무, 비지도학습의 범위 참고.

교재의 문장·도표를 전재하지 않는다. 정의와 방법을 확인한 뒤 자체 문장·예제·그림으로 작성하고, 각 장에 직접 참고한 자료를 기록한다. 아래 순서는 CH2 독자를 위한 편집안이며 특정 교재의 목차를 그대로 복제한 것이 아니다.

### 17.3 목표 목차와 장별 작업 목록

기존 slug는 유지한다. 새 slug는 이 계획의 제안값이며, 생성 전에 경로 충돌을 확인한다. 장별 상태와 검증 제한은 §17.9에 기록하며 체크는 §17.8 완료 기준 충족 후에만 한다. 아래 대표 그림은 최소한의 설계 방향이며 최종 장당 그림 수를 고정하지 않는다.

#### I. 데이터와 기술통계

- [ ] **01. 데이터와 변수** — 기존 `data-and-variables`. 관측 단위·변수·척도·결측값을 구분한다. 대표 그림: 관측표의 행·열과 변수 유형 연결.
- [ ] **02. 모집단과 표본, 자료 수집과 편향** — 신규 `population-and-sampling`. 대표성·선택편향·관측과 실험을 설명한다. 대표 그림: 모집단에서 서로 다르게 뽑힌 표본.
- [ ] **03. 그래프로 보는 데이터와 분포** — 기존 `graphs`. 막대·히스토그램·산점도의 용도와 왜도·다봉성을 설명한다. 대표 그림: 같은 자료의 표현 비교와 구간 폭 비교.
- [ ] **04. 평균과 중앙값** — 기존 `mean-and-median`. 중심의 의미와 극단값 영향, 가중평균을 설명한다. 대표 그림: 한 값 변화에 따른 평균·중앙값 이동.
- [ ] **05. 분위수와 상자그림** — 기존 `quantiles`. 백분위·사분위·상자그림의 읽기와 계산 관례를 설명한다. 대표 그림: 정렬 자료와 상자그림의 대응.
- [ ] **06. 분산과 표준편차** — 기존 `spread`. 편차·제곱편차·단위, 모집단과 표본의 계산 차이를 설명한다. 대표 그림: 중심은 같고 퍼짐은 다른 분포.
- [ ] **07. 이상치와 IQR** — 기존 `iqr-outliers`. 탐지 규칙과 오류 확인·민감도 분석을 구분한다. 대표 그림: IQR 경계와 포함·제외 비교. 이상치를 자동 삭제의 근거로 가르치지 않는다.

#### II. 확률과 표본의 불확실성

- [ ] **08. 확률의 기초와 조건부확률** — 신규 `probability`. 사건·조건·독립을 설명한다. 대표 그림: 빈도표와 조건부 비율, 확률나무.
- [ ] **09. 확률변수와 확률분포** — 신규 `probability-distributions`. 이산·연속, 이항·정규·t분포의 역할을 설명한다. 대표 그림: 확률질량과 밀도·구간 면적 비교.
- [ ] **10. 표본분포와 중심극한정리** — 신규 `sampling-distributions`. 원자료 분포와 표본평균 분포를 구별한다. 대표 그림: 반복 추출과 표본수별 평균 분포. 성립 조건과 근사의 한계를 명시한다.
- [ ] **11. 표준오차와 표본수** — 기존 `sample-size`. 표준편차와 표준오차, 표본수와 정밀도를 설명한다. 대표 그림: n에 따른 표준오차 변화. 표본수 증가가 선택편향을 없애지 않음을 설명한다.

#### III. 추정과 검정

- [ ] **12. 점추정과 신뢰구간** — 기존 `confidence-intervals`. 추정량·반복 표집·포함률을 설명한다. 대표 그림: 반복 계산한 신뢰구간과 모평균.
- [ ] **13. 가설검정과 p값** — 기존 `hypothesis-tests`. 귀무·대립가설, 유의수준, 1·2종 오류와 검정력을 설명한다. 대표 그림: 귀무분포와 양측 꼬리 면적. 표본 중앙값을 외부 기준처럼 사용하는 기존 예제를 교체한다.
- [ ] **14. 두 집단 비교와 효과크기** — 기존 `comparing-groups`. 독립·대응 자료, 평균 차이·신뢰구간·효과크기, Welch 검정을 설명한다. 대표 그림: 집단 분포와 평균 차이의 구간.
- [ ] **15. 여러 집단과 범주형 자료의 비교** — 신규 `multiple-groups-and-categorical`. 분산분석·카이제곱검정의 질문과 가정, 다중비교 주의를 설명한다. 대표 그림: 집단 내·집단 간 변동과 관측·기대 빈도.

#### IV. 상관과 회귀

- [ ] **16. 상관관계와 인과관계** — 기존 `correlation`. Pearson·순위상관, 비선형 관계와 교란을 설명한다. 대표 그림: 다양한 산점도와 집단을 나누기 전후의 관계.
- [ ] **17. 단순선형회귀와 최소제곱법** — 기존 `regression`. 기울기·절편·잔차와 최소제곱을 연결한다. 대표 그림: 후보 직선별 잔차제곱합.
- [ ] **18. 잔차와 회귀모형의 가정** — 기존 `residuals`. 선형성·등분산성·독립성, 추론의 정규성 가정, 영향점을 설명한다. 대표 그림: 잔차도·Q–Q 도표·영향점 비교.
- [ ] **19. 다중회귀와 변수의 해석** — 신규 `multiple-regression`. 다른 변수를 고려한 계수, 범주형 변수·상호작용·다중공선성을 설명한다. 대표 그림: 단순 관계와 조건을 고려한 관계 비교.
- [ ] **20. 로그변환과 비선형 관계** — 기존 `log-regression`. 로그-수준·수준-로그·로그-로그 해석과 역변환 주의를 설명한다. 대표 그림: 원척도·로그척도의 관계 및 잔차 비교.
- [ ] **21. 회귀모형의 적합도와 추정의 불확실성** — 기존 `model-fit`. R²·조정 R², 계수 구간, 평균 반응의 신뢰구간·개별값의 예측구간을 설명한다. 대표 그림: 변동 분해와 두 종류의 구간.

#### V. 예측과 모형 평가

- [ ] **22. 통계적 설명과 예측, 지도학습과 비지도학습** — 기존 `supervised-unsupervised`. 설명·예측의 목적, 목표변수, 회귀·분류·군집을 구별한다. 대표 그림: 문제 유형별 입력과 출력.
- [ ] **23. 학습·검증·시험 자료와 데이터 누수** — 신규 `train-validation-test`. 자료 분할과 전처리·변수 선택의 적용 범위를 설명한다. 대표 그림: 자료 분할 흐름과 누수 사례. 시간·지역·건물 중복이 있는 부동산 자료의 분할 주의를 포함한다.
- [ ] **24. 과적합과 편향–분산의 균형** — 기존 `overfitting`. 복잡도와 일반화의 관계를 설명한다. 대표 그림: 모형 복잡도별 학습·검증 오차.
- [ ] **25. 예측오차: MAE·RMSE·MAPE** — 신규 `prediction-errors`. 단위·이상값 민감도·0 또는 작은 실제값에서의 MAPE 문제를 설명한다. 대표 그림: 같은 예측의 오차 기여도 비교.
- [ ] **26. 교차검증과 모형 선택** — 기존 `cross-validation`. K-fold, 시간·집단 분할, CV-MAPE, 튜닝과 최종 시험의 분리를 설명한다. 대표 그림: fold 구성과 fold별 평가 결과.
- [ ] **27. 규제: 릿지와 라쏘** — 기존 `regularization`. 표준화·벌점·계수 축소·교차검증을 연결한다. 대표 그림: 규제 강도별 계수 경로와 검증 오차.

#### VI. 기초 머신러닝과 종합 해석

- [ ] **28. 분류와 로지스틱 회귀** — 신규 `classification`. 확률·판정 임계값, 혼동행렬·정밀도·재현율을 설명한다. 대표 그림: 로지스틱 곡선과 임계값별 판정 변화.
- [ ] **29. 최근접 이웃과 변수의 스케일** — 기존 `knn`. 회귀·분류, 거리·표준화·k 선택을 설명한다. 대표 그림: 스케일과 k에 따른 이웃 변화.
- [ ] **30. 의사결정나무** — 기존 `decision-tree`. 분할·깊이·가지치기, 회귀나무와 분류나무를 설명한다. 대표 그림: 특성 공간의 분할과 나무의 대응.
- [ ] **31. 군집분석** — 기존 `clustering`. 거리·표준화, K-means·계층적 군집과 해석의 한계를 설명한다. 대표 그림: 군집 수별 결과와 덴드로그램.
- [ ] **32. 통계 결과를 읽고 판단하는 법** — 기존 `reading-results`. 표본·추정·검정·모형·검증 결과를 연결한다. 대표 그림: 하나의 결과표를 읽는 순서. 판단 가능한 범위와 남는 불확실성을 구분한다.

기존 23개 장을 유지·확장하고 신규 9개 장(02·08·09·10·15·19·23·25·28)을 추가해 총 32장으로 구성한다.

### 17.4 장별 집필 틀과 문체

각 장은 다음 순서를 기본으로 삼되 내용에 따라 소절을 나눈다. 기존 §16.2의 다섯 항목을 기계적으로 반복하는 방식보다 개념의 설명 흐름을 우선한다.

1. **학습 목표와 빠른 이해:** 이 장에서 답할 질문, 핵심 설명, 대표 그림. 부분 학습자는 여기서 기본 의미를 얻는다.
2. **선수 개념:** 필요한 앞 장 1~3개와 짧은 요약. 반드시 이전 장을 모두 읽어야 이해되는 서술을 피한다.
3. **개념과 원리:** 용어·기호·공식의 의미와 적용 조건. 식은 필요한 만큼 쓰고 각 기호와 단위를 설명한다.
4. **계산 예제와 그래프:** 질문 → 자료 → 계산 → 그림 → 해석 순서로 전개한다. 그림은 관련 문단 가까이 둔다.
5. **비교·반례·자주 하는 오해:** 무엇이 달라지면 결과가 바뀌는지, 어떤 해석이 불가능한지 설명한다.
6. **확인 문제:** 핵심 해석을 확인하는 짧은 질문 1~3개와 접어서 볼 수 있는 답·해설. 계산 반복만으로 채우지 않는다.
7. **CH2 Macro 연결:** 실제 존재하고 확인한 기능만 연결한다. 해당 기능이 없으면 관련 개념으로 마무리하고 빈 블록을 만들지 않는다.
8. **핵심 정리·다음 장·참고자료:** 요점과 다음 질문, 직접 참고한 교재·공식 자료를 제공한다. 심화 수식은 별도 펼침 영역에 둔다.

문체 기준:

- 존댓말 설명체를 기본으로 한다. 정의를 정확히 제시한 다음 쉬운 말로 풀고 예제로 확인한다.
- 숫자를 연속 나열하거나 그림과 무관한 설명을 붙이지 않는다. 각 문단은 질문 또는 설명 목적 하나를 갖는다.
- “문장을 지운다”, “평균의 자리”처럼 전문 개념을 모호하게 대체하는 표현은 정식 개념과 명확한 해설로 바꾼다.
- p값·신뢰구간·표준오차·잔차·오차 등 용어를 일관되게 쓴다. 영어·기호는 첫 등장에 병기한다.
- 본문은 교과서 개념을 충분히 설명한다. Macro 예시가 본문을 대체하거나 개념을 특정 기능으로 제한하지 않게 한다.
- 학습용 추정·예측을 실제 물건의 적정가나 투자 결론으로 표현하지 않는다.

### 17.5 예제·계산·그래프 기준

**자료 구성**

- §16.4의 흥덕 예시 30건을 공통 예제로 활용하되 모든 개념에 강제하지 않는다.
- 공통 자료의 실제 거래 여부와 출처를 확인한다. 확인되지 않으면 실제 시장을 대표하는 관측 자료로 소개하지 않는다.
- 확률·표본분포는 생성 조건이 명시된 모의자료, 분류는 목표 범주가 명확한 별도 자료를 사용한다.
- 각 예제에 실제/가상/모의 자료 구분, 관측 단위·변수·단위·표본수·출처 또는 생성 방법을 적는다. 모의자료는 난수 시드를 고정한다.
- 평균·분산·분위수 계산 관례, 검정 종류·가정, 자료 분할·전처리·모형 설정·반올림 기준을 기록한다.
- 계산은 재현 가능한 스크립트와 자료로 검증한다. 본문·표·그림은 같은 검증된 결과를 사용한다. 계산과 검증은 교재 제작 과정에서 수행하며 서비스 AI의 실시간 재계산 기능을 추가하는 것이 아니다.

**그림 구성**

- 장당 서로 다른 학습 목적의 그림 3~5개를 우선 검토하되 필요성에 따라 조정한다. 기존 2~4개 제한은 고정 기준으로 삼지 않는다.
- 개념 설명, 조건 변화, 비교·반례를 균형 있게 배치한다. 같은 내용을 장식적으로 반복하지 않는다.
- 정적인 인라인 SVG를 기본으로 하고, 입력 변경이 이해에 실제로 도움이 되는 경우에만 가벼운 상호작용을 검토한다.
- 제목·축·단위·범례·표본 조건·출처와 짧은 해석을 제공한다. 개념도는 개념도임을 표시하고 실측 그래프처럼 오인시키지 않는다.
- 공통 예제의 같은 관측값·집단에는 동일한 색을 쓴다. 색만으로 구별하지 않고 선·기호·라벨을 함께 사용한다.
- 1280px·1440px·1920px 데스크톱 폭에서 글자·축·범례를 읽을 수 있게 확인한다. 브라우저 확대 125~150%에서도 겹침을 확인한다.
- SVG의 접근 가능한 이름·설명, 이미지 대체 텍스트, 키보드로 조작 가능한 펼침 영역을 제공한다.
