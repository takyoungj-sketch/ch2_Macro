# 현장용 모바일 기본통계 수정 — 2026-11-08

## 요청과 구현

이전 e022bf1은 모바일 모달 축소 스타일만 복원하여 지역 선택 및 집합 대문 문제를 해결하지 못했다. 이번 변경은 PC 화면과 분리된 모바일 진입점을 제공한다.

- 상단: 토지 / 주거집합 / 비주거집합 직접 이동. 모바일 `/collective/`도 바로 주거 통계 화면을 연다.
- 지역 입력: 세 서비스가 같은 canonical 지역명 검색을 사용한다. 전국 전체 카탈로그 로딩 중 입력을 막지 않는다. 검색 결과를 선택하거나 유일하게 일치하는 지역을 Enter로 확정하면 즉시 통계를 조회한다.
- 지역은 한 개만 보관하고 새 선택은 이전 지역을 대체한다. 지도·복수지역·PC 칩 선택·고급 분석·로그인 안내를 모바일 화면에 표시하지 않는다.
- 토지: 5년 기본통계 용도×지목 매트릭스(평균 단가·거래수), 셀 선택 시 5년 롤링 그래프와 구간 수치.
- 집합: 주거 단지·건물별 / 비주거 도로명별 거래수·중앙값·평균, 이름 선택 시 5년 롤링 그래프와 구간 수치. 유형은 복수 선택하며 주거 기본값은 아파트, 비주거 기본값은 집합상가이다.
- 모달은 작은 제목·닫기 버튼과 스크롤 본문만 제공한다. ESC와 포커스 복귀를 지원한다.
- PC App 및 기존 통계 산식·유료 정책은 수정하지 않는다. 모바일은 기존 무료 5년 API만 호출한다.

## 확인한 기존 문제

집합 모바일은 PC의 시도·시군구/칩 선택 UI를 사용하고 있었고, `analysisUnits`를 모바일 effect에서 비우는 동작이 있었다. 토지 입력은 전국 카탈로그 로딩에 종속되어 비활성화될 수 있었다. 새 모바일 화면은 두 상태 흐름을 사용하지 않고 검색 결과의 canonical 코드로 통계를 요청한다. 집합 API의 필수 addr2도 함께 전달한다.

## 모바일 이용 안내와 범례 이동

- 세 모바일 서비스의 첫 진입에 공통 이용 안내를 표시한다: “CH2 Macro 모바일은 현장에서 간단하게 통계치를 확인하는 용도입니다. 자세한 분석은 데스크탑을 이용해 주세요.”
- 토지 매트릭스 범례는 기본통계에서 제거하고, 토지 화면의 안내 팝업 안에 같은 셀 배치로 제공한다.
- 하단은 체크박스 대신 `확인` / `다시 보지 않기` 두 버튼. 확인은 sessionStorage로 현재 탭의 방문 중 반복 표시를 막고, 다시 보지 않기는 localStorage의 `ch2-macro:hide-mobile-usage-guide`에 저장하여 같은 브라우저·사이트의 세 모바일 서비스에 적용한다. 저장소 사용이 불가능해도 닫기 동작은 유지한다.
- 작은 상단 `안내` 버튼으로 언제든 다시 열 수 있다. ESC, 기본 dialog 포커스 관리, 내부 스크롤, 85dvh 높이 제한을 지원한다. 기존 PC 안내는 변경하지 않는다.
- 토지·집합 타입 검사와 배포 빌드 통과. 브라우저에서 첫 자동 표시, 문구·범례·하단 두 버튼, 확인 후 새로고침, 수동 다시 열기, 다시 보지 않기 후 새로고침을 확인했다.

## 모바일 집합 유형 복수 선택

사용자 요청에 따라 유형의 `전체` 버튼을 제거하고 PC와 같은 기존 자산유형 토글·인코딩 함수를 재사용한다. 주거는 아파트를 기본 선택하고, 비주거는 집합상가를 기본 선택한다. 버튼을 누르면 개별 추가·해제가 가능하며 마지막 한 유형은 유지한다. 선택된 유형 조합을 기존 API에 전달하고 유형 변경 시 열린 상세 모달을 닫는다. PC·API·통계 산식은 변경하지 않는다. 집합 TypeScript 및 production build 통과, 브라우저에서 기본 선택·복수 선택·조회 동작을 확인했다.
