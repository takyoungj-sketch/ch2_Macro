# 기존 AI 어시스턴트 개선 — 2026-10-25

목적은 CH2 Macro의 기능·사용법 설명과 이미 계산된 통계 결과의 해석이다. 이번 변경은 기존 AI의 검증과 화면 문맥을 보완한다.

## 변경

- 채팅·설명 응답의 공통 최종 처리에서 LLM 수치를 화면 스냅샷·Bundle·Explain·성공한 분석 이력·질문에 선택된 제품 지식과 대조한다. Open Mode도 검증한다. 근거 없는 수치가 있으면 CH2 결과 안내로 대체하며, 대체된 답변을 후속 대화 문맥에도 저장한다. 웹 조사는 별도 출처 경로를 유지한다.
- 문장 다듬기는 기존 숫자와 부호를 보존하고 새 숫자를 추가하지 않아야 한다. 소수·천 단위 표기와 백분율 표시 변환을 처리한다. 원시 이력 ID·시각·지문은 수치 근거에서 제외한다.
- ‘상업용’이라는 단어만으로 복합 회귀 질문을 임대 상권 자료로 보내던 분기를 제거한다. 명시적인 상권·공실·임대동향 질문은 기존 상권 지식을 사용한다.
- 분석 이력의 중복 판단에 전체 분석 문맥과 결과 지문을 사용한다. 지역코드·유형·필터·모형 조건을 보관하고 0인 지표·계수·p값을 누락하지 않는다. 조건이 다른 이력 비교에는 주의를 표시하고, 모형·종속변수 척도가 다른 계수는 직접 비교하지 않는다.
- 질문과 답변에 질문 당시 앱·지역·유형·분석 화면·제공된 기간을 표시한다. 요청 중 화면이 바뀌어도 해당 답변의 범위와 근거 표시는 요청 당시 문맥을 유지한다. 서버도 `answer_context`를 반환한다.
- ‘AI 신뢰도’를 ‘답변 근거·주의사항’으로 바꾸고 정확성 보증이 아님을 명시한다. 자료가 없는 화면을 높은 신뢰도로 기본 처리하거나 회귀·VIF·상관을 근거로 임의 표시하지 않는다.
- 역할·제한사항 안내는 대화가 시작되면 접어 답변 공간을 확보한다. 공통 컴포넌트로 5앱에 적용한다.

## 검증

- 기존 AI·AI2·AI3 관련 테스트 **241개 통과**. 외부 LLM과 운영 DB 호출은 모의 응답으로 차단했다.
- 토지·복합·집합·임대·지역프로필 TypeScript 검사 및 Vite 빌드 통과. 기존 대형 번들 경고는 남아 있다.
- 복합 개발 화면에서 사용법 질문을 입력하여 답변, 질문 당시 범위, 근거 안내와 접힘 UI를 확인했다. 이 질문은 제품 경로 안내 템플릿으로 처리됐다.
- 화면 기록: [개선 UI](./CH2_AI_ASSISTANT_IMPROVEMENT_UI.png).

## 범위와 한계

수치 검증은 제공된 근거에 숫자가 존재하는지 확인하는 보조 장치다. 같은 숫자를 다른 지표·단위·지역에 연결한 오해나 비수치 설명 오류까지 판정하지 않는다. 보수적인 검증으로 정상 답변도 결과 안내로 대체될 수 있다. 추가 LLM 호출은 발생하지 않는다.

분석 이력은 기존 서버 메모리 세션과 보관 한도를 사용한다. 서버 재시작 이후의 영구 기억은 추가하지 않았다. 기존 실행 버튼 동작도 유지한다. 이번 작업으로 새로운 분석 실행 기능을 추가하지 않았다.

로컬 변경이며 커밋·원격 푸시·운영 배포는 수행하지 않았다.
