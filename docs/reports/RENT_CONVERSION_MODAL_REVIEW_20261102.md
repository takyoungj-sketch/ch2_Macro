# 임대 전환율 모달·탭 오류보고 · 2026-11-02

## 검증 범위

로컬 임대 앱, 충청북도 음성군 아파트 5년 목록에서 건물 상세 모달의 전환율·롤링 구간·거래 목록·회귀 분석 탭을 확인했다. 실제 화면과 현재 소스를 대조했다. 코드 수정·커밋·배포는 하지 않았다.

탭 선택 자체는 정상 동작했다. 쌍용예가의 롤링 5개 구간과 원장 거래 목록도 로드됐다. 아래는 탭 내 수치·표본·기간 안내 문제다. 회귀 실행은 요청 후 실행 중 상태까지 확인했으며, 완료 결과와 계수 정합성은 검증하지 않았다.

## 1. [P2 · 재현] 선택 풀 건물 수와 실제 평균 계산 표본 수가 다름

재현:

1. `음성지평더웰2차아파트`를 연다.
2. 전세 3건·반전세 1건으로 이 건물 전환율은 `—`다.
3. 인접·동일권 건물에서 `음성아이파크 4.59%`를 선택한다.
4. `선택 풀(2동) 평균 4.59%`가 표시된다.

실제 평균에 기여하는 전환율은 아이파크 하나뿐이다. 선택한 2동과 유효 표본 1동이 구분되지 않아 2동 평균으로 오해할 수 있다.

원인: `BuildingDetailModal.tsx:65`의 `poolMean`은 null 전환율을 제외하지만, `:371`의 표본 표시는 `poolRows.length`를 사용한다.

권고: `선택 2동 · 산출 가능 1동 · 평균 4.59%`처럼 유효 표본 수를 별도로 표시한다. 유효 표본이 0이면 평균을 계산하지 못한 사유를 명시한다.

## 2. [P2 · 재현/소스 확인] 탭에 따라 분석 기간이 달라지지만 전체기간 안내가 없음

재현: `충북혁신도시 LH쌍용예가` 모달에서 전환율 탭은 5년 거래 398건(전세 267 + 반전세 131), 롤링 탭은 2021.10~2026.09 구간을 표시한다. 거래 목록 탭으로 이동하면 `원장 658건`이 표시된다. 모달 상단은 여전히 거래 398건이다.

원인:

- `BuildingDetailModal.tsx:224`의 거래 조회는 building key와 유형만 전달하며 기간을 보내지 않는다.
- `RentRegressionPanel.tsx:32` → `api/client.ts:245`의 회귀 호출 역시 날짜 범위를 보내지 않는다.
- 서버 `rent/router.py:374`, `:412`, `:441`은 날짜 범위를 받을 수 있지만 프런트가 전달하지 않는다.

판정: 전체 원장 열람 자체가 잘못이라고 단정하지 않는다. 다만 동일 모달에서 선택한 5년 창과 원장 전체기간을 명확히 구별하지 않는 것은 분석 범위 표시 문제다. 회귀도 선택한 5년 범위로 실행된다고 오해할 수 있다. 회귀 결과의 n은 이번에 확인하지 않았다.

권고: 선택 기간을 모든 탭에 전달하거나, 전체 원장을 보여주는 탭에는 전체기간과 실제 시작·종료일을 표시한다. 모달 상단 거래 건수에도 `5년 창`을 붙인다.

## 3. [P2 · 재현 · 정책 구분 필요] 선택 풀 평균에 지역 식별 구간 밖 전환율이 포함됨

재현: 쌍용예가 전환율 5.08%에서 `조원무궁화아파트 22.93% 구간밖`을 추가하면 `선택 풀(2동) 평균 14.00%`가 표시된다.

원인: `BuildingDetailModal.tsx:234`의 후보와 `:65`의 평균 계산은 `buildingRb != null`만 검사하고 1~15% 조건을 적용하지 않는다. 반면 `pipeline/rent/conversion.py:104`의 지역 평균은 구간 밖 건물을 제외한다.

판정: 후보에 `구간밖` 배지가 있어 수치가 완전히 감춰진 것은 아니다. 사용자가 만드는 탐색용 평균에 예외를 허용하려는 의도일 수 있다. 그러나 지역 평균과 선택 풀 평균의 포함 기준 차이, 선택 풀 평균은 목록 적용값을 바꾸지 않는다는 점이 요약 결과 옆에 명확하지 않다. 정책 재실험이나 산식 변경을 제안하는 것은 아니다.

권고: 지역 식별 표본과 같은 기준을 쓸지, 구간 밖을 포함하는 별도 탐색 평균으로 둘지 표시 정책을 명확히 한다. 후자라면 `구간 밖 1동 포함 · 탐색용 · 목록 환산 미반영`을 평균 옆에 표시한다.

## 4. [P2 · 재현/소스 확인] 95% 신뢰구간의 대상이 평균임을 표시하지 않음

쌍용예가 전세 카드의 표시:

- 중앙값 300.4
- 평균 309.3
- 95% 신뢰구간 303.2~315.4

중앙값은 해당 구간 밖에 있다. 이는 계산 오류가 아니다. `pipeline/stats.py:43`은 평균 중심의 t 신뢰구간을 계산하고, `stats_pack.py:63`을 거쳐 전달한다. 그런데 `BuildingDetailModal.tsx:89`의 라벨은 단순히 `95% 신뢰구간`이다. 이 탭은 중앙값을 강조하고 전환율 산식에도 중앙값을 사용하므로 중앙값 또는 전환율의 구간으로 오해할 여지가 있다.

권고: `평균의 95% 신뢰구간`으로 명시하고, 전환율 자체의 신뢰구간으로 읽히지 않도록 구분한다.

## 검증된 정상 동작과 한계

- 전환율 → 롤링 구간 → 거래 목록 → 전환율 → 회귀 분석 탭 선택은 정상.
- 쌍용예가 롤링 전세 건수 62+67+55+44+39=267로 전환율 카드 전세 건수와 일치.
- 전환율 탭에서 선택한 추가 건물은 회귀 탭에 `선택 2동 통합`으로 전달됨.
- 전환율 산출 불가 건물의 전세·반전세 최소 3건 조건 안내는 표시됨.
- 지역 전환율 산식은 종료된 실험의 확정 정책을 기준으로 검토했으며 재실험하지 않음.
- 검증 도중 브라우저 warn/error 로그는 없었음. 모든 지역·유형·회귀 결과·거래 원장 정합성을 보증하는 검사는 아님.

## 우선순위

선택 기간/전체기간 구분과 유효 표본 수를 먼저 수정하고, 선택 풀의 포함 기준·신뢰구간 라벨을 정리하는 순서가 적절하다.
