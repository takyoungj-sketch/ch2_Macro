# AI 어시스턴트 수정 결과

2026-11-07 로컬 작업 트리 기준. 운영 배포·push는 하지 않았다.

## 유지한 원칙

CH2·부동산 시장·통계·데이터 분석·관련 경제 분야에서는 네거티브 방식으로 대화한다. 무관한 질문, 개별 적정가격 결정과 직접적인 매수·매도 권유를 제한한다. 일반 지식, 수식, 가상 예시와 조건부 경제 시나리오는 허용한다. 답변의 길이·문단·표·수식·후속 질문·주의사항의 위치를 고정하지 않는다.

질문에 특정 단어가 있어야 표본·설명력·p값을 받을 수 있었던 자료 필터를 제거했다. ‘메뉴’, ‘게임’, ‘저녁’, ‘날씨’ 등의 단어가 포함됐다는 이유만으로 관련 분석 질문을 차단하지 않는다. 분명하게 무관한 전체 요청에만 간단한 네거티브 처리를 하고 나머지는 대화 모델이 맥락을 판단한다.

## 수정한 항목

- 공통 화면 등록: effect가 공급자 객체 전체에 의존하지 않게 변경하고, 없는 항목 삭제는 상태를 갱신하지 않도록 했다.
- 화면 근거: Insight·집합 주거/비주거 기본목록·임대 상세 변환기를 추가했다. 모달 뒤의 기본화면과 이전 대화의 근거도 별도 출처로 유지한다.
- Insight: 질문하는 시점에 현재 표시된 article의 제목·본문·표·선택 상태를 전달한다. 채팅 내용과 원시 거래·산점도 점 자료는 수집하지 않는다. 본문 전달 상한은 30,000자·120개 구역이며 생략 여부를 명시한다. 모델 전달 시 구역당 1,800자 상한을 적용한다. 긴 원문 참조는 근거 패널에 남기고 답변 본문에 반복 삽입하지 않는다.
- 지역프로필: 거래금액·인구·유형 구성·전국 순위·토지/아파트 분포·쌍둥이 지역을 추가하고 달력 연도 집계를 롤링 구간으로 부르지 않도록 했다.
- 임대 상세: 지역 전환율·건물 전환율·선택 건물 평균을 구분하고, 현재 탭의 집계값·롤링 지표·전체/불러온 거래 수를 전달한다. 개별 거래 행은 모델에 보내지 않는다.
- 상권: 연도와 건물유형을 혼동하던 변환을 수정했다. 오피스·중대형·소규모·집합상가·상가 전체를 모두 처리하고, 지표 12개 제한을 없애며 단위를 명시했다.
- 수치 검증: 모델이 일반 지식으로 분류해도 참조 없는 관측 수치를 그대로 통과시키지 않는다. 참조 없는 숫자 문장은 별도 모델 호출로 일반 정의·명시적인 가상 예시인지 확인한다. 이 확인 결과는 서버 내부 표시로만 인정해 모델이 JSON 필드를 위조해 통과할 수 없게 했다. 일반 예시와 근거 있는 관측을 한 답변에서 함께 설명할 수 있다.
- 세션: 로그인 사용자 ID를 세션에 연결했다. 비로그인 로컬 개발은 서버 발급 HttpOnly 브라우저 쿠키로 분리한다. 다른 소유자의 세션 ID는 새 세션으로 교체한다. 대화는 최근 40턴만 보관한다. 기존 제품 접근제어를 완화하지 않았다.
- 제품 지식: 공개 Insight 13개 주제의 번호·제목·내부 패널을 공통 JSON으로 관리하고 오래된 AI 설명을 수정했다.
- 오류: 제공자 응답 없음, 근거 검증 실패, 화면 자료 부족, 사용 한도 초과를 error_code로 구분한다. 실패할 때 무관한 정형 답안을 넣는 폴백을 제거했다. health에는 현재 실제 채팅 엔진을 명시했다.

## 검증

- 백엔드 테스트 160개 통과: 기존 AI·대화·사용량·전환율·플래너 테스트와 신규 화면 계약/검증/소유권 테스트.
- 토지·복합·집합·임대·지역프로필·Insight 6개 앱 TypeScript 검사 및 프로덕션 빌드 통과. 최종 임대 변경 후 해당 앱 빌드를 다시 확인했다.
- 실제 브라우저/모델: Insight 공개 3번에서 보고서 제목, 인구 보정 전후, 시군구 내부 비교 내용을 인식하고 수치를 인용하는 답변을 확인했다.
- 추가 실제 질문: 세 문장 요약과 가상 숫자 예시를 함께 요청해 응답을 확인했다. 원문 단락의 중복 삽입을 제거한 뒤에도 근거가 있는 답변이 나왔다.
- 해당 브라우저의 새 로그에서 Maximum update depth 경고는 확인되지 않았다.
- 로컬 API를 재시작해 변경을 반영했다. 로컬 개발 접근 설정은 기존 세션의 허용 범위대로 유지했다.

## 검증의 한계와 운영상 특성

일반 숫자 문장에는 필요할 때 추가 모델 호출이 발생한다. 재작성까지 수행하면 호출 수·비용·응답시간이 늘 수 있고, 기존 월 사용량 제한에 포함된다. 실제 관측 주장과 일반 설명의 의미 판단에는 모델이 사용되므로 완전한 사실성 보장을 뜻하지 않는다. 참조값·단위·출처의 구조 검증은 서버가 수행한다.

실모델 검증은 대표 Insight 질문에 한정했다. 다른 앱의 모든 데이터·탭에 대한 실모델 전수 검증, 운영 계정 간 E2E 격리 시험, 부하 시험은 수행하지 않았다. 계정 소유권 분리는 합성 사용자와 쿠키/JWT 테스트로 검증했다. 회귀·집계·결제 정책은 수정하지 않았다.

기존 미커밋 작업이 함께 있으므로 배포할 때 이번 AI 수정분을 구분해 별도 커밋으로 묶는 것이 좋다.
