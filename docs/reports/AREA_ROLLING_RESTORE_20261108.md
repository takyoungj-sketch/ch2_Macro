# 집합 면적형별 롤링 복원 — 2026-11-08

## 확인 결과

기존 `bc3fd11`(2026-11-06)의 전체/면적형 롤링 기능이 현재 배포 기준 main에 포함되지 않았다. PC 모달의 전환 버튼·면적형 차트뿐 아니라 API 클라이언트·응답 스키마·집계 함수·라우트도 함께 빠진 상태였다. 새 모바일 전용 모달도 전체 롤링만 연결하고 있었다.

## 복원 범위

- 원본 커밋에서 면적형 롤링 구현만 선별 복원. 최신 PC 회귀 UI·인증·안내 변경은 유지한다. 원본의 별도 AI 컨텍스트 변경 등 현재 코드와 관련 없는 기능은 가져오지 않는다.
- 주거·비주거 PC 롤링 탭: `전체 / 면적형`(공장은 `면적대`), 기존 평균·중앙값 전환 및 면적별 그래프·수치 표.
- 모바일 주거·비주거 롤링창: `전체 / 면적형·면적대` 전환 및 면적별 평균 추이·수치 표. 작은 헤더는 유지한다.
- 주거는 전용면적 5㎡ 반올림, 비주거는 기존 연면적 구간. 면적이 없는 거래는 면적형 보기에서 제외한다. 원장을 한 번 조회하고 메모리에서 기간×면적으로 나누는 기존 방식이다.
- 기본 5년은 PC·모바일 모두 비로그인 허용. 3·7년과 유료 분석은 기존 권한 제한을 유지한다.

## 검증

- `test_area_rolling.py` 및 `test_product_gate.py`: 10개 테스트 통과. 반올림·유형별 구간·거래 1건 유지·빈 구간 제외·무료/유료 구분 확인.
- 주거·비주거 API import, 집합 TypeScript 검사 및 production build 통과.
- 로컬 PC: 가경동 세원가경골 전체→면적형 전환에서 40㎡·60㎡ 선 그래프 및 5개 기간 수치 확인.
- 로컬 모바일 비주거: 가경동 2순환로 면적형 전환에서 연면적 구간별 그래프·수치 확인. PC 면적형의 평균↔중앙값 전환도 확인했다. 실제 휴대폰이 아닌 브라우저 화면 크기 검증이다.
- 운영 비로그인 스모크는 `pipeline/smoke_mobile_free.py`에 면적형 API와 7년 차단을 추가해 재현 가능하게 했다.
