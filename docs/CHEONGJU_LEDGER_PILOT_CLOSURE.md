# 청주 공통 대장 공급 파일럿 종료 보고서

종료일: 2026-10-05. 상태: **성공 범위를 충족하여 기술 검증 종료**. 사용자 결정 [D-077](lab/decisions/D-077.json)에 따른다. 파일럿 완료율 추정 대신 아래 완료 범위를 확정한다. 신규 실험·추가 적재·분석 재실행은 이번 종료 정리에서 수행하지 않는다.

## 종료 판단과 성공 범위

1. **청주 전체 원천 통합:** 같은 스키마·식별 규칙·소비 계약으로 2024-09·2025-07·2026-07 세 판본을 적재했다. 고유 관리 PK 144,247개, 건축 관측 421,987개, 토지·가격 관측 각각 1,436,782개를 보존했다. 최신 건물 관측 141,252개와 last_seen 2,995개를 구분한다. [전체 통합 결과](CHEONGJU_INTEGRATED_LEDGER_V2_CITY_RESULT.md).
2. **판본·출처·해시·복구 관리:** 원문과 가공 속성, 가격과 특성 내용, 주소 관측과 실제 소속을 분리한다. 원본 참조·해시·PK 공간·규칙 버전·출처·관측 이력을 보존하고 이전/최신 복구와 반복 실행을 확인했다. 4,000 PK의 별도 운영 경로에서도 세 실제 과거 판본을 접수·게시·복구했다. [4,000 PK 통합](CHEONGJU_INTEGRATED_LEDGER_V2_4000_RESULT.md), [원천 운영 절차](LEDGER_SOURCE_OPERATIONS_RUNBOOK.md).
3. **기존 제품 숫자 재공급:** 통합 원문에서 주거 속성 893개 키·공시지가 1,302개 키를 공급해 기존 값을 재현했다. 주거 1,471개 키, 비주거 도로명 군집 306개, 복합 13,293건의 기존 입력을 보존한다. 보류 속성·K-apt 등은 기존 출처를 유지한다. [숫자 공급 결과](CHEONGJU_PRODUCT_NUMERIC_SUPPLY_RESULT.md).
4. **실제 분석 엔진 재현:** 고정 사양·고정 입력에서 실제 주거·복합·비주거 상가/공장 회귀 엔진의 표본·계수·지표가 일치했다. 모형 성능 개선이나 새 변수 채택을 뜻하지 않는다. 가격 마트·응답 함수 재현과 실제 FastAPI/SQL의 244개 요청 비교에서도 차이 0건을 확인했다. [엔진 기록](lab/cheongju_supply_regression_replay.json), [마트·응답](CHEONGJU_PRODUCT_MARTS_API_REPLAY_RESULT.md), [실제 SQL/ASGI](CHEONGJU_PRODUCT_HTTP_SQL_RESULT.md).
5. **공급 handoff와 실패 시 이전 상태 유지:** 청주 최신 확장 원문을 별도 운영 경로에 접수하고 선택 DB에서 숫자를 재공급했다. 원천 active/revision·계약·검증 세대·코드·출력 해시를 묶었다. 새 공급을 실제 SQL 검증 입력에 투영한 해시도 일치했다. 적재·원천 게시·복구·제품 공급 게시 실패 시 이전 상태 유지와 소비 출력 복구를 확인했다. [공급 인계 결과](CHEONGJU_SOURCE_BOUND_PRODUCT_HANDOFF.md).

이를 통해 청주 전체 생성, 추적 가능한 판본, 기존 제품 값·실제 엔진 재현, 실패 시 공급 유지, 이전 복구, 보류 대상 자동 반영 금지, 제품 DB와 분리된 공급 경로라는 종료 조건을 충족했다. 이미 기록된 관련 테스트의 마지막 결과는 **168개 통과**, 최신 공급 인계 재연은 **11개 검사 통과**다. 이 문서 작성 중 재실행한 결과가 아니다.

## 성공을 과장하지 않는 경계

원문 보존은 검증한 선택 필드·원본 파일 참조와 제품 투영 필드의 보존이며 전국 원본 전체 열을 전부 복제했다는 뜻이 아니다. 최신 운영 래퍼 DB는 건물 141,252개·필지 480,633개의 **단일 판본에서 시작**했고, 원래 전체 DB의 과거 이력을 모두 이 래퍼에 옮긴 것은 아니다.

첫 최신 판본 접수·적재·게시 약 159초, 후보 DB 999,714,816바이트는 당시 측정이다. 원래 세 판본 전체 DB는 2,030,292,992바이트였다. 전국 용량·속도 추정치나 월간 순수 변경 비용으로 확대 해석하지 않는다.

주소가 관측됐다는 사실은 거래 소속·대표필지 인증과 다르다. 본번 0000과 코드 2 등 보류는 유지한다. 제품의 기존 결합·숫자 재현 성공은 원천 정확도 인증이나 운영 전환 승인과 다르다. 기본 소비 계약의 새 제품 보강·수량 합산·회귀 권한은 계속 false다.

## 미해결 항목은 후속 트랙으로 이관

- **데이터 품질:** 85개 검토 객체의 실제 소속·대표 선택, 복합 관리 PK 연결. 모든 키의 완전 판정을 파일럿 종료 조건으로 두지 않는다. 기존 보류·미할당·기존 값 보존을 유지한다.
- **실제 운영:** 새 원본 추출기의 접수 계약 연결, 실제 다음 월 자료 갱신, 정정판·장애 대응, 여러 판본 운영 래퍼의 공간/복구 비용. 새 자료가 들어올 때까지 파일럿을 열어 두지 않는다.
- **제품 통합:** 목적별 소비 권한 확정, TCP·프록시·브라우저와 제품 전환. 이미 확인한 ASGI/SQL 범위와 구별한다.
- **전국 구축:** 공통 구조 확정, 지역 단위 확장, 단계별 저장·처리 예산. 여러 도시·정밀 전국 비용 추정은 후속 구축 과제다.
- **회귀 연구:** 공시지가·특성·합산 변수의 최종 채택과 성능 개선. 공급 체계 성공 여부의 필수 조건이 아니다.

[제품 전환 판정](lab/cheongju_product_transition_gate.json)의 남은 세 조건은 **제품 전환 조건**이다. 이를 청주 파일럿 미완료·실패로 읽지 않는다. 원래 검증 보고서·코드·소비 권한을 종료 선언에 맞춰 임의로 바꾸지 않았다.

## 다음 단계와 종료 규칙

단계 명칭은 **① 청주 파일럿 종료 → ② 전국 공통 대장 구조 확정 → ③ 지역 단위 확장 → ④ 실제 월 갱신 운영 → ⑤ 제품 전환**으로 고정한다. 이번 요청에서는 ①의 기록과 [전국 확장 전 체크리스트](LEDGER_NATIONAL_BUILD_CHECKLIST.md)만 작성한다. ②~⑤를 착수·완료했다고 기록하지 않으며 실행 날짜는 미정이다.

Codex·Cursor와 후속 에이전트는 이 종료 보고서와 D-077을 먼저 읽는다. 과거 문서의 ‘다음 검증’은 당시 진행 이력이고 자동 실행 지시가 아니다. 추가 검증을 파일럿 완료 조건으로 붙이지 않는다. 새 구축 작업은 사용자 지정 범위로 시작하고, 실패가 발견되면 해당 구축 작업에서 처리한다. 파일럿 재개는 사용자가 명시적으로 결정할 때만 기록한다.
