VI. 기초 머신러닝과 종합 해석

29. 최근접 이웃과 변수의 스케일

① 정의

면적이 가까운 학습 건의 단가를 가져옵니다

최근접 이웃은 식을 만들지 않습니다. 확인 건의 면적과 학습 건의 면적 차이가 작은 순으로 k건을 고르고, 그 단가의 평균을 예측으로 둡니다. k = 1이면 가장 가까운 한 건의 단가 그대로입니다.

학습은 번호 1–20, 확인은 21–30입니다. 거리는 면적(㎡)만 씁니다. 단가는 고른 뒤에 평균합니다. 7번은 학습에 들어 있습니다.

② 같은 자료의 숫자

k = 1이면 확인 오차 64.0, k = 5이면 25.4

28번은 확인 자료이고 면적 28㎡, 단가 160입니다. 학습 면적 중 가장 가까운 것은 7번의 22㎡, 거리 6㎡입니다. k = 1의 예측은 480입니다. 절대오차는 320입니다.

k = 5이면 면적 22, 40, 48, 55, 60의 단가 480, 235, 188, 175, 168을 평균합니다. (480 + 235 + 188 + 175 + 168) / 5 = 249입니다. 160과의 차이는 89입니다.

k 28번 예측 확인 10건 오차
1 480 64.0
3 301 31.5
5 249 25.4

k = 3의 28번 예측은 (480 + 235 + 188) / 3 = 301입니다. 확인 10건 전체의 오차는 k가 1, 3, 5일 때 64.0, 31.5, 25.4입니다. k = 1의 확인 절대오차 합 640 가운데 320이 28번입니다.

③ 그림

28번에서 가장 가까운 학습 건은 7번입니다

④ 그 그림에서 읽을 문장

k를 키우면 480 한 건의 비중이 줄어듭니다

k = 1은 28번의 단가를 7번의 480으로 말합니다. k = 5는 그 480을 다섯 건 중 하나로 넣고 249를 말합니다. 160보다는 여전히 높지만, 480보다는 160에 가깝습니다. 확인 10건 오차도 64.0에서 25.4로 줄어듭니다.

이 25.4는 번호 21–30을 확인으로 둔 한 번의 결과입니다. k = 5가 다른 자르기에서도 가장 낮다는 말은 이 표에 없습니다. 자르기를 반복하는 방법은 교차검증입니다.

⑤ 자주 하는 실수

k = 1의 학습 오차 0을 성능으로 두지 않습니다

학습 건 자신의 가장 가까운 이웃은 자기 자신입니다. 그래서 k = 1로 학습 자료를 다시 맞히면 오차가 0입니다. 그 0은 과적합 장에서 본, 자료를 외운 점수입니다. 확인은 자기 자신을 이웃으로 쓸 수 없습니다.

주의

이웃은 면적 거리로 고릅니다. 표의 번호가 가까워도 이웃이 아닙니다.

조금 더 알아보기

학습 20건에서 각 점을 빼고 나머지 이웃으로 맞히면, k = 1의 오차는 0이 아니라 44.4입니다. 7번을 빼면 가장 가까운 학습 면적은 40㎡(단가 235)입니다. 자기 자신을 뺀 오차와, 확인 10건의 오차 64.0은 서로 다른 평가입니다.

가까운 이웃으로 맞추는 화면은 없습니다

집합이 보여주는 식은 직선과 로그입니다. k = 1, k = 3처럼 이웃 개수를 고르는 칸은 없습니다.
